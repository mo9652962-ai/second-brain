    1 Claude Code sends your email address to websites 701 242 Claude Code 在做网页搜索/取数时，把用户账号邮箱塞进了 User-Agent（形如 my-session-slug/1 <my.name@example.com>），等于把付费用户的真实邮箱主动送给任意第三方站点。issue 作者 taylor-edwards（v2.1.318 / macOS）称因此每天收到几十封诈骗与钓鱼邮件，获 204 个 👍，直言「这不该是 opt-in/opt-out 选项，应该从 harness 里彻底删掉」，并宣布把公司迁到 Pi + OpenRouter。Anthropic 员工 poteat 回复：v2.1.317 起内置 cc-plugin-privacy mod 会确定性拦截该行为，默认开启、可用 /plugins 关闭；但评论者 love540 在 2.1.318 上实测「文档里说要拦的那个场景没拦住」（用 echo 构造 User-Agent: test <自己邮箱> 测试），说明仍有 gap。评论主线两条：一是「隐私不该是插件，应该是不变量」（"Privacy shouldn't be a plugin. It should be an invariant."），二是有人让 Astra 检查 Codex CLI 0.159.0 的 UA——只含客户端版本、OS/架构与终端类型，不含邮箱。
    3 sshole 2437 598 今日最高分，一篇写法极骚的漏洞长文（作者 Ozgun Kultekin，Wakefield）：musl libc 上的 OpenSSH（Alpine / OpenWrt / Buildroot / Yocto 及大量 Docker 镜像）自 2016 年起，密码字段为 * 的账号接受任何 257–1024 字符的密码——即 root、纯密钥部署用户、LDAP 用户、Alpine 官方 AWS/Azure 镜像的默认 alpine 用户（该用户还带免密 doas，等价于 root）都可能被直接登录。成因是一串历史巧合：1980 年 Bill Joy 用 * 表示「永不可登录」；crypt() 失败本应返回 NULL，但 2012 年 musl 改成返回单字符 "*"（正好又是星号）；20 天后 musl 给 sha512crypt 加了 256 字节上限，超长密码直接失败 → 返回 "*"；2016 年 OpenSSH 修 CVE-2016-6210 的计时侧信道时引入「借用其他账号 salt 硬算一次」的逻辑，让 * 账号也走进密码比对，于是「库里的 * 对上 crypt() 返回的 *」→ 登录成功。2019/2022 年 Alpine 为修 CVE-2019-5021 又把 root 从 ! 换成 *，正好踩进来。十年没人发现，作者用 agent 集群构造 17,600 组怪异登录（glibc/musl × pam/no-pam × shadow 等）才在「musl 且无 PAM」这一格里跑出「yes」。修复：升级到 OpenSSH 10.6p2；暂不能升就 PasswordAuthentication no。站点自带浏览器内可交互复现 demo（数据不外发）。评论区：Debian/Ubuntu/Fedora 走 glibc + PAM 不受影响；有人贴出另一条讨论串（item 50377221）；还有人对「A+ 名字」和「star 才是主角」的梗会心一笑。
    4 MS Paint Remote Code Execution Vulnerability 381 141 微软画图（Windows Paint 应用）爆出 CVE-2026-83844：越界读（CWE-125），官方描述为「Out-of-bounds read in Windows Paint allows an unauthorized attacker to execute code over a network」；CVSS 3.1 = 8.1 HIGH（AV:N/AC:H/PR:N/UI:N/C:H/I:H/A:H，E:U/RL:O/RC:C），2026-10-13 公开，MSRC 已发布修复。CVE 记录里受影响区间为 11.0.0.0 ≤ v < 11.2605.91.0；评论区提到修复版本为 11.2609.401.0。评论第一反应统一是「以为是个玩笑」——画图也能 RCE；其次是追问「本地图像处理怎么算 remote」（远程来源的图片文件经网络投递触发）；也有人点赞微软 CVSS 的次级指标（攻击成熟度 Unproven、修复等级 Official Fix、置信度 Confirmed），认为比只给一个基础分有用得多。
    5 Nvidia Kubernetes Engine (NVKE) 21 3 NVIDIA 开源（Apache-2.0）的 NVKE：面向裸金属 GPU 集群的 Kubernetes 管理平面，97★ / 69 fork / 1,534 commits，文档在 docs.nvidia.com/nvke。官方明确它不是 K8s 发行版、也不是 Cluster API 的一个 flavour，而是「自托管集群工厂」——先由 nvkectl 起一个用完即弃的 seed 集群，再由它拉起 management cluster，之后管理平面通过 NICo + Cluster API + node agent 按需创建并全生命周期管理多个隔离的 workload cluster；Go 1.27.3 + Make 构建出 9 个二进制（agent / controller / nvkectl / management-engine / tenant-api / operator-api 等）。文档自己也把坑写在明面上：安装后 API 走明文 HTTP（需自行加认证）、管理集群不会自升级/自扩缩/无备份恢复流程、FDE 节点镜像仅供评估且不提供静态加密。评论第一条就扎心：「这就是 AI 生成 PR 的结果——FAQ 该说清产品到底干什么，而不是把文件树倒出来」；另一条在怀念几年前 K8s 霸榜 HN 的日子。
    6 Inkling 2 Small 111 50 Thinking Machines Lab 第二代模型（2026-11-05 发布）：MoE，594B 总参数 / 17B 激活，支持图像输入与可变 effort，Artificial Analysis Intelligence Index 拿到 31 分，官方称在 agentic coding、视觉、知识工作、推理上全面提升，靠的是更高效的预训练 + 一次大规模统一 RL。分发策略值得注意：先在自家 Tinker 平台以闭权重上线（可微调、可采样），承诺「外部安全测试与红队完成后，下周以 Apache 2.0 放出全量权重」——延续他们此前《a safe path to open weights》的路线。演示很有说服力：用 Three.js 无预制资产程序化生成整座城市模拟器、纯 Python 写的 PC 模拟器启动真实 Linux 内核并在浏览器里跑 Vim、Blender 渲染的手绘山谷+折纸鹤、从地图生成户型漫游视频。训练侧是对数十万条长程编码任务、跨多个 agent harness 与上下文压缩策略做 RL。评论：「还不是 SOTA，但开源权重实验室的迭代速度无可否认」；「这可能是第一个『够用』的美国开源模型，12 个月内出现开源版 Opus 5.5 不是幻想」；也有人注意到官方 benchmark 里报告方自己不是第一名，这点很加分。
    7 Closed AI models dominate the price-performance frontier 18 3 Village 用自家 LLM Atlas 做的「性价比前沿」研究（10-30 发布）：在 1%–3 倍 GPT-5 成本之间对数均布的 201 个预算点上，逐点找出能力最强的模型。结论很扎心——开放权重模型只在 3% 的预算点上是「最佳买」，而 6 月这个数字是 41%；且剩下的 3% 全挤在最便宜端，由 Gemma 4 E4B 与小米 MiMo-V2.6-Flash 把守。6 月的盛况是 DeepSeek V4 Flash 一家独占近三分之一预算点、智谱 GLM-5.2 紧随；随后被 GPT-6 Luna（9 月）、GPT-6.1 Terra（10 月）与 Claude Haiku 5.5 夺回。作者给的三条解释：闭源厂能拿自家旗舰自蒸馏出便宜档（Haiku 5.5 紧跟 Opus 5.5 两周）、一次发整个家族（GPT-6/6.1 从 Luna 到 Astra 占了前沿 21 点里的 11 点）、超大规模推理摊薄成本（Google 还用自己的芯片）。评论两条反驳：这数字本来就会来回摆；开源真正的价值不在性价比前沿，而在「可检查、可定制、不会被厂商禁止用于逆向和安全工作」。
    8 The Hackintosh Reborn 245 118 作者 Yoon 十年前写过 KVM + PCI 直通跑 macOS 10.14 的黑苹果指南；2021 年 M1 之后大家都以为这是终章，今年 macOS 27（Golden Gate）正式不再支持 x86，看似盖棺。转折是他为做人生第一个 iOS app，用闲置 ThinkPad T490 装了 macOS 26 + Xcode 26——Xcode 26 内置 Claude Code 与 OpenAI Codex 集成，一天之内没手写一行代码就做出可用 app。而最近几周黑苹果/黑 iOS 社区因为 AI 集体复活：macOS 27 跑上骁龙笔记本、ARM SBC（RK3588 + Mali 驱动）跑 macOS 27.2 Beta、Nintendo Switch OLED 跑 iOS 17、nullmoth 让 50 系 N 卡可用，还有 AirDrop、硬件视频解码、x86 上跑转译版 macOS 27。有人形容这是「打了类固醇的 Claude Code + Ghidra」。评论偏冷静：如今唯一还想要黑苹果的场景是无头构建机；也有人感叹「Mac 现在能原生跑 Switch 游戏，这才是 x86 终结的信号」。
    9 Pwn.college 14 1 亚利桑那州立大学（ASU）维护的免费网络安全实战教学平台，今日被重新翻出来。玩法是 dojo + 腰带制：注册即得「白带」，从终端、CPU 指令、网络比特流一路练到高阶漏洞利用，靠做题升级腰带；平台承载 ASU 大量安全课程，同时向全球免费开放。官方规则里有一条很实在的请求：题目同时用于给世界各地大学的学生打分，所以请不要公开 writeup、解题视频或直播（「我们知道拦不住，但请帮忙保住这个平台」）。对想系统入门 pwn/二进制方向的人来说，这是目前少见的「有课程结构 + 有评分 + 免费」的路径。
    10 Window Sweaters 272 86 一个纯为好玩而写的 macOS 菜单栏应用：给每个窗口套上「针织毛衣边框」。37 个应用有手挑配色的定制款（Finder、Slack、VS Code、Cursor、Claude、ChatGPT、Figma、Office 全家桶、Spotify……），其余应用从自身图标里取色织成锯齿/野餐/星光图案；菜单栏点毛线球即可换样式、图案、边框宽度与针脚大小。GPL-3.0，1.1k★ / 32 fork，Homebrew cask 一条命令装（未公证，需在隐私与安全性里「仍要打开」），macOS 13+，Intel 与 Apple Silicon 都支持，用了私有窗口 API（系统更新可能失效）。作者还贴心地写了一句「你可以直接把仓库丢给你的 coding agent，让它帮你装」。评论：有人说「正好赶上冬天」；有人因为今年供应链攻击太多，坦言「新仓库的东西我都不敢跑了」；也有人吐槽 README 里全是合成的空窗口图，看不到真实桌面效果。
