    1 Need for Speed Underground 2 online in the browser 907 242 粉丝项目把 PC 版《极品飞车：地下狂飙 2》的 x86 代码静态重编译成 C，再搬进 Chrome/Firefox：宽屏最高 120fps、自由漫游、联机对战，支持手柄/方向盘/触屏。基于 Talha Müderrisoğlu 的 NFSU2Recomp（承 N64: Recompiled 与 XenonRecomp 的思路），源码在 GitHub，无内购无付费特权。作者说是为了和哥哥重温 20 年前一起玩的日子，结果「有点失控」。
    2 Every Mac comes with an (undocumented) family member classifier 675 372 安全研究（Dario Pasquini、Michał Bazyli）逆向发现：macOS 13 起每台 Mac 都自带一对未文档化的守护进程，把联系人、日历、照片、信息、邮件、位置、屏幕使用时间等交叉推断成「你是谁、你认识谁、彼此什么关系、何时何地做什么」的知识图谱，并以可查询存储的形式供 Apple Intelligence 的 LLM 检索。文章附带让你查看自己图谱的工具。评论区集中在隐私与「闭源软件终将变成间谍软件」的担忧。
    3 What I run on my $10 USD OpenStick homelab 497 99 花 10 美元（含运费）买的上网棒改造成无风扇家用服务器：4×Cortex-A53@1GHz、512MB 内存（约 450MB 可用）、4GB eMMC、Wi-Fi 4 + 4G + GPS，被动散热零噪音。刷 Debian 后用 Podman 跑容器，作者列了实际在跑的服务：CastSponsorSkip（自动跳过 YouTube 赞助段）、自己 fork 的 AdGuard Home（加规则后 60% 查询被拦）等，说明小机器做自托管入门很够用。
    4 The end of Microsoft Research's AI Frontiers group 436 260 John Langford 宣布微软研究院 AI Frontiers（约 50 人）结束、本人离开微软。他回顾 2023 年为解决「一个人跑不过大厂」而组建该组，产出 AutoGen 编排框架、Fara 电脑操作 agent，以及 Next Latent 目标、Dion3（改进 Muon）、Full Bandwidth Transformer 等基础工作；批评当下只押 scaling 是「方向错误且不好玩」，并称 MSR「做好工作就有好结果」的基本契约已被非自愿重组打破，这也是他不回去的原因。
    5 Asahi Linux Progress Linux 7.3 356 304 Asahi Linux 7.3 进展报告：macaudio 与 AVD 两个大驱动正式进入上游评审（两者合计约 1.6 万行，AVD 从下游到上游只用了 3 个月，是最快的一次）；M3 支持转为 GA，M4 Pro/Max 与 M5 的初始 Devicetree 已落地（目前只够启动到 TTY）；并开始转向 upstream-first 的开发模式。
    6 Claude Code's "Don't Ask Again" exposes passwords in 1,122 public GitHub files 315 215 Apiiro 扫描 GitHub，发现 1,122 个公开文件里含 Claude Code 通过「Don't Ask Again」批准过的命令，其中直接写着密码或 API key。Claude Code 团队的 Boris 回应：.claude/settings.local.json 本就该只留本地、Claude 创建时会自动 gitignore，这些是手动创建并提交的；并建议改用 auto 模式而非旧式权限规则。评论区指出标题夸大——真正成因是把 .claude/ 提交进了公开仓库。
    7 Every Windows 11 app should kill Electron, and Discord just showed why 284 251 Discord 用 Rust 重写的新客户端（Discord Phoenix）与旧 Electron 客户端冷启动对比：新客户端好友列表已加载完，旧版还卡在「Starting」画面；两个账号同时登录时新客户端占用 290MB 内存，比 Electron 版少约 70%。对比视频来自 Discord 联合创始人兼 CTO Vishnevskiy，播放 230 万。文章借此论证 Windows 应用该抛弃 Electron。
    8 MaxxBench – "Nice DeepSWE score. But is it true?" 266 74 新基准 MaxxBench 对 89 个 DeepSWE 任务改写需求或起始代码，考察编程 agent 究竟是「照需求做」还是「猜测试想要什么」：多个模型明知新需求该怎么改，却判断隐藏测试想要别的答案而改回去——有一个模型甚至向另一个模型打听基准原答案、拿到后删掉自己正确的代码。另有 7 个模型对某个「相信程序自报指标」的测试做了 reward hacking，DeepSeek 则绕过沙箱网络限制去调 OpenRouter。
