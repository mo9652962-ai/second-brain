    垂直领域 AI Agent 工业级开发标准与双轨架构指南 (2026)¶

    ——从玩具 Demo 到工业级系统：以 WAVE-FIXTURE AI（波峰焊治具智能设计与审查）为实证解剖与工程基准

    Executive Summary 核心结论置顶¶

    1. 工业级垂直 Agent 普遍“上线即阵亡”的底层死因：
    2. 概率性与确定性的致命冲突：大模型本质是基于 Next-Token Prediction 的概率采样系统，天生具备不确定性、语义漂移与幻觉；而工业制造、硬件设计（PCB/CAD/EDA）、医疗金融、法律实务等垂直领域对错误的容忍度为 0（一次定位销错位或铜皮短路即导致整批产线报废）。
    3. 端到端黑盒的监督成本过高：将整个垂直业务完全丢给 Agent 自主闭环，微小误差在多步递归调用中被几何级放大，工程师排查黑盒输出的成本甚至超越了手动设计。
    4. 2026 工业级垂直 Agent 的黄金架构：双轨混合引擎（Dual-Track Hybrid Architecture）：
    5. 概率推理轨（LLM 负责）：仅负责意图识别、模糊语义向精确参数映射（NL-to-Params）、非标异常诊断归因、人机对话与解释。
    6. 确定性工程轨（物理/几何/规则引擎负责）：由纯 Python/C++ 领域解析器（Gerbonara/ezdxf）、几何拓扑内核（Shapely/Trimesh/OpenCASCADE）与硬性规则执行。
    7. 安全防伪锁（Human-in-the-Loop Gatekeeper）：置信度低时主动挂起阻塞性审核（Blocking Review），人工放行必须绑定几何指纹（geometrySha256），实现“生产图纸与带水印预览图纸硬隔离”。

    第一部分 工业级垂直 Agent 的五层成熟度模型（L1 ~ L5）¶

    等级 级别名称 核心特征 工业可用性 典型表现
    L1 单点提示词级 (Prompt Toy) 纯靠 LLM 提示词输入输出，无外部工具 ❌ 严禁上线 聊天框问答，写出的代码或几何数据充满幻觉
    L2 流程链条级 (Chained Agent) LangChain/ReAct 模式，串联基础 API ❌ 极度脆弱 多步调用容易陷入死循环，遇到非标输入直接崩溃
    L3 工具工具化级 (Tool-Assisted) LLM 驱动专用工具，具备结构化 JSON Schema ⚠️ 内部尝鲜 能调几何库画图，但缺乏物理干涉检查，无安全兜底
    L4 工业就绪级 (Production-Ready)
    (WAVE-FIXTURE AI 基准)    		 双轨混合引擎 + DRC 硬性门禁 + Golden Sample 自动化回归 + 人机协同闭环 ✅ 正式商用 缺层自动挂起 Review，错误阻断生产下载，全量用例回归
    L5 自愈自举级 (Autonomous Evolving) 从产线反馈与工程师修正中动态自适应更新规则库 🚀 未来标杆 自动沉淀新封装经验，DRC 阈值自优化

    第三部分 工业级垂直 Agent 开发的四大工程标准¶

    标准一：确定性与概率性职责边界（The Separation Doctrine）¶

    1. 绝对禁区：禁止让 LLM 直接“画坐标”、“算交集”、“估算承重”、“生成未校验的 G-code/DXF 原始数据”。
    2. 正确分工：
    3. LLM 输出的是 声明式指令（Declarative Intention） 或 参数配置字典（Config Dict）；
    4. 底层数学几何库执行 确定性编译（Deterministic Compilation） 并返回真实结果；
    5. LLM 接收真实几何运算结果的元数据（面积、干涉体积、违规项列表），负责向人类工程师进行自然语言汇报。

    标准二：人机协同审核与审计闭环（Confidence-Gated HITL）¶

    1. 低置信度主动挂起：
    2. 无论模型推理还是层映射，当置信度低于 0.8，或缺少输入必要依据时，系统必须挂起（Suspended），严禁自动猜测。
    3. 典型设计：4 种强制 Blocking Review：
      • CONFIRM_NO_BOTTOM_SMD：缺少底层阻焊/丝印时，强制工程师确认无贴片；
      • CONFIRM_NO_TOP_THT：缺少钻孔时，强制确认无通孔元器件；
      • CONFIRM_NO_SPRING_CLIP_REQUIRED：缺少顶层丝印时确认无需压扣弹力柱；
      • CONFIRM_NO_NPTH_AVAILABLE：无定位孔时强制挂起。
    4. 放行签名绑定几何指纹（Override SHA Invalidation）：
    5. 工程师在前端界面点击“人工放行此项警告”，后端必须计算当前工件全量几何的 SHA-256（geometrySha256）并存入放行记录。
    6. 一旦用户随后通过自然语言修改了任何参数（如倒角改 3mm），几何发生重绘，旧放行记录立即标记为 Expired，重新激活阻断门禁。

    标准三：黄金样本自动化回归基线（Golden Sample Framework）¶

    工业级系统必须杜绝“改了 A 修复，却悄悄弄崩了 B”的回归灾难： 1. 真实工业金样库（Golden Cases）： * 建立包含标准板、超高密度板、异形板、缺层异常板在内的端到端 Golden Case 数据集。 2. 客观几何指标断言： * 拒绝肉眼看图验收，采用数学距离自动化对比： $$\text{IoU} = \frac{\text{Area}(\text{Expected} \cap \text{Generated})}{\text{Area}(\text{Expected} \cup \text{Generated})} \ge 0.90$$ $$\text{Hausdorff Distance} = \max_{a \in A} \min_{b \in B} |a - b| \le 0.5\text{ mm}$$ $$\text{Hole Position Error} \le 0.05\text{ mm}, \quad \text{Radius Error} \le 0.02\text{ mm}$$

    标准四：零数据外泄与生产环境完全离线（Edge-First Local Pipeline）¶

    1. 涉及工业图纸、商业电路、军工/航空航天等垂直制造场景，核心几何解析、DRC 门禁和 DXF 导出必须实现 100% 本地纯离线运行。
    2. 即使接入 LLM，也必须做到本地部署（如 vLLM / Ollama 离线驱动）或仅将脱敏后的几何元数据传输给外部模型，严禁原始 CAD/Gerber 文件外泄。

    第四部分 垂直 Agent 开发技术选型速查表¶

    技术分层 推荐技术栈 工业级落选原因/避坑说明
    协议与标准集成 MCP (Model Context Protocol) 传统私有 REST 协议难以与现代 Agent 编排体系（Hermes/Claude）无缝对接
    底层解析器 Python gerbonara / C++ libopencad / tree-sitter 不要手写正则解析工业文件；KiCad/Gerber 历史方言繁多
    2D 几何内核 shapely (GEOS 绑定) scipy.spatial 缺乏复杂的几何拓扑布尔运算（Buffer/Union/Difference）
    3D 几何内核 trimesh + manifold3d / OpenCASCADE 传统 numpy-stl 无法做真正的实体布尔差集运算
    前端交互视口 Three.js (WebGL, 模块化 ESModule) 纯 2D Canvas 无法直观展示立体干涉与工装夹具装配结构
    后端驱动框架 FastAPI + Pydantic v2 高并发异步 I/O，强类型数据校验，自动生成 OpenAPI 契约

    第五部分 工业级垂直 Agent 核心套件实现（实测通过验证）¶

    已在 D:/wave-fixture-ai/vertical_agent_toolkit.py 完整实现并测试通过四大工业级核心引擎：

    1. VerticalAgentFSM：支持 INIT、INGESTING、PARSED、DRC_CHECKING、REVIEW_SUSPENDED、PRODUCTION_READY 六级状态机与历史检查点回滚（rollback_to）。
    2. GeometricHealer：提供 heal_polygon 拓扑四级自愈（is_valid ➔ make_valid ➔ buffer(0) ➔ dilate-erode），实测自动修复自相交领结多边形；计算不可伪造的 geometrySha256。
    3. DomainContextDistiller：将包含数万图元的原始工程数据，按边界、缺失层、DRC 违规与待审核列表压缩为 ~68 tokens 的极简 JSON 快照，实现 LLM 零幻觉低成本决策。
    4. AgentEvalHarness：提供自动化回归比对（IoU >= 0.90 且 Hausdorff <= 0.5mm），生成结构化基线报告。
