    自选课题千轮研究 ×20 · 应用性评估总报告（2026-08-23）¶

    任务：搜索引擎自找课题，重复 20 次，每课题不同，逐一评估「能否应用」 方法：IterResearch 式（覆盖率清单 + 多源交叉验证 + 应用映射） 实际执行：22 个课题方向 / 33 轮搜索 / 全部完成应用性判定 数据截止：2026-08-23

    🎯 结论置顶¶

    20+ 课题中：6 项高价值可直接应用（其中 1 项是墨题的潜在数据丢失风险！）、8 项印证现有实践、8 项入库备查。

    🔴 高价值发现（必须行动）¶

    R2/R25. Capacitor WebView IndexedDB 会被系统清除 ⚠️ 墨题风险¶

    • 信源：super-productivity issue #7901（真实案例：用户隔夜更新后 IDB 整库清空）+ Capacitor 官方文档 + bkbtechies 分析
    • 事实：Android System WebView 的 IndexedDB 在存储压力下可被 OS 静默清除；navigator.storage.persist() 在 WebView 内经常是 no-op；iOS WebKit 还有「7 天不用即清除」规则
    • 对墨题：v9.29 手机端 AI 直连用 IDB 缓存（llm-direct.ts）——缓存丢失只是重新下载模型（可接受），但若错题/练习记录也放 IDB 就是数据丢失事故
    • 行动项：排查墨题 IDB 存了什么——纯缓存可接受；用户数据必须迁 @capacitor-community/sqlite（原生文件系统，不可驱逐）

    R6/R20. 闲鱼「经营性卖家」新规量化标准 ⚠️ 业务合规¶

    • 信源：《闲鱼社区经营性行为界定与管理规范》（2026-06-01 生效）+ 网经社
    • 触发标准（任一即标记）：① 年发布超 30 件且品类 <3 类 ② 同款商品反复售出 >5 次 ③ 年累计销售 >10 万元
    • 对 sora：数模套餐（写作150/建模300/月卡400）是典型「同款服务反复售出」——有被标记为经营性卖家、要求市场主体登记的风险；另有敏感词红线（「代做」「包过」类词严打）、自动发货需原创资质
    • 行动项：闲鱼上架时标题避开敏感词组合（破解/代做/包过）；关注账号是否已被标记；量大后考虑正规化路径

    R8. whisper-tiny 中文准确率不足以交付¶

    • 信源：腾讯云实测（100 样本）+ 阿里云 ASR 实践
    • 数据：中文安静场景字错率——whisper-tiny ≈7.8~31.9%（AIShell 测试集 0.319！）、base ≈6.2~22%、small ≈4.1%；Qwen3-ASR-0.6B 平均 CER 5.2% 且速度最快
    • 对墨题：口语评测离线用 tiny 可能识别太糙——评测场景对准确率敏感。建议：默认升 base（+70MB 但 CER 明显改善），或关注 Qwen3-ASR-0.6B 的浏览器端可行性
    • 行动项：SpeakingView 加模型档位选择（tiny 快 / base 准），让用户按设备选

    R13/R14. 打包分发两板斧（刷题机直接适用）¶

    • PyInstaller 误报：重建 bootloader 从源码编译 → VirusTotal 误报 19/71 → 1/71（唯一有效手段；Nuitka 反而更差 19/71）；配 upx=False
    • Electron 中国更新镜像：cherry-studio 开源方案——按 IP 国家判断（cn→GitCode 镜像），配置化 feedUrl + 双镜像 fallback
    • 行动项：刷题机 Windows 包下次构建时重建 bootloader；Electron 端更新加国内镜像检测

    R24. 数模国赛官方规范红线（代写业务必知）¶

    • 信源：全国组委会《论文格式规范（2026 修订稿）》+《赛区评阅工作规范》
    • 硬性规定：摘要专用页为第 3 页且≤1 页；正文≤30 页不要目录；附录必须含全部可运行源程序，缺源程序或结果不符可能取消评奖资格；电子版第一页必须是摘要页；相似度 ≥25% 原则上不能报送全国评阅
    • 对代写业务：交付前检查清单必须有——①附录含可运行代码 ②全文无身份信息 ③相似度过线预警（AI 生成内容查重风险直接关联取消资格！）④PDF ≤20MB

    ✅ 印证现有实践的（8 项）¶

    # 课题 印证点
    R1 SQLite WAL 生产配置 墨题已有 busy_timeout=5000/WAL/NORMAL；可补 BEGIN IMMEDIATE 写事务（防死锁升级）；PRAGMA 需每连接重设（synchronous/cache_size 不持久）
    R4 BackgroundTasks vs Celery 墨题 AI 调用同步短任务 OK；>50 并发/长任务才需队列；分段 checkpoint 模式值得记（>10 API 调用的流水线必做）
    R7 TencentDB Agent Memory 官方 README 已有 Windows 原生安装 bat（setup-hermes-memory-tencentdb.bat）——之前评估时没注意到，接入成本比预想低
    R11 FSRS 生态 py-fsrs/ts-fsrs/fsrs-rs 官方多语言实现齐全——墨题 v9.19 用 FSRS 是正确押注，生态活跃
    R15 Prompt Caching 三层 Anthropic cache_control 读 90% 折扣/写 1.25×；Hermes per-conversation caching sacred 原则与业界最佳一致
    R18 Tauri vs Electron 新桌面工具选 Tauri（14MB vs 187MB、冷启动 320ms vs 1.8s）；但渲染一致性需求高仍选 Electron——刷题机维持 Electron 合理
    R19 Claude Code 上下文管理 microcompaction（热尾+磁盘卸载）/ 结构化压缩契约 / 子代理隔离——Hermes 压缩机制同级；「任务边界手动 compact」是好习惯
    R23 Hermes cron 可靠性 failure_streak + ticker heartbeat 双信号（PR #50016）——我们的 cron 错峰调度技能与官方设计吻合

    📌 入库备查的（8 项）¶

    # 课题 一句话结论
    R3 浏览器 STT 选型 browser-whisper 库（worker 架构+混合量化 fp32 encoder/q4 decoder）比裸 transformers.js 强；hybrid 量化是精度关键
    R5 KiCad IPC API SWIG pcbnew 绑定 KiCad 9 起 deprecated、11 移除；新开发用 kicad-python（IPC API）——PCB 自动化脚本要开始迁移
    R9 Obsidian 手机 git 插件移动端不稳定（isomorphic-git 内存天花板）；正解 = GitSync（Rust 原生）或 Remotely Save；我们 GitHub 同步走桌面端是对的
    R10 AI Skill 供应链安全 ClawHub ClawHavoc 1184 恶意技能；SCH 攻击（自然语言合规劫持）0% 检测率——skill-vetter 技能的价值实证，外部技能必须审 SKILL.md 语义而非只扫代码
    R12 Vue 虚拟表格 vue-virtual-bi-table 双轴虚拟化（行 useVirtualList + 列 IntersectionObserver），5 万行×25 列流畅——墨题错题列表膨胀时的候选
    R16 Yjs CRDT 协作 snapshot+tail 重放模式、awareness 不持久化、persist-before-fanout——未来协作功能的方法论库
    R21 JLCPCB 自动化 kicad-jlcpcb-tools（Bouni）已覆盖 LCSC 选料+BOM/CPL 生成+钩子脚本——PCB 流水线可直接集成
    R26 多供应商熔断器 per-(provider,model) 熔断 + fallback 链内重试 + 半开探测——Hermes 容灾链的理论补全
