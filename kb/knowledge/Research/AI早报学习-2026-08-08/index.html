    AI 早报学习研究 · 2026-08-08¶

    来源：8.6 AI 早报（阿梨Aria）+ 原文验证。learn→research→apply 流程。

    🥇 Top 发现¶

    1. ChainDrop npm 供应链攻击（已应用到本地安全检查）¶

    事实（Chainguard/Snyk/Socket 三源验证）： - 8/4 攻击者攻陷 keyv 维护者 GitHub 账号 → 发布恶意版本：keyv@6.0.0、cacheable-request@13.0.20、cache-manager@7.2.10、@cacheable/utils@2.5.1、flat-cache@6.1.24（9 包家族） - 恶意特征：包内加 setup.mjs + Math_Symbol.js + "preinstall": "node setup.mjs" → npm install 时自动执行 - 行为：Bun 混淆载荷 → 窃取 npm/GitHub/AWS/K8s/Vault 凭据 → 用窃取 token 自动重打包发布（蠕虫式传播 400-2200 包） - C2 域名：npm-cache[.]com / pypi-get[.]com / js-mirror[.]com；回退通道：GitHub 仓库 Shai-Hulud: Here We Go Again

    本地 apply（已执行）： - 扫描刷题机 frontend + Hermes ui-tui + apps 的 node_modules → 无 setup.mjs 恶意特征，干净 ✅ - 刷题机 package-lock 无 keyv/flat-cache/cache-manager 依赖 ✅ - 唯一 Math_Symbol.js 是 regenerate-unicode-properties（babel Unicode 数据）正常文件，非恶意

    教训入库：npm 依赖有 lock 还不够——preinstall 钩子在 install 时执行，特征文件扫描（setup.mjs/Math_Symbol.js）+ 锁定已知恶意版本号是有效检测手段。

    2. Cloudflare OS — 企业 AI 工作平台设计原则（可迁移）¶

    事实（Cloudflare 官方博客）： - 用 Workers + Access 自建内部 AI 平台，数千员工使用 - 五原则：① AI 服务客户优先（先定义 jobs-to-be-done）② 人人有超能力 ③ 人负责输出（AI 是工具不是团队成员）④ 组织上下文比模型重要 ⑤ AI 权限不扩大（用 AI 时权限 ≤ 本人权限） - 魔法邮件别名 → 收集用户不想做的工作 → 沉淀 skills → 平台化（与 Hermes 的 skill 模式同构！）

    对照 Hermes：sora 的刷题机/自动化工作流遵循同样模式（human owns output + skill 沉淀）——验证了方向正确。

    3. Qwen-Image-3.0-Pro — 文生图成本大幅下降（闲鱼应用）¶

    事实：阿里发布，Arena 文生图榜中国第一/主流第二；4.5k token 提示词（报纸/试卷/菜单一图生成）；10px 级文字渲染；12 种语言；Pro 1K 图 0.25 元/张、标准版 0.18 元/张。

    apply 评估：闲鱼 PPT/素材生意的配图成本可忽略（0.2 元/张 vs 现用 0.5-1 元）；文字渲染能力强 → 可做"带字海报/菜单"类商品。待办：接入百炼 API 测试 → ✅ 2026-08-23 已确认落地：百炼（dashscope）已接入 health_provider_check 且 OK（qwen-plus 1333ms）；qwen-image-3.0-pro 已成为日常生图主力（见记忆「视觉: 日常→qwen-image-3.0-pro(百炼)」）。

    4. 小米 XR-1 — 机器人 VLA 数据范式突破（行业知识）¶

    事实（GitHub/HF 原文验证）：10 万小时手持 UMI 轨迹（非昂贵机器人演示）预训练 → 后训练对齐实体/指令；RoboCasa365/RoboDojo 双榜第一（+23.2%/+58.3%）；每任务 <10h 微调成功率 75%（π0.5 仅 40%）；5B 模型开源（Qwen3-VL + DiT MoT 架构）。

    关联：与 sora 的单片机/边缘 AI 兴趣线相关——"低成本数据替代昂贵演示"范式可延伸到边缘设备数据集设计。

    5. 谷歌 DeepMind 高层变动（行业动态）¶

    事实：Hassabis 卸任 CEO → Alphabet 首席科学家（专注 AGI 战略 + Isomorphic 药物研发）；Jeff Dean 27 年谷歌生涯结束 → 与 Ghemawat/Vinyals/Quoc Le 创办 Discovery Loop（自动化 ML/科学实验，Radical Ventures + Khosla 领投，谷歌投资+云合作）；Koray Kavukcuoglu 接任 SVP。行业解读：谷歌 AI 面临 OpenAI/Anthropic 追赶压力下的领导层重构。
