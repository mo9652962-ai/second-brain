    PCB 自动化能力千轮研究 · 2026-08-08¶

    2 轮 × 8 路搜索引擎研究（自动布线/质量规则/AI 布线/SKiDL）+ 本地实测验证（SKiDL 跑通）。

    结论置顶¶

    PCB 自动化能力矩阵升级三件套：①SKiDL 原理图自动化（已实测跑通：Python 电路→ERC→KiCad netlist）；②自动布线工具链（KiCadRoutingTools/kicad-tools 含 MCP Server，CLI 可脚本化）；③JLCPCB DRC 质量参数固化（最小线宽 0.15mm/过孔 0.15mm/丝印 1.0mm）。2026 模式：AI 加速原理图 → EDA 自动布线 → JLCDFM 验证 → 打样。

    一、自动布线工具链（本地 CLI，可嵌入流程）¶

    工具 能力 接入方式
    KiCadRoutingTools（drandyhaas） route.py 单端 / route_diff.py 差分对 / route_planes.py 电源地平面 / place_optimize.py 布局优化 pip install + CLI：route.py in.kicad_pcb out.kicad_pcb --nets "Net1" --power-nets GND VCC --power-nets-widths 0.4 0.5 --track-width 0.2 --via-size 0.4
    kicad-tools（rjwalters） kct route --complete 补线 / --nets 指定网络 / MCP Server for AI Agents pip install "kicad-tools[mcp]"——AI agent 直接操作 KiCad 设计
    OrthoRoute（bbenchoff） GPU 加速 PathFinder 布线，KiCad 9+ IPC API，headless 云模式 插件 + CLI
    Freerouting 经典开源 rip-up-and-retry，95%+ 完成率 KiCad 插件/外部程序

    二、AI 布线服务（云端，免费层可用）¶

    服务 方式 实测
    Quilter 物理驱动 RL，多候选布局并行 + 物理评分，KiCad 导入导出 需要完整原理图
    DeepPCB RL 自博弈路由，免费层 pay-as-you-go 开源板实测：98/290/414 线全部成功

    工作流模式：AI 加速原理图 → EDA 布局布线 → 制造输出。AI 产物必须人工 DRC/ERC 验证（不验证不投产）。

    三、质量规则（JLCPCB 实测能力参数）¶

    参数 值
    最小线宽/间距 ≥0.15mm（3.5mil）
    最小过孔 ≥0.15mm
    丝印字高 ≥1.0mm（40mil），宽高比 1:6
    非镀通孔 ≥0.5mm
    槽宽（2 层） ≥0.5mm，长≥2 倍宽
    Via-in-Pad 6-20 层免费
    免费 DFM 验证 JLCDFM（jlcdfm.com）上传 Gerber

    信号完整性：3W 规则（高速线间距≥3 倍线宽）、高速线勿跨分割地平面、先跑原理图 ERC 再布局。

    四、去耦电容布局规则（可脚本化）¶

    1. 高频去耦电容尽量靠近 IC 电源引脚（0.1µF SRF 100MHz → <0.375 英寸）
    2. 短宽走线 + 专用过孔（减小环路电感）
    3. 多电容覆盖频段（如 0.1µF + 10µF 组合）
    4. 不同电源轨独立去耦网络

    五、SKiDL 原理图自动化（本地实测 ✅）¶

    验证结果：LED 电路（R + LED + C）→ ERC（0 错误）→ KiCad netlist 生成成功。

    import skidl
skidl.lib_search_paths['kicad10'].append(r'~\AppData\Local\Programs\KiCad\10.0\share\kicad\symbols')
from skidl import *
vin = Net('VIN'); gnd = Net('GND')
r1 = Part('Device', 'R', value='1K', footprint='Resistor_SMD:R_0805_2012Metric', ref='R1')
vin & r1[1] & led1[2]   # & = 连接
ERC()
generate_netlist(file_='test.net', tool='kicad10')   # 工具名小写！

    坑：①工具名小写 'kicad10'（不是 'KICAD9'/'KICAD10'）；②lib_search_paths['kicad10'] 需追加符号目录；③SKiDL 用系统 python（netlist 是文本），KiCad python 只管 pcbnew；④& 在 bash heredoc 会被解析——脚本用 write_file 写。

    六、升级后的自动化流水线（目标架构）¶

    SKiDL 电路描述 (Python)
  → ERC + netlist (kicad10)
  → pcbnew 放置 + 板框 (generate_board.py 模板)
  → KiCadRoutingTools 自动布线 (route.py --power-nets)
  → DRC 校验 (JLCPCB 参数)
  → JLCDFM 验证 Gerber
  → kicad-cli 导出 Gerber/3D
  → 打样交付
