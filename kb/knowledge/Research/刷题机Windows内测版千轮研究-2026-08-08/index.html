    英语刷题机 Windows 内测版 · 千轮研究¶

    2 轮 × 7 路搜索：竞品分析 + 桌面框架选型 + 自动更新方案 + Windows 安全协议。 执行结果（2026-08-08）：✅ 数据清理（4.8MB→316KB 空库）✅ main.js 数据目录改 %APPDATA% ✅ 构建 v2.0.0-beta.1 ✅ 已发布 epm-releases（自动更新链路验证通过）✅ 稳定性增强（单实例锁/崩溃日志/数据自动备份）✅ 内置293道正式真题（考研/高考/四六级）✅ beta.2 发布（150MB）⚠️ 待用户 VirusTotal 扫描

    结论置顶¶

    Windows 版不是从零开始——现有 electron/main.js（170 行）+ electron-updater + PyInstaller 后端已完成 90%。内测前必须做：①清空测试数据（question_bank.db 4.8MB 测试内容）②安全协议（签名/行为规范）③更新机制验证 ④内测清单。

    一、竞品研究（背单词/刷题 Windows 生态）¶

    竞品 核心机制 借鉴点
    墨墨背单词 艾宾浩斯遗忘曲线安排复习（认识/模糊/忘记三态） 复习调度算法（我们已有 practice_answers + wrong_stats 可扩展）
    百词斩 图片联想 + 选择题（排除法） 选择题模式我们已有（单选题）
    不背单词 原声例句 + 语境记忆 例句库增强方向
    Anki 间隔重复 + 高度自定义（桌面端强） 自定义词卡/导入导出
    扇贝 打卡 + 社群节奏 打卡统计（learning_days 表已有）

    差异化定位：竞品都是"背单词"，我们是"刷真题"（考研/高考客观题）——这正是市场空白（Anki 太硬核，墨墨/百词斩是背词不是刷题）。

    二、技术方案（沿用现有，已验证）¶

    Vue3 + Vite + sql.js (前端纯静态)
  ↓ electron-builder 打包
Electron main.js (spawn 后端 + autoUpdater)
  ↓ PyInstaller onedir
FastAPI backend_app.exe (EPM_DATA_DIR 隔离数据)

    选择理由（研究验证）： - Electron + electron-updater = 行业标准（差分更新 + GitHub Releases 集成） - 前端 sql.js = 数据本地化（无服务器依赖，内测分发简单） - 后端 PyInstaller = 免 Python 依赖（standalone_main.py v9.20.1 已验证）

    三、自动更新方案（已有基础）¶

    现状：electron/main.js 已实现 autoUpdater + GitHub epm-releases 发布源（mo9652962-ai/epm-releases）

    完善点： 1. 更新通道：内测版用 beta 通道（electron-builder 支持 draft/prerelease 标记），正式版走 stable 2. 更新检查频率：启动检查 + 每 30 分钟（现有逻辑） 3. 更新服务器：GitHub Releases（公开仓库 epm-releases 存发布包）——注意：epm-releases 是发布专用仓库（不含源码，避免内测泄露） 4. latest.yml 元数据：electron-builder 自动生成，确认上传

    四、Windows 安全协议（防杀软误报）⭐¶

    4.1 核心原则（微软官方文档 + 2026 实践）¶

    1. 数据放用户目录（%APPDATA% 或 %LOCALAPPDATA%），不写 C:\Windows / Program Files
    2. 不加开机自启（无提示自启 = 高危信号）
    3. 不收集隐私（不读浏览器历史/通讯录）
    4. 标准安装器（NSIS——electron-builder 默认）
    5. 代码签名（最核心）：
    6. 内测阶段：自签名证书 + 文档说明"首次运行 SmartScreen 提示属正常"
    7. 正式发布：OV 证书（约 ¥2000/年）+ RFC3161 时间戳
    8. EV 证书不再绕过 SmartScreen（微软 2026 确认）——不必多花钱
    9. SmartScreen 信誉：签名 + 时间戳 → 提交微软 SmartScreen 门户积累信誉
    10. 发布前自扫：VirusTotal 多引擎扫描（确认无引擎误报）
