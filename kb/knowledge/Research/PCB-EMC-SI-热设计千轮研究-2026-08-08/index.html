    PCB EMC/信号完整性/热设计千轮研究 · 2026-08-08¶

    2 轮 × 7 路搜索：EMC 黄金规则、信号完整性、热设计、继电器电弧抑制、去耦电容、via stitching。目标：把规则转成空调板 v2 可执行动作。

    结论置顶¶

    三大类规则已系统化：EMC（回流路径/去耦/地平面 8 条黄金规则）、信号完整性（3W/受控阻抗/短走线）、热设计（热过孔阵列/铜皮铺展/载流宽度）。空调板 v2 必做 5 件事：①继电器加 RC 吸收（250V 电容）+续流二极管 ②去耦电容贴 IC 电源引脚（via 近 pad）③GND 铺铜 + via stitching ④强电弱电隔离槽 ⑤电源入口滤波。

    一、EMC 黄金规则（Academy of EMC 8 条 + Sierra 7 条）¶

    回流路径（最重要）¶

    1. 信号绝不跨越分割参考平面（分割 = 回流中断 = 大环路 = EMI）
    2. 始终考虑回流电流：高频回流走最低电感路径 = 信号正下方地平面
    3. 高频信号（>1MHz）贴着参考平面走
    4. 顶层/底层填充 GND（共模抑制）

    去耦（Guideline #3）¶

    • 低电感电容 + 电源/地平面
    • 去耦电容直接连电源/地平面（via 在 pad 内或相邻）
    • 可与 IC 共享电源 via（走线 < 平面间距即可）
    • 两个去耦电容间隔几厘米 > 单电容

    其他¶

    • 控制上升/下降时间（慢边沿 = 低 EMI）
    • 时钟线尽量短
    • λ/10 规则：走线 > λ/10 视为传输线（受控阻抗）
    • 参考：Montrose《PCB Design Techniques for EMC Compliance》(IEEE)

    二、信号完整性¶

    规则 内容
    3W 规则 平行走线中心距 ≥ 3×线宽（降串扰）
    差分对 紧耦合、等长
    受控阻抗 IPC-2141A 微带/带状线计算（>50MHz 时）
    相邻层垂直 相邻层信号垂直走线（非平行）
    端接 长走线 50Ω 端接防反射/振铃
    短走线 时钟/高速信号尽量短

    三、热设计¶

    技术 参数
    热过孔阵列 0.15-0.25mm 直径，SMT 热焊盘下方密集排布
    Via farm 镀厚铜 55-70µm（vs 常规 35-45µm），Z 向导热
    PCB 冷却上限 1-3W/元件（以上需散热器）
    铜皮铺展 功率元件接大面积铜皮；平面放外层散热更好
    载流宽度 IPC-2221/2152（电流 → 线宽）
    过孔阵列 直接连接内部/底层实铜平面（低热阻路径）

    四、继电器电弧抑制（空调板直接相关！）¶

    线圈侧（DC 12V）: 续流二极管（flyback）→ 保护驱动晶体管
触点侧（AC 220V）: RC 吸收网络（snubber）→ 消除触点电弧 + LC 振铃
    • 续流二极管：DC 感性负载必加，防止关断高压反冲
    • RC snubber：AC 电路不能用续流二极管 → RC/MOV/TVS
    • 电容耐压 ≥250V（230V AC 应用，触点瞬态可达数倍电源电压）
    • 电阻用金属膜/碳膜（绕线电阻是电感，自相矛盾）
    • snubber 走线尽量短
    • 两者都用：继电器寿命 100×（50k → 5M 次）+ EMI 干净
    • 5 个元件（1 二极管 + 2 电阻 + 2 电容）全套保护

    五、去耦电容放置（Power Integrity）¶

    • bypass（高频局部，0.1µF）vs decoupling（板级低频，10µF）——不同职责
    • 放置：尽量靠近 IC 电源引脚，via 贴近 pad（最小回路电感）
    • 多 via 降电感（高功率设计）
    • 不要串联去耦（VCC→电容→IC 引脚是错误老思路——电容并联于平面间）
    • 组合：100nF + 10µF 覆盖宽频段

    六、Via Stitching（可脚本化落地）¶

    场景 间距
    RF/高速（阻挡电磁波传播） λ/20
    连接多层地平面 常规即可
    电源（高电流低温升） 紧密排布
    地平面断裂处/板边 沿走线/边缘成行
    • pcbnew 可脚本添加缝合过孔（board.Add(PCB_VIA) + SetDrill/SetPosition）
    • 低速信号连接地平面：方便但不必须

    七、空调板 v2 升级清单（EMC/SI/热 → 动作）¶

    # 动作 对应规则 实现
    1 K1-K3 触点加 RC 吸收（电容 250V/0.1µF + 金属膜电阻 100Ω） 继电器电弧 原理图加元件 + 近触点放置
    2 Q1-Q3 集电极加续流二极管（1N4007） 感性负载反冲 原理图加元件
    3 去耦电容贴 U1/U4 电源引脚（via 近 pad） 去耦黄金规则 布局调整
    4 GND 铺铜（顶层/底层）+ via stitching 地平面屏蔽 pcbnew zone + 脚本 via
    5 强电区（继电器/220V 端子）与弱电区隔离槽 爬电距离 6.3mm Edge.Cuts 槽
    6 电源入口 π 滤波（C+磁珠+C） 电源滤波 原理图加元件
    7 载流线宽核算（IPC-2221） 热设计 12V 驱动 ≥1.5mm
