    五篇亮点¶

    1. MEMOIR — 记忆生命周期（知识管理） 2611.07631v1 现有记忆系统的病：写入时打静态重要度、用完从不回改。MEMOIR 两步治：① 压缩前先过筛（judge 检查「答案相关证据是否还在」再合并）② 每次查询后归因（哪些记忆支撑了答案 → 回写检索优先级）+ UCB 探索项防热门记忆挤掉冷证据。LoCoMo 1,905 对 QA 上 evidence recall@5 +11.92pp（对比裸 cosine），置信门反馈再 +1.50pp。 → 直接对应 mnemon：131 条洞察全是「写入即定分」，没有「用后回改」。

    2. MemUse — 记忆到底有没有被用上（知识管理 · 反常识） 2611.01718v1 8,000 条 SWE-bench Verified 轨迹 × 3 套记忆系统：resolve rate 与「完全无记忆」基线差距 < 0.4pp。细看：多数投递的记忆不相关、多数相关的记忆没被用、两套系统里多数投递只是复述 agent 自己还看得见的内容。23.2% 用对了记忆的 episode 仍然失败；16 个「用错」的里 5 个照样成功。 → 结论：记忆评测不能看「投递了什么」，要看「投递之后动作变了没」。这条也是本周最该写进组会 PPT 的反常识。

    3. Zep Agent Skills — 从验证过的轨迹编译技能（AI Agent） 2611.01386v1 只用 verified attempts 当证据；每个 Skill 字段标注支撑事件；Trace = 有序事件 + 结果 + 验证强度；Reflector + Curator 双角色编译成带版本 Skill，准入闸门管谁能上线，验证后的使用结果反过来改检索排序。Agent Skills 是开放格式（Anthropic → Agentic AI Foundation），走 API/MCP + 渐进披露。τ³-bench banking / AppWorld / EnterpriseOps-Gym 上，教师模型轨迹编出的技能提升三个弱执行器通过率。 → 对应我们的 skill-pipeline：技能该有「证据引用 + 验证强度 + 用后调权」，而不是纯 markdown。

    4. LLM 能不能做文献综述（AI 辅助写作 · 102 篇基准） 2611.05459v1 6 个 AI 工具 × 4 阶段（找文 → 解读 → 综合 → 提未来方向），基准是一篇已发表综述 + 其 102 篇语料。初检：5 个工具合计找到 57 篇，单工具最好 42 篇；开机构图书馆权限后 Codex 42→82、Claude Code 15→79。给全 102 篇 PDF 后：3 个工具都找对了 18 篇「实质相关」，但把 40%~79% 的顺带提及误判为实质相关。综合段落"大体准确但洞见有限"，存在无支撑论断、引文错误、共识夸大。没有一个工具在所有任务上最好。 → 直接对上我们的 light-literature-search：覆盖度必须标、passing mention 与 substantial 必须分档、综合结论必须带出处。

    5. IdeaTaste — LLM 有没有「研究品味」（科研工具） 2611.03424v1 用 2025 冻结的文献快照让模型写提案，对比同一社区 2026 真实发表；6 模型 × 4 领域 × 90,000+ 提案。引用匹配仅达人类 26%、想法匹配 18%。模型能像社区一样「引得多、任务和方法也接得住」，但落不到具体做法和研究计划；给更丰富上下文、扩模型种群都补不上这个缺口。盲审里 AI 提案「表述最接近、预期成功率差最多」。
