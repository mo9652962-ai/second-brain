    AI / ML / 编程 / 开源精选（4 条）¶

    1. Gpiozero Flow¶

    • 链接: https://bennuttall.com/blog/2026/07/gpiozero-flow/
    • 评分: 78 · 评论: 21
    • 摘要: gpiozero 作者 Ben Nuttall 用 Claude 辅助开发的可视化拖拽式树莓派 GPIO 编程工具，基于设备间 source/values 数据流模型，类似 Scratch 的图形化编程方式，让按钮、LED、伺服电机等外设以"连线"方式组合控制。

    2. AI's top startups are barely publishing their research¶

    • 链接: https://www.science.org/content/article/ai-s-top-startups-are-barely-publishing-their-research
    • 评分: 537 · 评论: 274
    • 摘要: Science 报道指出 AI 头部创业公司几乎不再发表研究论文，引发社区对前沿 AI 研究透明度和开放性的激烈讨论（274 条评论为当日 AI 类最高热度之一）。

    3. Agent-Manager: A Tmux TUI for Running Claude Code, Codex and OpenCode¶

    • 链接: https://github.com/YoanWai/agent-manager
    • 评分: 38 · 评论: 22
    • 摘要: 开源 Go 编写的 tmux 终端界面，把 Claude Code、Codex、OpenCode、Grok、Gemini CLI 等多个 AI 编程 Agent 会话统一管理——实时状态、项目分组树、会话内 diff 审查（Ctrl+R 全文件 diff 并回传评审提示）、内置 MCP 服务让 Agent 原生发现命令。

    4. GCC steering committee announces AI policy¶

    • 链接: https://lwn.net/Articles/1086041/
    • 评分: 106 · 评论: 102
    • 摘要: GCC 指导委员会采纳 AI 贡献政策：拒绝包含 LLM 生成内容的"法律意义上重大"贡献（约 15 行代码/文本以上），但允许 LLM 用于研究、bug 排查和补丁评审，政策将定期复审演进。
