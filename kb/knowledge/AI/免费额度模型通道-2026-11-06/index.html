    免费额度模型通道清单（国内 / 国外）· 2026-11-06¶

    这份笔记怎么来的：11-06 18:54 起 Antigravity/Gemini 账号被 Google 以 TOS 为由 403（service disabled ... violation of Terms of Service），sora 19:19 让「搜索全网查看现在还有什么可以免费使用额度的模型，国内和国外的」。k 在 19:19–19:27 做了 30 次 web_search + 4 次 web_extract（含 openrouter.ai/docs/guides/overview/limits），答案只发在聊天里，没有任何文件写入（该会话 write_file=0 / patch=0）。11-07 反思时从 state.db 把结论回存成本笔记。

    证据档位：清单结构、平台名单、接入端点 = 当日检索所得（观察）；具体额度数字 = 二手汇总（多为第三方文档/价格页摘要），今日未逐条复核。接入前打开文末官方链接再核一遍，别把这里的数字当 SLA。

    先分清三种「免费」¶

    类型 含义 稳定性
    ① 零费率模型 定价页写免费，调用不扣钱 长期有，但限速/限并发
    ② 注册赠额 送一笔 token/代金券，可抵扣付费模型 会过期，用完即止
    ③ 订阅内含 买会员才「免」 不算白嫖

    Hermes 只能接 ① 和 ② 里的 OpenAI 兼容 API；客户端内赠送的 token（如 ZCode）导不进来。

    国内（直连，适合 Hermes）¶

    平台 可白嫖项 额度/限制 接入 备注
    智谱 BigModel glm-4-flash / glm-4.7-flash 长期免费 免费模型限速；新用户另有体验包（以控制台为准） https://open.bigmodel.cn/api/paas/v4 国内最稳零费率；GLM-5.x 旗舰付费，别填错 ID
    硅基流动 价格页仍标免费的小模型（GLM-4-9B、部分 embedding/OCR/语音） 免费模型 RPM/TPM 固定，升级不增免费额 已配 现有付费 key 已 402，只能打免费模型 ID
    阿里云百炼 华北2（北京）新开通：多数模型各约 100 万 token / 90 天 仅北京地域；主/子账号共享；用完即停要手动开 DashScope 已通 老号额度可能已过期
    火山方舟 每模型一次性约 50 万；签到奖励另计 只抵在线推理；默认关「安心体验」会转后付费 有账号但订阅曾失效 先开安心体验再签到
    百度千帆 ERNIE-Speed / Lite / Tiny 定价 0 需实名，QPS 有限 可配 能力偏轻
    讯飞星火 Spark Lite 永久免费 QPS≈2 可配 只适合极低频
    腾讯混元 Hunyuan-Lite 永久免费 2.0 已停免费 可配 旗舰别指望
    DeepSeek 官方 新用户小额体验（网上说法 300 万/30 天，未核） 之后按量 可配 不是长期免费

    国内优先序：智谱 Flash（长期 0 元）→ 百炼新号 90 天赠额 → 方舟签到 → 硅基只用免费小模型。

    注：本机现有的主力通道是订阅型/自建反代（非官方免费额度，不在此表范围内），但仍是当前主力；本表只列「官方零费率 / 注册赠额」两类真·免费。

    国外（需出海/代理）¶

    平台 可白嫖项 额度/限制 接入 备注
    OpenRouter :free 25+ 个 $0 模型（ID 带 :free） 约 20 RPM / 50 次/天；累计充值 ≥$10 升到 1000 次/天；失败也计数 已有 key 未充值别当生产
    Google AI Studio API Flash / Flash-Lite 免费层（不是 Antigravity 登录） 第三方汇总：3.8/3.6 Flash 约 20 RPD；Flash-Lite 约 500 RPD 官方 key 被封的是 Antigravity 产品线，API key 是另一条
    Groq gpt-oss-120b / gpt-oss-20b / qwen3.8-27b 等 约 30 RPM / 1000 RPD / 20 万 TPD（2026-10-29 文档） OpenAI 兼容 极快；Llama 已不在免费档
    Cloudflare Workers AI 每天 10,000 Neurons，UTC 0 点重置 Free 计划用完即停 可配 计量单位不是 token
    Cerebras 绑支付方式后 $5 / 30 天 无长期免费日额度 可配 「每天 100 万 token」已过时

    不要当成免费的：SiliconFlow 国际站 $1 赠金（一次性）；OpenCode Go（订阅）；Moonshot/智谱付费档 429。

    和本机的配法（11-06 结论）¶

    现行运行时配置（默认模型 / provider / fallback 链）以 [[knowledge/META/current-model-status|当前模型与 API 状态]] 为准；本页只回答「哪里还有官方免费额度」。

    目标 建议
    日常主模型 维持现有主力通道（订阅型，已在跑）
    加一条官方免费兜底 智谱 glm-4-flash（国内直连）或 Groq gpt-oss-120b（海外快）
    要 Gemini 且合法 AI Studio API key，不要再喂 Antigravity 登录
    OpenRouter 只打 :free，当探活/冷备

    复核入口（接入前打开）¶

    • 智谱：https://open.bigmodel.cn
    • 百炼赠额：https://help.aliyun.com/zh/model-studio/new-free-quota
    • OpenRouter 限额：https://openrouter.ai/docs/api_reference/limits
    • Groq 限额：https://console.groq.com/docs/rate-limits
    • Gemini 定价（含免费列）：https://ai.google.dev/gemini-api/docs/pricing
