    墨题口语评测技术参考（webai-realtime-voice-chat 实证）¶

    来源：proj-airi/webai-realtime-voice-chat（AIRI 子项目，ChatGPT realtime voice 完整示例） 研究：k · 2026-08-23 · 基于本地 clone（D:\webai-realtime-voice-chat）源码实证 目标：墨题英语刷题机「口语评测」功能的技术方案参考

    结论置顶¶

    墨题口语评测可直接借鉴 AIRI 的「VAD 本地切分 + ASR 服务器识别 + LLM 评分」三段式： - VAD（Silero，浏览器端免费）解决「学生什么时候开始/结束说话」——录音自动切分，不需要按钮 - ASR 走 OpenAI 兼容 Whisper（墨题已有供应商体系，加一个 transcription 端点即可） - 评分走墨题已有 LLM 链路（口语 = 识别文本 → LLM 按发音/流利度/语法评分）

    项目结构（4 个渐进示例）¶

    App 能力 墨题对应
    vad 仅语音活动检测 录音切分
    vad-asr VAD + 语音识别 口语评测核心（听→文本）
    vad-asr-chat + LLM 对话 口语对话练习（AI 对话）
    vad-asr-chat-tts + TTS 语音合成 完整口语练习闭环

    核心架构（vad-asr 实证）¶

    麦克风 → AudioWorklet (process.worklet.ts)
       → Silero VAD（浏览器端 ONNX，transformers.js）
       → 事件: speech-start / speech-end / speech-ready(buffer, duration)
       → toWav(buffer) 转 WAV
       → @xsai/generate-transcription → ASR 服务器（Whisper）
       → 识别文本 → (墨题) LLM 评分

    关键实现细节¶

    VAD（apps/vad-asr/src/libs/vad/vad.ts）： - 模型：onnx-community/silero-vad（@huggingface/transformers 加载，浏览器端免费） - 关键参数（可调）： - speechThreshold: 0.3（高于此概率=说话） - exitThreshold: 0.1（低于=结束说话） - minSilenceDurationMs: 400（静音 400ms 判说话结束） - speechPadMs: 80（前后留 80ms 防切头切尾） - minSpeechDurationMs: 250（低于 250ms 不算有效语音） - maxBufferDuration: 30（最长 30s 缓冲） - 事件驱动：speech-ready 返回 {buffer: Float32Array, duration}——完整语音段

    ASR（apps/vad-asr/src/pages/index.vue）： - @xsai/generate-transcription（xAI 语音抽象，OpenAI 兼容） - 默认指向 http://localhost:8000/v1/（推荐 Speaches——本地 Whisper 服务器） - 模型：large-v3-turbo（Whisper 快模型） - 也可接任意 OpenAI 兼容 transcription 端点

    WAV 转换（libs/vad/wav.ts）：Float32Array → WAV（16kHz 单声道标准）

    墨题接入方案（三段式）¶

    阶段 1：录音切分（VAD，纯前端）¶

    学生点「口语练习」→ 浏览器麦克风 → Silero VAD
→ 自动检测说话开始/结束 → 得到语音段 WAV
    • 零后端成本（Silero 浏览器端跑）
    • 替代「手动按录音键」——体验提升（自动切句）
    • 代码：抄 apps/vad-asr/src/libs/vad/（vad.ts + manager.ts + process.worklet.ts + wav.ts）

    阶段 2：语音识别（ASR，服务器）¶

    语音段 → 墨题后端 → Whisper（OpenAI 兼容 transcription）
    • 墨题已有 API 供应商体系（记忆：v9.29 手机端 AI 直连）——加一个 transcription 端点
    • 选项：DeepSeek 无 ASR → 用墨题供应商里支持 ASR 的（硅基流动/通义等）或本地 Speaches

    阶段 3：口语评分（LLM，墨题已有）¶

    识别文本 → LLM 评分 prompt（发音/流利度/语法/内容）
    • 墨题 llm-direct.ts 已有精讲/作文/口语链路——口语评分直接复用

    关键决策点¶

    问题 建议
    VAD 用浏览器端还是服务器 浏览器端 Silero（免费+低延迟+隐私）
    ASR 模型 Whisper large-v3-turbo（速度/精度平衡）或墨题供应商 ASR
    离线支持 Silero VAD 可离线；ASR 离线需本地 Whisper（Speaches/whisper.cpp）
    手机端 VAD 是 WASM 可跑（墨题 v9.29 手机端已支持 AI 直连）
    评测维度 发音（音素级需专门引擎）/流利度（语速+停顿）/语法（LLM）/内容（LLM）
