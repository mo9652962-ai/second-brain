    🃏 知识卡片 · 抖音「流量池」不是被证伪，是没人拿得出出处¶

    来源：抖音安全与信任中心（2025 年上线，新浪科技 2025-04-16 报道口径为「近日上线」；确切上线日 03-30 仅见第三方解析，未直读官方公告）· RankMixer 论文（arXiv 2507.15551 v1 2025-07-21 / v3 07-26，CIKM '25 DOI 10.1145/3746252.3761507）· 本次 cron 用 curl 直读 arXiv abs 页逐句核对摘要 一句话：官方公开的是「预测行为概率 × 行为价值权重」这个打分公式和双塔 / Wide&Deep 这些模型示例，从没公开过流量池档位和晋级阈值；网上那套「200-500 播放、完播 45% 进下一池」查不到出处——但「查不到出处」不等于「已被证伪」，把它当平台规则去优化，就是拿假设当目标。

    核心洞察 / 影响¶

    维度 内容
    官方给了什么 推荐优先级 = 综合预测用户行为概率 × 行为价值权重；行为信号含完播、点赞、评论、分享、收藏、关注、划走、不喜欢、回访、相关搜索；分钟级实时更新；双塔召回 / Wide&Deep 排序只是示例，不是完整链路
    官方没给什么 召回有几路、粗排/精排/重排各用什么模型、流量池档位与晋级阈值、任何模型参数/延迟/QPS
    民间说法的问题 「初始池 200-500 播放 → 完播率 45% 晋级」在官方材料与字节论文里均无依据；第三方英文解析页给出过 ≈200-500 这个数，但自己用的是 roughly，且不引用任何官方文档
    证据定级（关键） 「固定流量池规则」= 未知（无公开依据），不是「已证伪」；「早期主要优化完播率、后转多目标」= 官方承认
    工程侧硬证据 RankMixer（CIKM '25）：MFU 4.5% → 45%，参数扩 100× 到 1B，延迟基本不变，1B Dense 版全流量上线，活跃天数 +0.3%、使用时长 +1.08%
    反常识点 参数涨 100 倍、延迟不涨——说明「大模型 = 慢」在精排这一层不成立；真正决定分发的不是池子档位，而是每次请求里这条视频和这个用户的相对排序

    关键数据 · 本次核对的证据分级¶

    档位 内容
    观察 arXiv abs 页 curl 直读 46KB HTML，摘要逐句核对：4.5% → 45%、scale parameters by 100x、roughly the same inference latency、+0.3% active days / +1.08% usage duration 全部在原文
    观察 ACM DL CIKM '25 页面（DOI 10.1145/3746252.3761507）标题与摘要同源，表述为「两个数量级」
    观察 抖音安全与信任中心 trust.douyin.com 在线可访问；官方公式「预测行为概率 × 行为价值权重」经新浪科技 2025-04-16 报道转述（二手，官网正文是 JS 壳，本次未逐字直读）
    推断 「流量池」说法流行的一种解释：曝光曲线在观察上呈阶段性，看起来像晋级——但结果曲线推不出固定晋级机制
    未知 是否存在冷启动分阶段曝光策略：公开材料既不足以证明，也不足以排除
    口径注意 参数扩张倍数：arXiv v3 摘要写 100×，第三方解析写 70×（按 16M 基线 → 1B 实为 ≈62.5×）——引用必须带基线，否则同一个事实能算出三个数

    ✅ 2026-11-06 daily-todo-executor 落实： ① 第 1 条 → 已 patch douyin-ai-practical-video 的「Prompt C：发布前审核」，新增【硬判据·精确数字】四问（出处/样本/时间/适用范围），答不上即判「修改」并降级为假设； ② 第 2 条 → 技能 §8「可依据的优化目标（官方口径内）」已在位（有效停留 + 深度互动 + 标题字幕关键词布局），复核确认； ③ 第 3 条 → 技能 §8「两秒跳出率」已在位（前 2 秒直击痛点/反常识），复核确认； ④ 第 4 条 → 本次新增 §8 条目「引用 RankMixer 数据要带基线（16M → 1B）」，已落。

    为什么重要¶

    • 业务相关性：直接决定抖音起号的优化目标建在官方口径上，还是建在营销号传说上
    • 可行动性：给了可复用的判据（精确数字 → 四问出处），小红书 / 视频号 / 公众号推荐机制传言同款适用
    • 强化自身：这张卡当场纠正了我们自己 11-01 笔记里的过度断言——「证据不足」不能升级成「已证伪」，这是 k 的观察/推断/未知三分法的实战用例

    📱 微信推送版（可直接复制）¶

    抖音「流量池」那套说法，不是被证伪，是没人拿得出出处。

    网上传得最广的版本：新视频先进 200-500 播放的小池子，完播率过 45% 就晋级下一级，一共四级。

    我去翻了官方材料：抖音 2025 年上线了「安全与信任中心」，公开了推荐原理——排序分 = 预测用户行为概率 × 行为价值权重，行为信号包括完播、点赞、评论、分享、收藏、关注、划走、不喜欢、回访、相关搜索，分钟级更新。

    但流量池有几档、多大、阈值多少，官方一个字没给。字节自己的 RankMixer 论文（CIKM '25）也只讲模型：MFU 从 4.5% 提到 45%，参数扩到 10 亿，延迟基本没变，全流量上线后活跃天数 +0.3%、使用时长 +1.08%。

    所以正确的结论不是「流量池是假的」，而是「这个精确数字没人能给出处」。这两句话差别很大：前者是结论，后者是空白。

    空白怎么用？一条判据就够：看到「完播率 45% 进下一池」这种精确数字，先问四件事——出处、样本、时间、适用范围。答不上来，就当假设，别当规则。

    真正能抓的还是官方公开的那部分：有效停留、收藏和长评这类深度互动、标题字幕里的关键词布局。以及你自己 100% 可控的前 2 秒——开头别铺垫，直接抛反常识。

    （数据核对：arXiv 2507.15551 摘要逐句读过；抖音官网是动态页面，公式部分取自媒体转述，标为二手。）
