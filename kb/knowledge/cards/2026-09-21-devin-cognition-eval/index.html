    🃏 知识卡片 · Devin 评估：云端 Agent 适合当「远程执行队员」，不替代 Codex + Hermes¶

    来源：Devin 官方产品页/定价页 + arXiv 2609.17598 独立研究（官方源 / 厂商自报 / 独立研究三级分级）· 2026-09-20 评估，09-21 补选 ✅ 数字已分级，价格易变需购买前复核 一句话：Devin 已成熟到可把边界清晰的工程任务异步丢到云端跑成 PR，但 90 天回滚率 14.5% 高于人工基线，正确用法是「远程执行队员 + 人工审查」，不是无人值守的自动程序员。

    核心洞察 / 影响¶

    维度 内容
    定位 云端异步软件工程 Agent：Issue→PR、代码迁移、补测试、PR 草稿；GitHub/Linear/Jira/Slack 团队集成产品化较完整
    可靠性证据 arXiv 2609.17598 观察 37,623 个 PR（含 4,827 Devin PR）：Devin 90 天回滚率 14.5% vs 人工 11.5%（优势比 1.31）；按行计算的长期维护负担与人工无显著差异（独立研究）
    经验边界 官方：人工约 3 小时能完成且边界清楚的任务，Devin 更可能成功；极复杂任务仍需拆解和接管
    定价 Free $0 / Pro $20 / Max $200 / Teams $80/月起+$40/席；SWE-2 免费到 2026-10-10（官方源，易变）

    关键数据 / 对 sora 的影响¶

    1. ✅ 工具分工矩阵扩展：Hermes（知识/拆题）→ Codex（本地受控执行）→ Devin（云端并行 Issue→PR）→ 人工审查 diff/测试/合并——与现有 Codex 分工互补不冲突
    2. ⚠️ 不交给它的：生产部署/支付/权限/账号迁移/Windows 打包/Android 真机/显卡验证——墨题项目的敏感区几乎全在禁区内
    3. ⚠️ 云端环境与本机不一致（本机无虚拟化、Windows 专属环境）→ 首次试用选独立后端/前端小 Bug + 要求加回归测试
    4. 💡 试用方案：3 个相似任务做 A/B，记录首测通过率/返工时间/改动文件数/实际费用，持续减少返工才扩大使用
    5. 💡 隐私红线：不把私人知识库无差别上传，只传筛选后的约束/AGENTS.md/验收标准

    行动项¶

    • [ ] 墨题项目选 1 个独立小 Bug 试用 Devin CLI（Free 档），跑 3 任务 A/B 四指标
    • [ ] 10-10 前评估 SWE-2 免费窗口是否值得用（Pro 档；官方价格会变，购买前重核对）

    为什么重要¶

    • 业务相关性：直接回答「要不要接入 Devin」——结论明确（当远程执行队员），给 sora 工具选型矩阵加一块拼图
    • 可行动性：试用是「3 任务 A/B 四指标」的具体清单，不是理论
    • 强化自身：官方源/厂商自报/独立研究三级证据分级 = 可复用的工具评估框架（Fusion 数字是厂商自报，不与自家实测混淆）
