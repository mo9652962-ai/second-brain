    Lossless Scaling（无损缩放/小黄鸭）研究（2026-08-18 五轮千轮研究）¶

    Steam ¥29（史低 ¥4），36,665 评测 90% 特别好评 定位: 通用型 AI 插帧 + 超分辨率工具（不挑显卡不挑游戏）

    一、核心结论（先看这个）¶

    ✅ 值得买（¥29 一杯奶茶钱），但别指望救老爷机
✅ 最佳场景: 锁帧游戏 / 老游戏 / 模拟器 / 视频补帧
✅ 4060 用户: 有用但需求有限（4060 本身性能够）
❌ 不能救: 原生帧 <30-45 的游戏（补帧变拖影）
❌ 不适合: GPU 满载的 3A（黑神话悟空类）+ FPS 竞技（延迟）

    二、基本信息¶

    价格: ¥29（史低 ¥4，等打折更好）
评价: 特别好评 90%（36,665 评测）
功能: ① LSFG 帧生成（补帧）② 缩放/超分（提升清晰度）
兼容: 大多数游戏/应用（无内置 DLSS/FSR 也能用）+ 视频播放器
双 GPU: 可把计算转移到副 GPU（核显/第二显卡）
平台: Windows 10 2004+（Linux 有社区移植 lsfg-vk）
限制: 仅窗口化/无边框全屏（独占全屏无效）

    三、技术原理（LSFG 3.x）¶

    原理: 捕获两相邻帧 → 分析像素运动(猜) → 神经网络生成中间帧
      （后处理方式, 没有游戏运动矢量 → 质量不如 DLSS/FSR）
版本: LSFG 3.0（质量/负载/延迟大改进）→ 3.1（AFG 自适应）
负载: X2 比 LSFG2 降 40% / 高倍率降 45%+ / X3 比 X2 高 1.7 倍
延迟: 比 LSFG2 降 24%（40 基础 FPS, X2）
倍率: 最高 X20（3X+ 需锁帧避免 GPU 满载）
基础帧: 1080p 至少 30（推荐 40+, 理想 60）；<10 FPS 自动禁用

    四、关键设置（4060 推荐方案）¶

    帧生成: LSFG 3.x + 自适应模式(AFG) → 目标=显示器刷新率
        （或固定 2 倍，别超 2.5 倍否则果冻）
缩放: FSR（锐化自然，N/A 卡通用）或 LS1（现代 3D 首选）
     Anime4K(动漫) / Integer,xBR(像素) / NIS(老 N 卡)
效能模式: 强烈建议开启（降延迟最有感）
捕获 API: Win10 用 DXGI / Win11 24H2 用 WGC
队列目标: 0（低延迟）/ 1(默认) / 2（高稳定）
最大帧延迟: 1-5（低=低延迟高抖动 / 高=稳定高延迟）
同步: 预设（推荐）/ 关闭（最低延迟，目标退 3 帧）
N 卡控制面板: 低延迟模式=开启（别用超高, 会限 90% GPU）

    五、竞品对比¶

    方案 适用 质量 延迟 价格
    Lossless Scaling 任何游戏/显卡/视频 中（AI 猜运动） 高（2x 约 99ms） ¥29
    DLSS 3/4 支持的游戏 + RTX 最高（运动矢量） 低（59ms） 免费
    FSR 3 支持的游戏 高 低 免费
    AFMF 2 A 卡/APU（驱动级） 高（低基础帧更干净） 低 免费
    Magpie 开源免费（纯缩放无补帧） 缩放不错 — 免费
    SVP4 Pro 视频补帧专用 好 — 付费 
    关键: 有 DLSS/FSR 支持的游戏 → 优先游戏内置（LS 增加延迟伪影）
     没内置支持/锁帧游戏 → LS 是值得的选择

    六、适用场景（sora 的 4060 + 游戏）¶

    场景 是否适用 说明
    骑砍2 战团（老游戏） ✅ 超分/补帧 老游戏锁帧/低分辨率 → 提升明显
    骑砍2 战场掉帧 ✅ 补帧 千人战场 CPU 瓶颈 → 抹平 Low 帧卡顿
    Sims4（模拟器类） ✅ 补帧 CPU 单核瓶颈掉帧 → 抹平卡顿
    inZOI ❌ 不推荐 自带 DLSS FG(烂)+FSR3; 4060 8GB 显存紧张(需9GB); 正确=DLSS超分+关FG+锁帧
    视频补帧（24→48fps） ✅ 固定 2 倍模式
    黑神话悟空类满载 3A ❌ GPU 满载无闲置机能 
    4060 实测参考（少数派）:
  赛博朋克 2077: DLSS 帧生成 91.9→142（4060 用 DLSS 更好）
  黑神话悟空: 显卡满载 → 小黄鸭无效
  4060 有闲置机能(70-85% 利用率)时 → 小黄鸭可补

    七、购买建议¶

    ① 29 元可买（或等史低 4 元）
② 买完先试: 骑砍2 战场掉帧场景 + 模拟器
③ 设置: AFG 自适应 + 效能模式 + FSR 缩放 + DXGI
④ 记住红线: 原生帧 <45 不开帧生成 / FPS 竞技不开 / GPU 满载不开
