    SOP-008: 闲鱼高交互个人主页/作品集定制交付全流程¶

    核心目标：打破 30~50 元作业/PPT/论文代做的低价内卷，开辟 398~898 元高客单、低交付摩擦 的 Web 定制业务。 标准工时：1.5 ~ 2 小时 / 单，毛利率 > 90%。

    一、服务阶梯定价矩阵 (SKU 设计)¶

    版本名称 标价 目标客群 包含交付物 预计耗时
    L1 极简展示版 ¥398 求职者、程序员简历、小工作室展示 5段式自适应单页 + Netlify/Vercel 全球极速部署 + 永久免服务器费用 + 基础响应式 1.0h
    L2 沉浸动效版 (主推) ¥598 UI/3D 设计师、插画师、独立创作者 L1 全部 + 3D 鼠标跟随/视角追视 + React Bits 高级交互动效（水波/磁性按钮/卡片 3D 悬浮） 1.5h
    L3 商业后台版 (高客单) ¥898 摄影师、小型品牌、需要频繁更新作品的创作者 L2 全部 + 可视化后台管理系统 (/admin)（自己能上传图片、改文字、拖拽调顺序，无需改代码） 2.0h

    二、闲鱼上架文案模板（防违规 + 转化钩子）¶

    1. 商品标题 (30字极限打满)¶

    网页制作定制 个人作品集开发 3D交互主页 设计师简历 前端免服务器建站

    2. 首图与主图建议 (6张)¶

    • 图 1 (主封面)：高颜值深色/水墨主页在 MacBook + 手机的真机模型图（Mockup），大字写：“个人作品集/开发者主页定制 · 终身免服务器 · 自带后台”；
    • 图 2 (功能特点)：3D 鼠标追视 + 磁性交互动态 GIF / 静态分解；
    • 图 3 (客户痛点对比)：传统外包（要买服务器每年几百/改个图要加钱） vs 我们的方案（0 服务器费/带后台自己改）；
    • 图 4 (真实案例预览)：展示 5 段骨架（头图/关于/分类/详情/页脚）；
    • 图 5 (后台管理界面)：展示拖拽排序与图片上传界面；
    • 图 6 (买家须知与流程)：沟通需求 $\to$ 拍下 $\to$ 出预览链接 $\to$ 确认满意 $\to$ 交付源码与后台。

    3. 详情页文案 (直接复制)¶

    【专业做高审美·可交互的个人主页与作品集】
适合：UI/视觉/3D设计师、摄影师、独立开发者、考研求职简历、小型工作室。

💡 为什么选择我们？
1️⃣ 【终身 0 服务器成本】：
传统建站每年要交几百块服务器和域名费。我们采用全球顶级 CDN 托管（Netlify/Vercel），赠送极速访问二级域名，支持绑定自有域名，一分钱服务器费都不用交！

2️⃣ 【自带管理后台，拒绝后期二次收费】：
很多买家最怕做完网站后，以后加个新作品又要找人花钱改代码。
我们赠送可视化后台（手机/电脑打开就能用）：上传图片、修改介绍、拖拽调整顺序，前台实时同步更新！

3️⃣ 【现代高交互体验】：
拒绝千篇一律的死板模板！支持 3D 鼠标跟随视线、卡片立体倾斜、流畅滚动转场、平滑水波微动效。

📋 制作流程：
1. 发送您的参考风格/喜欢的网址或想法；
2. 提供文字与作品图片素材；
3. 拍下对应版本，最快当天出公网预览链接；
4. 满意后交付源码包 + 部署权限 + 后台管理账号。

价格透明，拍前请先咨询聊聊～

    三、接单前深度对齐（Grill 沟通 4 问）¶

    接单前严禁直接开工，必须通过 4 个问题锁死边界，拒绝抽象扯皮：

    1. “您这个网站的主要用途是？”
    2. 选项：设计师求职作品集 / 独立开发者展示 / 摄影约拍主页 / 品牌小官网。
    3. 目的：明确核心重点是视觉展示还是联系方式线索。
    4. “有没有您特别喜欢或想参考的现成网站（给 1~2 个链接或截图）？”
    5. 红线：绝不接受“我要高级感/大气点”这种模糊词；让买家发具体参考图或从 motion.site / reactbits.dev 中挑一个动效。
    6. “文案和作品图准备好了吗？”
    7. 要求：让买家打成一个压缩包，按“关于我 / 作品 1 / 作品 2 / 联系方式”建文件夹发过来。
    8. “是否需要自己后续频繁加作品？”
    9. 分流：不需要改动 $\to$ 推 ¥598 动效版；需要频繁改 $\to$ 推 ¥898 后台版。

    四、标准化极速生产流水线 (2小时交付 SOP)¶

    [1. 骨架确立 (10m)] ──> [2. 素材规整 (15m)] ──> [3. Codex 派活 (30m)]
                                                      │
[6. 极速交付 (10m)] <── [5. Netlify 部署 (10m)] <── [4. 交互打磨 (25m)]

    Step 1: 确立 5 段结构¶

    固定使用标品骨架： Hero (3D追视/主标语) -> About (经历卡片) -> Categories (折叠/分类) -> Showcase (网格作品) -> Footer (联系)。

    Step 2: 素材规整与参考对齐¶

    • 客户若有肖像照，用即梦/SD 生成 3D 角色卡（锁脸提示词保证一致性）；
    • 选定 React Bits 的 1 个核心动效（如 Card 3D Tilt 或 Spotlight Card）。

    Step 3: Codex 结构生成¶

    直接派活模板：

    “使用单个 HTML 文件（内嵌 Tailwind / Vanilla CSS 与原生 JS），根据上传的素材目录，构建一个现代暗色风格的响应式作品集单页。包含：Hero 视差首屏、About 时间线、Showcase 响应式图片瀑布流、Footer 复制邮箱与社媒卡片。参考上传图片的配色方案。”

    Step 4: SRP 小步微调¶

    • 轮次 1：修布局、图片比例自适应（object-fit: cover 防止拉伸白边）；
    • 轮次 2：接入交互事件与动效；
    • 轮次 3：挂载轻量 LocalStorage CMS 后台（/admin）。

    Step 5: Netlify / Vercel 免费托管¶

    • 直接使用 Netlify 拖拽文件夹（Drop to deploy）或通过 GitHub 仓库关联；
    • 30 秒生成 https://[client-name].netlify.app。

    Step 6: 交付物核验清单¶

    • [ ] 手机竖屏浏览器实测（弹层无遮挡、汉堡菜单正常）；
    • [ ] 桌面端 Chrome 实测（动效帧率稳定 60fps、无控制台报错）；
    • [ ] 后台 /admin 新增一条测试数据，前台确认能实时更新；
    • [ ] 交付说明文档（告知后台登录方式与如何修改密码）。

    五、风控与防退款红线¶

    1. 坚持平台交易：所有沟通与确认均在闲鱼应用内留痕，不脱离平台支付；
    2. 预览确认门禁：先给 Netlify 临时公网链接预览，买家确认“外观与功能无误”并确认收货后，再发送源码压缩包与后台最终管理权；
    3. 修改次数声明：详情页与聊聊中明确“基于确认的参考风格免费微调 2 次细节，不支持无故推翻风格重做”。
