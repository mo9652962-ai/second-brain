    「Agent 操作系统之争」B 站初稿（第 1 期候选）¶

    选题来源：[[agent-os-harness-trend-2026-08-22]]（8/22 研究素材） 定位：实战派 AI 自动化区 · 冲突叙事 + 硬数据 + 个人实战 状态：🆕 初稿（约 1700 字，配口播 5-6 分钟）· 待 sora 审校选标题 存稿日期：2026-08-23

    封面文案（大字）¶

    • 主标题：Agent 操作系统之争
    • 副标题：DeepSeek vs OpenAI 同时开源
    • 数据钩子：ARC-AGI-3：13.3% → 38.3%

    口播稿¶

    开场（15 秒，冲突钩子）¶

    两周之内，DeepSeek 和 OpenAI 几乎同时开源了同一个东西——Agent 的运行框架。DeepSeek Harness，12 小时破 5 万星，现在已突破 20 万星（8/31 实测 204K+，8/23 时 95K+）；OpenAI 也把 Codex 的底座全部开源。很多人说这是巧合，但我看完两边架构，结论是：这不是巧合，是行业共识落地了——模型能力的红利在递减，下一个战场是 Agent 的"操作系统层"。

    什么是 Harness（45 秒，概念）¶

    先说人话。模型是大脑，Harness 是让大脑有手有脚、有记忆有门禁的运行环境。裸模型不是 Agent，模型 + Harness 才是。

    你平时用的所有 AI 工具，背后都是这一套：管上下文怎么装、工具怎么调、失败怎么恢复、权限怎么控、干过的活怎么审计。以前这是各家产品的黑盒，现在被抽出来变成开源平台——就像当年操作系统从每台电脑里抽出来变成 Windows 一样。

    为什么现在清晰了（60 秒，数据说话）¶

    三个原因。

    第一，模型的边际收益递减了。OpenAI 官方数据：只调 Harness，不换模型，ARC-AGI-3 从 13.3% 涨到 38.3%，三倍；输出 Token 省了 6 倍。模型没换，工作方式换了，能力就变了——这说明什么？说明竞争已经不在"谁的模型强"，而在"谁能把模型组织成可靠的工作系统"。

    第二，企业要长任务。让 Agent 连续干几个小时、跨上下文窗口干活，需要状态持久化、验证循环、失败恢复。这些模型本身给不了，全是 Harness 的活。

    第三，安全可控。Agent 有文件权限、Shell、网络、凭据——没有沙箱和审批，谁敢让它上线干活？

    DeepSeek 路线（60 秒，赛博乐高）¶

    DeepSeek 的答案是"一切皆插件"。模型是插件、工具是插件、Skills 是插件、连 Agent Loop 本身都是插件。内核只干一件事：插件加载、卸载、依赖管理。插件卸载的时候，注册效果按反序回滚，服务不中断。

    最狠的是 Append-only Session Log——模型看到的一切，思维链、工具调用、子 Agent 调度，全部写进同一个事件流，可以搜索、分叉、回放。等于给 Agent 装了"行车记录仪"。

    OpenAI 路线（45 秒，平台开放）¶

    OpenAI 的答案是"平台开放"。把 Codex 底座开源成 CLI、SDK、App Server 三大件，Apache-2.0 协议，让业务系统直接嵌入。走的是当年 iOS 的路——我不但给你系统，还给你开发工具。

    两条路线，一个方向：Harness 是新的竞争层。

    我的实战（45 秒，差异化）¶

    说点我自己的。我日常用 DeepSeek Harness 做编码委派——headless 一次性任务、Web UI 插件生态、沙箱权限配置、跨 Agent 记忆。最直观的感受是：换一个 provider，整个产品形态跟着换。插件化让 Agent 不再是死配置，而是可以拼装、可以演进的东西。

    风险泼冷水（30 秒，深度）¶

    但我也要泼盆冷水。插件生态的供应链安全是个大坑——恶意插件能碰你的上下文、文件、Shell、凭据；长会话的预算失控也是真实问题。而且今天 Harness 补模型的短板，未来部分能力会被模型吸收掉。所以别追概念，要追落地。

    结尾（15 秒）¶

    一句话总结：Agent = Model + Harness。模型决定下限，Harness 决定上限。 关注我，下期拆 DeepSeek Harness 的插件架构到底怎么设计的。
