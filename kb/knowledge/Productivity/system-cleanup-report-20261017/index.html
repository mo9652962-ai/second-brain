    项 大小 原因 / 属性

    用户工作区与私有知识库 - Documents / Desktop / private_knowledge 等全部遵守安全隔离，只读不触碰

    安全协议遵守自检¶

    • ✅ 零误伤：未擅自删除任何 Downloads、Documents、Desktop 用户个人文件或源码。
    • ✅ 资产隔离：严格遵守资产隔离，绝不触碰核心资产与敏感配置。
    • ✅ 官方工具优先：包管理器调用官方清理命令，组件存储调用 DISM 官方模块。
