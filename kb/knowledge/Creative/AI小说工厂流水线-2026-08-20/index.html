    AI 小说工厂流水线（摸鱼大法师 · 抖音 2026-08-20）¶

    来源：抖音 @摸鱼大法师🐟《写小说开工厂了，AI流水线全自动一条龙》（36 秒演示，429 赞） 标签：#ai工具测评 #网站推荐 #写作 状态：✅ 已定位（2026-08-20 网络恢复 + SenseVoice 增强转写后实证研究）

    视频核心信息¶

    一个开源 AI 小说生产工作流——把「写书那点事」拆成流水线，用户不用动技术，选一条线剩下全是 AI 的事。

    流水线组成（SenseVoice 增强转写提取，错字已修正）¶

    环节 说明
    世界观构建 设定生成
    角色创建 人物卡
    章节生产 32 个节点全接好，单章全自动
    大纲规划 全文大纲
    章节润色 正文优化
    章节后验 质量把关
    故事规划 剧情走向
    • 七条产线全给（用户自选）
    • 36 个小说专家（prompt/agent 角色：设定/角色/伏笔/人设专人负责）
    • 34 维度设定——写几十万字不崩（视频原话「四维度设定」口误可能）
    • 开源不花一分钱，开箱直接用

    📊 实证定位（2026-08-20 千轮研究）¶

    结论：视频演示的「7 条产线」最匹配 xindoo/sumeru（须弥写作），「32 节点」是 Coze 工作流风格话术——大概率作者把类 sumeru 思想做成了 Coze 工作流或直接演示 sumeru。

    实测结构核验（2026-08-20 clone 4 个候选）¶

    项目 语言/形态 大小 依赖 运行
    sumeru 纯 Skills 包（CLAUDE.md+skills/） 323K Python 3.11+ / Node 20（部分脚本） Claude Code/OpenCode 加载；⚠️ 声明 macOS/Linux zsh
    ainovel-cli Go（修正：不是 Python！） 15M Go 构建 or 官方 release 二进制 ainovel-cli 一键安装/Docker；Windows 有 release
    ai-novelist Claude Code 版 14M（含样例小说） Node Claude Code 加载，有 novels/ 样例
    LangGraph 版 Python + langchain/gradio 7M langchain 全家桶（重） python app_gradio.py，本地+API 双模式

    结论：视频「7 条产线」= sumeru 7 模块（高度吻合）；ainovel-cli 最火最成熟（Go 全自动引擎）；LangGraph 版依赖重价值低。

    Coze 工作流侧（「32 节点」佐证）¶

    • 掘金/B站大量 Coze 小说工作流教程（10-30 节点，循环节点破解「AI 失忆症」）
    • 「32 个节点全接好」= Coze 节点式工作流（开始→大纲→循环→批处理→结束）
    • 与视频「选一条线，剩下全是 AI 的活」的 Coze 交互一致

    与 sora 现状对照¶

    • 已有 novel-worldbuilding 技能（网文/小说世界观设定方法论：5问框架/力量体系）——sumeru 的 worldbuilder 思路相通
    • sora 是 AI 博主（AI 自动化 6 领域）——「AI 小说流水线」是现成内容素材（拆解 sumeru 7 模块 or ainovel-cli 多 agent）
    • 闲鱼变现角度：AI 小说代写/网文工业化是热门需求，可作服务线备选

    可操作下一步（按需）¶

    1. git clone https://github.com/xindoo/sumeru 实测（Claude Code/OpenCode 技能包——sora 有 Claude Code 技能）
    2. 或 clone voocel/ainovel-cli（1739★ 全自动，Python 引擎）
    3. 产出 AI 博主内容：拆解「AI 小说工厂」架构（7 模块 vs 多 agent）
