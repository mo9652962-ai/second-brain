    SRC 挖洞系统性知识体系（2026-08-18 六轮千轮研究）¶

    覆盖：信息收集 / 漏洞挖掘 / 工具链 / 实战方法论 / 报告提交 / 平台合规 技能：src-bug-hunting（配合使用） 目标：从「新手」到「能稳定出洞」的完整作战手册

    一、信息收集体系（挖洞 70% 的时间）¶

    标准流程¶

    ① 子域名: OneForAll(全但慢) + subfinder(快) + httpx 存活
② 端口: 全端口(晚上挂) + 常见服务(白天) → 关注非标准端口
③ 指纹: EHole + httpx -tech-detect + wappalyzer
④ 目录: dirsearch + 定制字典(springboot/swagger 路径)
⑤ JS 提取: katana/Link/JSFinder → 接口+密钥
⑥ 资产归属: 企查查/天眼查/爱企查(股权穿透+小程序/公众号/APP)
⑦ 供应链: FOFA cert= / icp= 反查 + favicon hash 横向

    扫描前探针（10 秒省几小时）¶

    先发 5-10 个随机路径（/asdfqwertasdf12345）看 404 是否一致:
  一致 = 扫描模型成立，可以扫
  不一致 = 软 404，需内容指纹二次过滤
  全 403 = WAF 统一拦截，别扫了转旁路

    边缘端口清单（藏宝区）¶

    Nacos 8848 / Apollo 8070 / SkyWalking 8080 / Sentinel 8080
XXL-Job 8080 / Druid 监控 / Spring Boot Admin / JMX 1099
Jenkins 8080/50000 / ES 9200 / Docker 2375 / K8s 10250
pprof 6060 / Prometheus 9090 / Redis 6379 / Mongo 27017

    指纹关联（效率最高的横向发现）¶

    favicon hash 一致 = 同一套部署模板
自研前端指纹(JS文件名/CSS class/meta) → FOFA 搜 → 全出
自研网关响应特征(自定义Header/错误结构) → 横向搜
证书 SAN 字段 → 内部域名清单

    二、漏洞挖掘体系（全谱）¶

    新手 5 种（当天出成果）¶

    ① 信息泄露: F12/JS/敏感文件 → 手机号/邮箱/身份证
② 未授权访问: 域名加 /dashboard /admin /api /actuator
③ 弱口令: admin/admin 等（针对性: 公司缩写+年份）
④ SQLi: 参数加单引号 → 英文错误提示
⑤ 任意密码重置: 抓包改 username/手机号（红线: 只证明不改）

    2026 最快 P1 的 5 个点¶

    ① Actuator heapdump → 数据库密码/云密钥/JWT密钥
② Nacos 未授权 → 配置全暴露
③ 旧版接口 (v1/v2) → 全量用户
④ 测试环境 (dev/test/pre) → 全是漏洞
⑤ 云存储密钥 (OSS/COS/OBS) → 直接读写

    逻辑漏洞全谱（高价值）¶

    支付: 改价/负数/拆分/续费/优惠券(并发/他人券)
验证码: 删除code字段/不绑定/可爆破/可复用
越权: 改ID看他人数据/返回包数组空=可能越权
条件竞争: 一次领取多次到账
注册覆盖: 注册已有账号=覆盖登录
重放: 邀请链接无限刷VIP

    核心心法¶

    抢洞优先级: 未授权 → 信息泄露 → 越权（避开 XSS/URL 跳转）
登录后的漏洞重复率比登录前低 → 挖深层次
80% 漏洞是别人漏掉你捡的 → 边缘资产/全端口/特殊字典

    三、工具链体系¶

    Burp 插件矩阵（捡洞神器）¶

    ssrf-King: 自动 SSRF 检测（配合 Collaborator）
inql: GraphQL 测试（自动生成请求包）
Autorepeater: 越权/未授权（自动替换 token 比对包大小）
routevulscan: 批量敏感目录递归检测

    Nuclei 踩坑全记录¶

    模板: 大陆网络下载失败 → git clone nuclei-templates 到 ~/.nuclei-templates
限速: 默认 150 并发会封 IP → -c 30 -rate-limit 30
输出: 要 -json 标志才写 JSON
DNS: -smart-dns-cache 提速 39%
标准: nuclei -u target -c 30 -rate-limit 30 -json-export out.json -irr -persist

    其他关键工具¶

    sqlmap: --dbs → --tables → --dump → --os-shell（红线: 只证明）
dirsearch: -e php,html,txt + 定制字典
ffuf: 高速 Fuzz
Crawlergo+Xray: 动态爬虫+被动扫描（挂机流水线）

    四、实战方法论¶

    CDN 绕过 3 法（纯公开信息）¶

    ① crt.sh 证书透明度: 含过期证书 → 找 origin/backend/direct 域名
   → 证书指纹去 FOFA 搜 cert="指纹" → 关联所有 IP
② DNS 历史: SecurityTrails/ViewDNS → 三个月前解析的 IP
   → TXT/MX/NS 记录也可能泄露
③ HTTP 响应头指纹: 错误页面一致 = 同一台服务器
   → FOFA 组合语法精准定位

    WAF 绕过¶

    路径混淆: %20 / %09 / /./ / /../ / /..;/ 绕过 90% 入门 WAF
请求方式: GET→PATCH→PUT→OPTIONS
缩短 payload: ShortPayload 项目
burp 特征被识别 → 用 yakit 或 burp-awesome-tls 插件

    快速判定 10 秒¶

    删 Token/Cookie → 200 出数据 = 未授权
访问 /actuator/env /doc.html /nacos
扫非标准端口（组件默认口令/未授权）
JS 搜 key/secret/token/ip/url
Host 碰撞: IP+Host头直接访问

    捡漏策略（SRC 80% 靠捡）¶

    别人扫 Top1000 你扫全端口
别人跑通用字典你上边缘资产专用字典
别人忽略 404 页面你截包看响应体
组合 FOFA 语法: 交叉验证比扫得猛强

    五、报告与提交体系¶

    报告 6 要素（清晰/完整/可复现）¶

    标题/类型/影响范围/复现步骤/截图证明/修复建议

    四维提升法（AI 润色，通过率 50%→80%）¶

    ① 攻击链具象化: "攻击者可批量遍历 userId 获取 12 万条数据"
② 业务影响量化: "罚款上限 5000 万 / 潜在赔偿 6000 万"
③ 攻击链串联: 中危+中危 = 严重
④ 修复方案具体化: 代码级建议

    三条黄金法则¶

    人工审校（AI 可能脑补）/ 适度包装禁止造假 / 附带验证截图

    审核判定三维模型¶

    风险杀伤链（能否完整利用）
攻击熵增效应（远程非接触 > 需社工）
资产腐蚀面（全局鉴权绕过 > 单页面）

    六、平台与合规体系¶

    平台对比¶

    漏洞盒子: 新手最友好, 无权重, 审核 3-7 天, 现金+积分
补天: 厂商多, 权重≥1(edu/gov 免费), 审核 1-3 天, 现金+KB
漏洞银行: 新手专区, 专人指导
字节 SRC: 新人奖励, 反馈快
京东 SRC: 公开报告质量高, 可学习
大厂(阿里/腾讯): 奖金高, 竞争激烈, 适合进阶

    奖金参考（各平台综合）¶

    严重 1万-50万+ / 高危 1000-10万 / 中危 300-5000 / 低危 50-300

    法律红线 3 条（不可触碰）¶

    ① 未授权测试 = 违法（网络安全法 27 条: 扫描探测都算）
   处罚: 5-15 日拘留 + 5-100 万罚款
② 超范围测试 = 违法（授权范围/时间/方式三个维度）
③ 私下交易漏洞/恶意披露 = 违法（提供工具罪/泄露数据罪）

    授权要素（合法测试三确认）¶

    范围: 具体域名/IP/端口
时间: 明确起止
方式: 允许的测试手段（禁 DDoS/爆破）

    即使有授权也不能碰¶

    拖库/批量读真实数据/下载源码 → 非法获取数据罪
植入后门/删除篡改数据/DoS → 破坏系统罪
内网横向渗透未授权系统 → 非法控制罪
钓鱼社工 → 诈骗/侵犯公民信息
未修复前公开漏洞 → 寻衅滋事/侵犯商业秘密
留存测试数据 → 测试后 24h 内删除

    七、新手成长路径（3 阶段）¶

    阶段 1 (0-1月): 第三方平台入门, 信息泄露/未授权/弱口令
   → 目标: 3-5 个有效漏洞, 建立信心
阶段 2 (1-3月): 逻辑漏洞/中危, 工具联动
   → 目标: 稳定出洞, 提高通过率
阶段 3 (3月+): 云原生/AI安全, 头部厂商
   → 目标: 冲击高危, 内推机会

核心: 每天 1-2 小时, 坚持 1-2 个月 = 稳定挖到低危
