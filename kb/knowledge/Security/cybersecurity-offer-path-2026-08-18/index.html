    双非本科网络安全 Offer 路径研究（2026-08-18）¶

    来源：白帽小七抖音视频（双非本科拿下网络安全offer）+ 3 轮千轮研究 视频信息：点赞 744 / 评论 48 / ID 7673084661827915059

    〇、博主原话（whisper 转写，核心观点）¶

    「很多人学网络安全就是今天装个 Kali 明天跑个脚本，
  到最后只会当个脚本小子，原理一问三不知」
「别被网上那些三天入门黑客五天拿 offer 的标题党带歪了」
「要真想入行网安并入职好公司，一般人没有三个月的沉淀根本行不通」
「我从入门到拿下渗透测试岗 offer 用了整整六个月时间」

三个月真实学习路线（每天固定 2 小时）:
  第 1 月: 基础理论——网络协议/操作系统原理/Web 安全基础
          (HTTP 请求包、TCP 和 UDP 区别、SQLi/XSS 是什么、
           工具怎么配置、攻击链怎么设计)
          刷 CNVD/CVE 漏洞公告 + FreeBuf/C Bug 技术博客
  第 2 月: Web 核心攻防——OWASP Top 10 漏洞原理 + 渗透测试流程
          用黑客视角构造稳定 payload
          理解绕过技术: 怎么绕 WAF/权限提升/内网渗透/横向移动框架
  第 3 月(重中之重): 产出完整渗透测试报告
          选靶场或 SRC 实际挖 2-3 个漏洞
          从信息收集到漏洞利用最后附修复建议 → 写出专业报告
          「学到这，你才具备拿下一个网安 offer 的能力」

结尾: 「90% 的人都只停留在现成的 POC 脚本，
       宁愿相信一个注入工具打，也不愿意去抠底层原理」

    对照启示¶

    • 博主 6 个月路线 = 你正在走的路径（DVWA 三档 + SRC 实战 + 报告）
    • 「挖 2-3 个漏洞 + 专业报告」= 你的目标站点 signkey 第 1 个正在做
    • 「别当脚本小子」= 你学了三档绕过原理（不是只跑工具）✅

    一、双非进大厂的真实路径（案例）¶

    案例 路径 关键点
    普通本科→腾讯云鼎 弃CTF → 2000h系统课程 → 3段实习 → 秋招30w+ 系统学习+实习积累
    双非26秋招 10+实习(小米/海康/美团) → 华勤/小鹏/美团 广撒网实习
    双非→鹅厂 三次投递坚持 心态

    共性: 双非不是原罪, 但要更主动 + 实习是最好跳板 + 项目经验比文凭有说服力

    二、核心技能（2026 蓝队/SOC 视角）¶

    系统管理(动手搭/搞坏/修复) / 日志分析 / 脚本编程(选一门)
理解攻击者行为 / 网络与流量分析 / 写作能力
实验环境(家庭实验室) 是简历最大加分项之一

    三、证书体系（敲门砖非万能钥匙）¶

    在校生: NISP二级 (校园版CISP, 毕业可换CISP, 性价比最高)
在职:   CISP (需学历+工作经验)
渗透:   CISP-PTE (实战导向, 条件宽松)
优先级: OSCP > CISSP > CISP-PTE > CEH
关键: 证书提供学习结构, 实战经验才是决定因素

    四、SRC 经验 → offer 竞争力（核心转化方法）¶

    简历量化（STAR 法则）¶

    ❌ "会挖 SRC 漏洞"
✅ "在 EDU SRC 挖掘 13 个高危漏洞（10 未授权 + 3 SQLi），
    协助 2 所高校修复，避免 5000+ 条学生敏感信息泄露"
✅ "在 SRC 平台提交 XSS 漏洞 1 个，被某知名互联网公司确认并收录"

    面试话术（讲过程 > 讲工具）¶

    ❌ "我用 Burp 挖到的"
✅ "先梳理系统架构，发现成绩查询模块公开访问，抓包发现学号参数未过滤，
    构造 SQLi payload 被 WAF 拦截，改用数字型 + 注释符混淆绕过"
✅ 补一句复盘: "整理了《高校系统常见漏洞防御指南》分享给同学"

    加分项（写最显眼位置）¶

    典型案例 / 优秀白帽称号 / 漏洞证书 / SRC 平台排名(补天/漏洞盒子)
CTF 获奖 / 开源安全工具(GitHub stars) / 安全博客

    阶段路线¶

    0-1月:   靶场练习 + 提交低危(反射XSS/弱口令) 建立信心
1-3月:   逻辑漏洞 + 中危 Web 漏洞 + 工具联动
3月+:    云原生/AI安全新兴漏洞 + 头部SRC + 高危冲击 + 内推机会

    五、EDU SRC 挖洞要点（新手最快战绩来源）¶

    工具: FOFA/ZoomEye 搜 edu.cn 域名
新手洞: XSS(留言板/搜索框) / 越权(改学生ID) / 弱口令(admin/123456)
高价值: 未授权访问 / SQL注入 / 逻辑漏洞(奖学金/评优系统改参数)
报告 4 点: 漏洞在哪+影响多大+怎么复现+怎么修复

    六、简历检查清单¶

    求职意向与岗位匹配 / 实战经验放核心位置(50%+) / STAR 量化
技能分类(熟悉/掌握/精通) / 证书单列 / GitHub+CTFtime 链接
排版 1-2 页 / PDF 格式 / 文件名: 姓名-岗位-学校-简历

    七、对本项目的启示（sora 路径对照）¶
