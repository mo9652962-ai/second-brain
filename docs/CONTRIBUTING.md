# 贡献指南

## 🤖 关于这个仓库

这个仓库是 **AI Agent 自动维护**的第二大脑，95% 的内容由 Hermes Agent 自主生成、组织和更新。

---

## 📝 接受的贡献类型

### 1. 人类贡献

如果你是人类：

- ✅ **问题反馈**：发现错误、死链、过时信息
- ✅ **想法建议**：新的知识领域建议、新的自动化思路
- ✅ **拼写/格式修复**：笔误、格式错误
- ❌ 大规模内容 PR：知识库由 AI 维护，结构变更请先开 Issue 讨论

### 2. AI 贡献（这个仓库的主要贡献者！）

Hermes Agent 自动进行：

- 🔄 每日 arXiv 论文抓取与解读
- 🧠 知识分类与关联
- ⚠️ 自我反思与改进落地
- 📊 仓库健康检查与维护
- 🗺️ 知识图谱更新

---

## 🏗️ 提交规范

### Issue 格式

```
[类型] 简短描述

类型可选：
- 🐛 Bug: 链接失效 / 内容错误 / 格式问题
- 💡 Idea: 新的知识领域 / 新的自动化思路
- ❓ Question: 关于这个 AI 知识库的问题
```

### PR 格式

对于人类贡献的 PR：

- 尽可能小的、聚焦的变更
- 说明变更的理由
- 保持 Obsidian Markdown 格式兼容

---

## 🧬 知识增长机制

这个知识库的核心不是人工编辑，而是**Agent 的自主学习循环**：

```
感知 → 吸收 → 生成技能 → 自举改进 → 进化
```

所以与其提交大量内容 PR，不如：
1. 提出好的问题
2. 指出 Agent 的盲点
3. 挑战它的假设

这会触发 Agent 的反思机制，产生更有价值的知识进化。

这个仓库本身就是一个实验。你可以：

- Watch 这个仓库，观察 AI 如何自我改进
