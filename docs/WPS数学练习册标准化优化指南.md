## 3. 段落格式优化

### 3.1 行距设置

| 内容类型 | 行距 | 段前 | 段后 |
|---------|------|------|------|
| 主标题 | 1.5倍 | 0.5行 | 0.3行 |
| 板块标题 | 固定值20磅 | 0.3行 | 0.1行 |
| 口算题目 | 固定值18磅 | 0 | 0 |
| 竖式计算 | 固定值22磅 | 0 | 0 |
| 分数口算分子/分母行 | 固定值16磅 | 0 | 0 |
| 分数分数线行 | 固定值14磅 | 0 | 0 |

**WPS操作步骤：**
1. 选中段落 → 右键 → [段落]
2. 选择 [行距] 选择对应类型，输入数值
3. 输入段前/段后间距
```

### 3.2 缩进设置
```
首行缩进: 0字符（题目不缩进）
左缩进: 0.5字符（使题目整体右移一点）
```

## 4. 分数竖式格式精修

### 4.1 使用WPS公式编辑器（推荐）Alt+=）

**步骤：**
```
1. 光标放在要插入分数的位置
2. 按快捷键 Alt + = 调出公式编辑器
3. 点击 [设计] 菜单
4. 选择 [分数] → [竖式分数（上）
5. 输入分子和分母
6. 在分数后输入减号、等号
7. 重复以上步骤
```

**效果：
```
  8     7
 ─── - ─── = 
 10    10
```

### 4.2 分数对齐技巧

```
选中分数格式设置：
```
1. 选中所有分数
2. 右键 → 字体 → 高级
3. 位置：标准
4. 间距：标准
5. 如果分数线不齐，可以使用公式编辑器重新编辑

## ⚡ 快速优化技巧

### 技巧1：使用格式刷批量应用
```
1. 选中已经设置好的段落
2. 双击格式刷（双击是连续应用，单击是一次）
3. 点击要应用的段落
4. 全部应用完后再点击格式刷取消
```

### 技巧2：使用样式管理器
```
1. [开始] → [样式]
2. 新建样式：主标题、板块标题、题目内容等
3. 以后直接点击样式即可一键应用
```

### 技巧3：批量替换格式
```
1. [开始] → [替换]
2. 点击 [更多] → [格式]
3. 可以批量替换字体、字号等
```
