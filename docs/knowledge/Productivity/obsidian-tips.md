# Obsidian 笔记知识（第三方经验）

来源：社区分享
更新：2026-07-25

## 推荐插件

| 插件 | 用途 | 推荐理由 |
|:----|:-----|:---------|
| **Easy Typing** | 中文输入优化 | 解决中文字号/空格/标点痛点 |
| **Export Image** | 笔记导出为图片 | 自动加阴影圆角，比截图美观 |
| **Omnisearch** | 增强全局搜索 | 比原生搜索快，支持PDF/OCR |
| **Recent Files** | 侧边栏最近文件 | 来回切换笔记时省时间 |
| **Novel word count** | 字数统计 | 实时显示当前笔记和仓库总字数 |
| **Editing toolbar** | 富文本工具栏 | 不熟 md 语法时必备 |
| **Nutstore Sync** | 坚果云同步 | 国内体验比 OneDrive 好，月1G上传够用 |
| **Claudian** | 内置 AI（Claude Code）| 可填人设，直接编辑笔记 |

## 关键观点

1. **笔记最重要的是内容**，不是折腾软件本身
2. MD 格式保证永不被锁定，记事本都能打开
3. AI 是效率工具，不能完全信任（会编数据）
4. Agent 让 AI 从"回答问题"变成"动手干活"
