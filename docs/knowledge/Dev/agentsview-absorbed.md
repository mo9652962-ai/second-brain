# AgentsView · 会话分析平台 · 吸收

> 本地优先的 AI Coding Agent 会话分析平台
> 支持 20+ 工具（含 Hermes Agent）

---

## 核心价值

- **自动发现** Hermes Agent 的所有历史会话
- **Token 用量仪表盘** — 按会话/模型/工具查看
- **费用追踪** — 实时掌握 API 支出
- **全文搜索** — 跨所有工具搜索
- **活动热力图** — 使用习惯可视化
- **完全本地** — SQLite，零云端

## 对我们的意义

| 痛点 | AgentsView 解决 |
|:-----|:----------------|
| 22 个 cron + 日常对话 → 不知花了多少 token | ✅ 统一仪表盘 |
| 多个工具混用（Hermes + Codex 等） | ✅ 跨工具汇总 |
| 想优化成本但缺数据 | ✅ 按模型/项目归因 |

## 安装方式

```bash
# Windows
winget install AgentsView
# 或下载二进制
```

## 建议

装一个看看 token 都花在哪了，尤其是 cron 任务的消耗占比。
