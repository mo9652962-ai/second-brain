# Privacy & Security Boundary Policy for Second Brain

**Last Updated:** October 2026

`second-brain` is an open-source, digital garden and autonomous AI agent knowledge base. We maintain strict physical isolation between public knowledge and private assets.

## 1. Dual-Track Physical Isolation
- **Public Garden:** All notes tracked in this repository are curated for public open-source knowledge sharing, technical roadmaps, architecture diagrams, and verified methodologies.
- **Private Knowledge Gating:** Proprietary engineering algorithms, commercial customer workflows, and private research notes are physically segregated into `private_knowledge/` (strictly `.gitignore` blocked) or held within encrypted offline vaults.

## 2. Zero Telemetry & Local Execution
- The knowledge vault contains zero telemetry code, zero web trackers, and zero analytical beacons.
- Search indexing and 3D topological visualization run 100% locally in-browser or client-side.

## 3. Reporting a Vulnerability or Accidental Exposure
If any unintended credential or sensitive snippet is detected in commit history, please report privately via GitHub Security Advisories or contact `mo9652962-ai@users.noreply.github.com`.
