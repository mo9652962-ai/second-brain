# 🃏 知识卡片 · AI Agent 自我进化：从"攒技能"到"协同进化"

> **来源**：ACL 2026 长文 + arXiv 2026 最新论文（5 篇合成）
> **一句话**：Agent 自我进化的范式已从"单通道技能积累"转向"技能图 + 反模式记忆 + 工具协同 + 量化验证"的多通道协同进化。

---

## 🧠 五个核心发现

**① SkillDAG — 技能不是列表，是图**
技能库组织为有向无环图，边有四种类型：前置依赖 / 特化 / 组合 / 冲突。
→ 技能间显式关系，避免"技能膨胀→上下文污染"。

**② SkillGen — 失败比成功更值钱**
同时分析成功和失败轨迹，提取"成功有但失败没有"的关键模式。
候选技能在部署前必须通过**配对验证**（同一任务有/无技能对比），净效果为正才上线。

**③ SkillSmith — 技能和工具要一起进化**
技能变异时同时修改工具（WRAP/EDIT/COMPOSE/SPLIT/RETIRE）。
技能膨胀时先检查工具层是否需要修复，而非一味加技能。

**④ 反模式记忆 — 别在同一个坑里摔两次**
记录失败签名 + 归因 + 修复方案。新方案先匹配已知反模式 → 命中则否决。

**⑤ COVE — 双通道协调**
简单修复 → 技能更新（harness，快但浅）
深层模式 → 参数更新（权重，慢但深）
根据任务特征自动路由到合适的进化通道。

## 💡 对每个人的启发

| 洞察 | 怎么用 |
|------|--------|
| 技能是图不是列表 | 你的知识/技能库加"前置/组合/冲突"关系，别堆平铺 |
| 对比归纳 > 单纯总结 | 失败时别只问"哪错了"，对比成功的轨迹找差异 |
| 工具和技能协同 | 技能不好用时，先查是不是工具该改了 |
| 反模式记忆 | 建一个"踩坑清单"，每次新方案先查是否匹配旧坑 |
| 量化验证门 | 新方法上线前，做个 A/B 对比，确认真的更好 |
