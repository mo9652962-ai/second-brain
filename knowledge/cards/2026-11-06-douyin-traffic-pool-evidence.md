# 🃏 知识卡片 · 抖音「流量池」不是被证伪，是没人拿得出出处

> **来源**：抖音安全与信任中心（2025 年上线，新浪科技 2025-04-16 报道口径为「近日上线」；确切上线日 03-30 仅见第三方解析，未直读官方公告）· RankMixer 论文（arXiv [2507.15551](https://arxiv.org/abs/2507.15551) v1 2025-07-21 / v3 07-26，CIKM '25 DOI 10.1145/3746252.3761507）· 本次 cron 用 curl 直读 arXiv abs 页逐句核对摘要
> **一句话**：官方公开的是「预测行为概率 × 行为价值权重」这个打分公式和双塔 / Wide&Deep 这些**模型示例**，从没公开过流量池档位和晋级阈值；网上那套「200-500 播放、完播 45% 进下一池」查不到出处——但**「查不到出处」不等于「已被证伪」**，把它当平台规则去优化，就是拿假设当目标。

## 核心洞察 / 影响

| 维度 | 内容 |
|------|------|
| 官方给了什么 | 推荐优先级 = 综合预测用户行为概率 × 行为价值权重；行为信号含完播、点赞、评论、分享、收藏、关注、划走、不喜欢、回访、相关搜索；分钟级实时更新；双塔召回 / Wide&Deep 排序只是**示例**，不是完整链路 |
| 官方没给什么 | 召回有几路、粗排/精排/重排各用什么模型、流量池档位与晋级阈值、任何模型参数/延迟/QPS |
| 民间说法的问题 | 「初始池 200-500 播放 → 完播率 45% 晋级」在官方材料与字节论文里均无依据；第三方英文解析页给出过 `≈200-500` 这个数，但自己用的是 *roughly*，且不引用任何官方文档 |
| 证据定级（关键） | 「固定流量池规则」= **未知（无公开依据）**，不是「已证伪」；「早期主要优化完播率、后转多目标」= **官方承认** |
| 工程侧硬证据 | RankMixer（CIKM '25）：MFU **4.5% → 45%**，参数扩 **100×** 到 **1B**，延迟**基本不变**，1B Dense 版**全流量上线**，活跃天数 **+0.3%**、使用时长 **+1.08%** |
| 反常识点 | 参数涨 100 倍、延迟不涨——说明「大模型 = 慢」在精排这一层不成立；真正决定分发的不是池子档位，而是**每次请求里这条视频和这个用户的相对排序** |

## 📱 微信推送版（可直接复制）

抖音「流量池」那套说法，不是被证伪，是没人拿得出出处。

网上传得最广的版本：新视频先进 200-500 播放的小池子，完播率过 45% 就晋级下一级，一共四级。

我去翻了官方材料：抖音 2025 年上线了「安全与信任中心」，公开了推荐原理——排序分 = 预测用户行为概率 × 行为价值权重，行为信号包括完播、点赞、评论、分享、收藏、关注、划走、不喜欢、回访、相关搜索，分钟级更新。

但流量池有几档、多大、阈值多少，官方一个字没给。字节自己的 RankMixer 论文（CIKM '25）也只讲模型：MFU 从 4.5% 提到 45%，参数扩到 10 亿，延迟基本没变，全流量上线后活跃天数 +0.3%、使用时长 +1.08%。

所以正确的结论不是「流量池是假的」，而是「这个精确数字没人能给出处」。这两句话差别很大：前者是结论，后者是空白。

空白怎么用？一条判据就够：看到「完播率 45% 进下一池」这种精确数字，先问四件事——出处、样本、时间、适用范围。答不上来，就当假设，别当规则。

真正能抓的还是官方公开的那部分：有效停留、收藏和长评这类深度互动、标题字幕里的关键词布局。以及你自己 100% 可控的前 2 秒——开头别铺垫，直接抛反常识。

（数据核对：arXiv 2507.15551 摘要逐句读过；抖音官网是动态页面，公式部分取自媒体转述，标为二手。）
