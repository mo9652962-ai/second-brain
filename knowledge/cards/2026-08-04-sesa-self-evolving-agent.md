# 🃏 知识卡片 · SESA：让 Agent 自己出题、解题、把失败写成技能再进化

> **来源**：arXiv 2607.29468（Self-Play Meets Skill Evolution，2026-07-31）· 今日 arXiv 周报 ✅ 高价值验证
> **一句话**：搜索 Agent 用**自博弈**给自己出题（挑战者），失败被蒸馏成**可复用技能写回记忆**，记忆又改变下次行为与出题分布——任务生成和技能记忆**双向共进化**，7 个基准上稳定提升 1.2~3.2 分。

---

## 核心洞察 / 影响

| 维度 | 内容 |
|------|------|
| 闭环设计 | 挑战者出题 → 求解者解题 → 失败蒸馏为技能写回记忆 → 记忆改变行为 → 改变未来问题分布 → 产生新失败再写回 |
| 关键差异 | 传统 self-play 失败只影响梯度，不改变未来练习；SESA 让失败**显式塑造**技能记忆 |
| 收益 | 记忆既是外部技能库，又能进入模型参数（可无记忆部署），7 个 QA 基准提升 1.2~3.2 分 |
| 佐证 | 同主题：OpenClaw 的 self-improving-agent、Simbian SecOps（90%+ 自主解决率）——2026 主流方向 |

## 对 sora / 自举体系的三层影响

1. ✅ **印证并强化现有机制**：k 的 skill_manage（失败→沉淀技能）+ .learnings/ERRORS.md 正是「技能写回记忆」的本地实现，方向被 2026 顶会级研究验证
2. ⚠️ **缺口在「挑战者」**：sora 体系缺少主动出题者——错误大多被动等来。可补一个「每周出题」：从旧 session 挑失败场景出变体题，主动跑一遍验证技能是否真的被复用
3. 💡 **可落地轻量版**：写技能时加一行「预期触发场景」，下次同类场景出现时系统自查是否调用了该技能（对齐 TAPO 行动后果预测）
