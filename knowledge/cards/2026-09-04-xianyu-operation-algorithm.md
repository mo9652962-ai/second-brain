## 核心洞察

| 维度 | 内容 |
|------|------|
| 推流链路 | 识别（图像+文本解析）→ 初始曝光 50-500 次 → 赛马（综合效率分）→ 信任倍率（0.1x-1.5x 全局放大器） |
| 点击率分层 | <5% 低流量池终止 / 5-10% 观察区 / 10-18% 赛马场资格 / >18% 爆款潜力（跳跃加速） |
| 赛马公式 | 综合效率分 = 点击权重×点击率 + 互动权重×互动率 + 转化权重×**转化速率** + GMV 权重×单位曝光产值 − 负反馈权重×负反馈率 |
| 信任倍率 | 0.1-0.8x：未实人/纠纷/回复率低/退款高；1.0x：实名+芝麻优秀；1.2-1.5x：芝麻极好/验货宝/高鱼力值/鱼小铺 |
| 市场真相 | 卖家月均成交 **897 元**；「90% 个人接单者月入不过千」是常态；**差异化定位**（垂直细分）报价可高同行 30%+ |
| 经营红线 | 同款反复售出 >5 次 / 年发 >30 件且品类 <3 / 年销 >10 万 / 年交易 >104 笔 → 经营性卖家标记（2026-06-01 生效） |

## 对 sora 的影响

1. ✅ **响应速度是第一杠杆**：5 分钟回复率 >90%（目标值），≤75% 流量腰斩——消息通知全开 + 固定 4 个时段集中回复
2. ⚠️ **经营新规红线自查**：论文/PPT 套餐属「同款反复售出」典型风险——变体上架分散、标题避敏感词；年流水逼近 10 万评估个体户正规化
3. 💡 **标题/主图按新算法重做**：前 15 字放核心关键词；首图点击率目标 >10%；图内文字也避敏感词；主图加「个人闲置」水印降营销号识别

## 行动项

- [ ] **回复提速**：5 分钟回复率 >90%，固定 4 时段集中回复（9:30-10:30 / 15:00-16:00 / 20:00-22:00 也是流量高峰）
- [ ] **标题重写**：核心词+属性词+场景词，前 15 字核心词，用搜索框下拉词找长尾
- [ ] **擦亮节奏**：优先擦亮有咨询/收藏≥3 的高潜力商品；擦亮后立即微调（改标点/换图序）→ 曝光加权 +42%
- [ ] **差异化迁移**：PPT 从「30-80 走量」向垂直细分（如考研复试答辩 PPT）迁移，用「项目」报价不用「页」
- [ ] **鱼小铺暂缓**：服务费 0.6%→1.6%（涨 166%、取消 60 元封顶），月成交额未过万前不开
