# 🃏 知识卡片 · Agent 能出「合法 PPT」，但语义还原是瓶颈：PPTBench 最好只有 67.80 分

> **来源**：arXiv 2609.29718（PPTBench）· 官方 abs 页 curl 直连复核（2026-09-26，标题/摘要原文与速览一致）· 数字全部来自论文摘要（官方源）
> **一句话**：让 agent 把真实 arXiv 论文流程图重建成单页**可编辑 PPTX**，31 种配置里最好的 Kimi K3 只有 **67.80 分**、**中位数 19.47**——产出合法文件很稳，**「看懂图 → 还原语义」仍是瓶颈**。

---

## 核心洞察 / 影响

| 维度 | 内容 |
|------|------|
| 基准规模 | **500 个任务**，每个 = 一篇真实 arXiv 论文的流程图 → 重建为**单页 PPTX**（原生、可编辑对象） |
| 评测方式 | 四阶段 Agentic Judge：产物有效性 / 语义正确性 / 渲染质量 / 细粒度视觉质量 |
| 结果分布 | **31 种配置**（跨模型家族 × effort 档 × harness）：最好 **67.80（Kimi K3）**，**中位 19.47** |
| 瓶颈定位 | agent **能稳定产出合法 PPTX**，但语义与视觉正确性差，**文字细节最差** |
| 变量结论 | 「更多推理」主要帮 agent **过硬门**；**「更强验证」才与更高质量稳定相关** |

## 关键数据 / 对 sora 的影响

1. ✅ **对客话术依据**：AI 做 PPT 的能力边界有了公开基准——中位 19.47 意味着一半配置连基础语义还原都做不到，所以「AI 出稿 + 人工精修」不是谦虚，是实测结论
2. ⚠️ **报价锚点不变**：PPT 单 30~80 元档位不受影响；客户问「为什么不能全自动」时，有第三方基准可引用（不承诺全自动 = 防跑单闭环的一部分）
3. 💡 **k 侧流水线可借鉴**：本次论文里「加验证轮」比「加推理轮」更有效——与 k 已有的 PPT 渲染验证闭环（LibreOffice 渲染 + 像素/视觉核验）同向，**验证步的权重值得再提一档**
4. 💡 **内容选题**：「AI 做 PPT 到底行不行？500 个真实任务的公开成绩单」——对 AI 博主线是有钩子的现成题材（合规：只讲公开技术，不进论文套餐）
