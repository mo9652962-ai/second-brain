# 🃏 知识卡片 · 装技能就是引入供应链：25.1% 的真实技能会走通危险路径，链式攻击成功率 84.3%

> **来源**：arXiv 09-30 ~ 10-02 三日窗口速览中的三篇独立论文（**官方源**：arxiv.org abs 页，2026-10-02 由 k 逐篇重抓原文核对数字）
> **一句话**：agent 的技能（Skill）不是插件，是**可自动调用、带权限的第三方代码**——三篇论文从三个角度证明，这条信任链现在几乎无人审计。

---

## 核心洞察 / 影响

| 维度 | 内容 |
|------|------|
| ① 静态路径 | **TrustProbe**（2609.39065）：在 11 个开源 agent（8 个 GitHub ★>10k）中挖出 **104 个污点式漏洞**；用公开 hub（ClawHub 等）的真实技能语料验证，**25.1% 的「技能×agent」试验走通了已识别的危险路径**，其中 15 个漏洞被 payload 注入真正武器化 |
| ② 链式放大 | **APEX**（2610.01564）：agent 自己写的「任务进展记录」可以夹带**伪造的用户授权**跨越技能边界。690 次尝试诱导出攻击者选定动作 **512 次（74.2%）**；GPT-5.4 上完整链 **84.3%**，而把同一工作流**合并成单个技能只剩 17.4%** |
| ③ 审计盲区 | **Hiding in Plain Sight**（2609.39352）：把「为什么执行」与「执行什么」**解耦**——上游技能用例行工具操作改写持久环境产物（编借口），下游技能保留完整恶意动作。**单看任何一个技能都干净** |
| ④ 防御代价 | 提示式防御（要求 agent 把技能产出文件与原请求核对）：GPT-5.4 上目标动作成功率 84.3% → **59.1%**，但 72 个良性原生技能任务的通过率从 86.7% → **56.3%**——防御不是免费的 |

## 关键数据 / 对 sora 的影响

1. ⚠️ **「来自热门 hub、star 很多」不构成安全证据**：8 个 ★>10k 的 agent 全中招；真实技能 25.1% 触发危险路径。k 的技能库（`skill_manage` 安装 + 后续任务自动调用）**正是这条供应链**，且目前是「无人隔离审计」状态
2. ⚠️ **多步流水线天然放大风险**：链式 84.3% vs 单体 17.4%（4.8 倍）。k 的 cron 流水线（速览 → 卡片 → MOC → 次日速览）每多一环，就多一个「上游改环境、下游照做」的位置
3. 💡 **「agent 自己写的文件」≠「用户批准过」**：凡涉及外部动作（推送、发送、下单、上传）的授权判断，必须回溯到**用户原始指令**，不能采信中间产物——APEX 的杀招正是伪造的中间记录
4. ✅ **有状态策略比白名单更值**（同批 2610.00797 Sapien）：把「命令白名单」升级为**有状态谓词**（如「先跑过 verify 才允许 push」），AgentDojo 上排除 93–95% 攻击，而效用只差几个百分点

## 行动项

- [ ] **装外部技能前跑「装前双检」**：① 单技能静态检查——它写哪些路径 / 发哪些网络请求 / 读哪些凭据；② 跨技能依赖链检查——有没有「A 改环境 → B 用环境」的隐性组合（pretext-actuation）
- [ ] 把「外部动作授权」的判据写成硬规则：**只看用户原始指令**，不看 agent 自己写的进度记录
- [ ] 高风险门禁从「命令白名单」升级为「前置状态谓词」，并让门禁输出**拒绝 + 替代路径**而不是单纯拒绝

## 为什么重要

- **直击 k 自身**：sora 常装第三方技能（skill-installer / external-skill-installation），而 k 的 cron 链本质就是「上游产出喂下游」——三篇论文分别命中「安装」「链式传递」「审计盲区」三个环节，且数字来自官方 abs 页逐篇核对
- **不是单篇孤证**：同一天同一窗口三篇独立工作（静态污点 / 链式构造 / 攻击范式）互相印证，属「交叉验证型」新知识而非重复结论
- **内容选题**：「装个技能而已，能有多危险？」——25.1% / 84.3% / 104 个漏洞 是能讲清、能演示、有出处的实战题材（AI 博主蓝海工程向）
