# 🃏 知识卡片 · 今天起，欧盟 AI 法案高风险义务正式执法

> **来源**：EU AI Act (Regulation 2024/1689) · **2026-08-02 生效** · ✅ 已评估
> **一句话**：从今天开始，欧盟对「高风险 AI 系统」的强制义务正式执法——对你的闲鱼接单没影响，但将来做对外多 Agent 产品，必须内置「日志 + 人工升级 + 透明度声明」三件套。

---

## 今天生效了什么

| 类别 | 内容 |
|------|------|
| **Annex III 高风险义务** | Art.9-17 + Art.72：风险管理、数据治理、技术文档、防篡改日志(≥6个月)、透明度、人工监督、网络安全韧性、QMS、上市后监控 |
| **透明度义务** | Art.50：与 AI 交互需告知用户 |
| **执法权** | GPAI 模型执法权 + 完整处罚机制启动 |

⚠️ **关键条款（Recital 99/100）**：在 agent 链中，合规边界延伸到**每个执行高风险功能的 agent**——调用 API / MCP 服务器即进入网络安全与日志强制范围。

## 对 sora 的三层影响

1. ✅ **闲鱼论文/PPT/PCB 接单**：一次性文档交付，不属高风险 AI 系统 → **不受影响**
2. ✅ **校园小程序/平台**：客户不面向 EU、功能不涉高风险（简历筛选/信用评估等）→ 大概率不在范围
3. ⚠️ **对外多 Agent 产品/服务**：明确进入范围 → 预置三件套（审计日志 + HITL 人工升级入口 + 透明度声明），成本约 1 天

## 行动项

- [x] 接单问卷已加「客户是否面向 EU 市场？」（8/1 已并入 SOP 1.3）
- [ ] 若未来做多 Agent 产品：预置三件套（与 MEMORY「Bounded Autonomy」最佳实践天然对齐）
- ⚠️ Digital Omnibus 推迟提案只是提案、未立法——**勿按推迟规划**

## 为什么今天重要

- 这是**今天（8/2）**生效的全球最大 AI 监管里程碑，不是远期风险
- 多 Agent 链式架构是 sora 的方向（Hermes/OpenClaw 就是多 agent 编排）——现在就知道合规边界，成本最低
- 对 AI 博主是很好的内容选题：一条法规如何影响个人开发者/接单党
