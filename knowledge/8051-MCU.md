# 51 单片机 (8051/MCS-51) — 嵌入式开发入门

> Intel 1981 年推出 · 最经典 8 位 MCU 架构 · 至今仍在大量使用（STC/Atmel/Silicon Labs/Nuvoton）
> 来源：GitHub Topics + 多源中文教程 + 开源工具链

## 🏗️ 硬件架构

### 8051 核心参数

| 组件 | 规格 |
|------|------|
| CPU | 8-bit CISC |
| 工作频率 | 12MHz (经典) / 11.0592MHz (波特率友好) |
| 内部 RAM | 128/256 bytes |
| 内部 ROM/Flash | 4KB (8051 原版) ~ 64KB (现代 STC) |
| I/O 口 | 4 组 8 位 (P0, P1, P2, P3) |
| 定时器/计数器 | 2 个 16-bit (T0, T1) |
| 串口 | 1 个全双工 UART |
| 中断 | 5 个源 (INT0, INT1, T0, T1, 串口) |

### 引脚功能速查

```
     ┌───┐┌───┐
  P1.0 □ 1      40 □ VCC
  P1.1 □ 2      39 □ P0.0/AD0
  P1.2 □ 3      38 □ P0.1/AD1
  P1.3 □ 4      37 □ P0.2/AD2
  P1.4 □ 5      36 □ P0.3/AD3
  P1.5 □ 6      35 □ P0.4/AD4
  P1.6 □ 7      34 □ P0.5/AD5
  P1.7 □ 8      33 □ P0.6/AD6
  RST  □ 9      32 □ P0.7/AD7
  P3.0/RXD □10  31 □ EA/VPP
  P3.1/TXD □11  30 □ ALE/PROG
  P3.2/INT0 □12 29 □ PSEN
  P3.3/INT1 □13 28 □ P2.7/A15
  P3.4/T0 □14   27 □ P2.6/A14
  P3.5/T1 □15   26 □ P2.5/A13
  P3.6/WR □16   25 □ P2.4/A12
  P3.7/RD □17   24 □ P2.3/A11
  XTAL2 □18     23 □ P2.2/A10
  XTAL1 □19     22 □ P2.1/A9
  GND   □20     21 □ P2.0/A8
     └───────────┘
```

- **P0**: 开漏输出，需上拉电阻
- **P1**: 通用 I/O
- **P2**: 通用 I/O + 高 8 位地址总线
- **P3**: 复用功能（RXD, TXD, INT0, INT1, T0, T1, WR, RD）

### 最小系统

```
VCC ─┬─ 40脚(VCC) ──┬─ 10μF ──┬─ GND
     │              │          │
     │   31脚(EA) ──┘          │
     │                         │
     ├─ 10KΩ ── 9脚(RST) ── 10μF ── GND
     │
     ├─ 30pF ── 18脚(XTAL2) ── 晶振 ── 19脚(XTAL1) ── 30pF ── GND
     │              (12MHz 或 11.0592MHz)
     └─ 20脚(GND)
```

## 💻 开发环境

### 方案一：Keil C51 (经典/商业)

```
Keil uVision → 编写 .c 文件 → 编译 → .hex 文件 → STC-ISP → USB转串口 → 烧录到芯片
```

| 工具 | 用途 | 获取 |
|------|------|------|
| **Keil C51** | IDE + C 编译器 + 仿真器 | keil.com (免费版限 2KB 代码) |
| **STC-ISP** | 串口烧录工具 | stcmcudata.com (STC 官方) |

### 方案二：SDCC + stcgal (开源/跨平台)

```bash
# 编译
sdcc -mmcs51 main.c -o main.ihx
# 转 hex
packihx main.ihx > main.hex
# 烧录 (Linux/Mac/Windows)
stcgal -P stc89 -p COM3 main.hex
```

| 工具 | 用途 | 获取 |
|------|------|------|
| **SDCC** | 开源 C 编译器 (支持 MCS-51) | sdcc.sourceforge.net |
| **stcgal** | 开源 STC ISP 烧录工具 | github.com/grigorig/stcgal |
| **MCU 8051 IDE** | 开源 8051 IDE | sourceforge.net |

### 方案三：PlatformIO (现代)

## 📝 C 语言编程基础

### 第一个程序：LED 闪烁

```c
#include <reg52.h>  // STC89C52 头文件

typedef unsigned char u8;
typedef unsigned int u16;

sbit LED = P1^0;  // 位定义: P1.0 控制 LED

void delay_ms(u16 ms) {
    u16 i, j;
    for (i = 0; i < ms; i++)
        for (j = 0; j < 123; j++);  // 12MHz 约 1ms
}

void main() {
    while (1) {
        LED = 0;     // 点亮（低电平驱动）
        delay_ms(500);
        LED = 1;     // 熄灭
        delay_ms(500);
    }
}
```

### 特殊功能寄存器 (SFR)

```c
sfr P0    = 0x80;  // P0 端口
sfr P1    = 0x90;
sfr P2    = 0xA0;
sfr P3    = 0xB0;
sfr TMOD  = 0x89;  // 定时器模式
sfr TCON  = 0x88;  // 定时器控制
sfr TH0   = 0x8C;  // 定时器 0 高字节
sfr TL0   = 0x8A;  // 定时器 0 低字节
sfr SCON  = 0x98;  // 串口控制
sfr SBUF  = 0x99;  // 串口数据缓冲

// 位寻址
sbit EA  = 0xAF;  // 全局中断允许
sbit ET0 = 0xA9;  // T0 中断允许
sbit TR0 = 0x8C;  // T0 运行控制
sbit TI  = 0x98;  // 发送中断标志
sbit RI  = 0x99;  // 接收中断标志
```

### 定时器中断

```c
void timer0_init() {
    TMOD |= 0x01;   // T0 模式 1 (16-bit)
    TH0 = 0xFC;     // 初值高 8 位 (1ms @ 12MHz)
    TL0 = 0x18;     // 初值低 8 位
    ET0 = 1;        // 允许 T0 中断
    EA  = 1;        // 开全局中断
    TR0 = 1;        // 启动 T0
}

volatile u16 timer0_count = 0;

void timer0_isr() __interrupt(1) {  // 中断号 1 = T0
    TH0 = 0xFC;   // 重装初值
    TL0 = 0x18;
    timer0_count++;
}

// Keil C51 写法 (不使用 __interrupt):
// void timer0_isr() interrupt 1 { ... }
```

### 串口通信

```c
void uart_init() {
    SCON = 0x50;   // 模式 1, 8-bit UART, 允许接收
    TMOD |= 0x20;  // T1 模式 2 (8-bit 自动重装)
    TH1 = 0xFD;    // 9600 bps @ 11.0592MHz
    TL1 = 0xFD;
    TR1 = 1;       // 启动 T1
    ES  = 1;       // 允许串口中断
    EA  = 1;       // 开全局中断
}

void uart_send_byte(u8 dat) {
    SBUF = dat;
    while (!TI);   // 等待发送完成
    TI = 0;
}

void uart_send_string(u8 *str) {
    while (*str) uart_send_byte(*str++);
}

void uart_isr() __interrupt(4) {  // 中断号 4 = 串口
    if (RI) {
        u8 received = SBUF;
        RI = 0;
        // 处理接收到的字节
    }
}
```

## 🔌 常用外设驱动

### LCD1602 显示

```c
// 引脚定义
sbit LCD_RS = P2^0;
sbit LCD_RW = P2^1;
sbit LCD_EN = P2^2;
#define LCD_DATA P0

void lcd_write_cmd(u8 cmd) {
    LCD_RS = 0;  LCD_RW = 0;
    LCD_DATA = cmd;
    LCD_EN = 1;  delay_us(5);
    LCD_EN = 0;  delay_ms(2);
}

void lcd_write_data(u8 dat) {
    LCD_RS = 1;  LCD_RW = 0;
    LCD_DATA = dat;
    LCD_EN = 1;  delay_us(5);
    LCD_EN = 0;  delay_ms(2);
}

void lcd_init() {
    lcd_write_cmd(0x38);  // 8-bit, 2 行, 5×7 点阵
    lcd_write_cmd(0x0C);  // 显示开, 光标关
    lcd_write_cmd(0x06);  // 光标右移
    lcd_write_cmd(0x01);  // 清屏
}

void lcd_print(u8 *str) {
    while (*str) lcd_write_data(*str++);
}
```

### 数码管显示

```c
// 共阴极段码表
u8 code SEG_CODE[] = {
    0x3F, // 0
    0x06, // 1
    0x5B, // 2
    0x4F, // 3
    0x66, // 4
    0x6D, // 5
    0x7D, // 6
    0x07, // 7
    0x7F, // 8
    0x6F  // 9
};

// 动态扫描 4 位数码管
sbit SEG_CS1 = P2^0;  // 位选 1
sbit SEG_CS2 = P2^1;
sbit SEG_CS3 = P2^2;
sbit SEG_CS4 = P2^3;

void display_number(u16 num) {
    u8 digits[4];
    digits[0] = num / 1000;
    digits[1] = (num / 100) % 10;
    digits[2] = (num / 10) % 10;
    digits[3] = num % 10;
    
    SEG_CS1 = 1; P0 = SEG_CODE[digits[0]]; delay_ms(2); SEG_CS1 = 0;
    SEG_CS2 = 1; P0 = SEG_CODE[digits[1]]; delay_ms(2); SEG_CS2 = 0;
    SEG_CS3 = 1; P0 = SEG_CODE[digits[2]]; delay_ms(2); SEG_CS3 = 0;
    SEG_CS4 = 1; P0 = SEG_CODE[digits[3]]; delay_ms(2); SEG_CS4 = 0;
}
```

### DS18B20 温度传感器

```c
sbit DQ = P3^3;  // 单总线数据线

u8 ds18b20_init() {
    u8 presence;
    DQ = 0;  delay_us(480);   // 复位脉冲
    DQ = 1;  delay_us(60);    // 释放总线
    presence = DQ;            // 读取存在脉冲
    delay_us(420);
    return presence;          // 0 = 设备存在
}

u8 ds18b20_read_byte() {
    u8 i, dat = 0;
    for (i = 0; i < 8; i++) {
        DQ = 0;  dat >>= 1;
        DQ = 1;  delay_us(2);
        if (DQ) dat |= 0x80;
        delay_us(60);
    }
    return dat;
}

void ds18b20_write_byte(u8 dat) {
    u8 i;
    for (i = 0; i < 8; i++) {
        DQ = 0;  delay_us(2);
        DQ = dat & 0x01;  delay_us(60);
        DQ = 1;
        dat >>= 1;
    }
}

float ds18b20_read_temp() {
    u8 tl, th;
    if (ds18b20_init()) return -999;
    ds18b20_write_byte(0xCC);  // 跳过 ROM
    ds18b20_write_byte(0x44);  // 启动温度转换
    delay_ms(750);
    ds18b20_init();
    ds18b20_write_byte(0xCC);
    ds18b20_write_byte(0xBE);  // 读取暂存器
    tl = ds18b20_read_byte();
    th = ds18b20_read_byte();
    return (th * 256 + tl) * 0.0625;  // 12-bit 分辨率
}
```

## 🔥 烧录流程

### STC 芯片 (国内最常用)

```
1. 连接: USB 转 TTL → 芯片 (P3.0=RX, P3.1=TX)
2. 打开 STC-ISP 软件
3. 选择芯片型号 (如 STC89C52RC)
4. 选择 COM 口 + 波特率 (默认 115200)
5. 打开 .hex 文件
6. 点击"下载/编程"
7. 给芯片断电再上电 (冷启动)
8. 等待烧录完成
```

### 关键注意事项

- STC 芯片需要**冷启动**（先断电 → 点下载 → 再上电）
- 烧录波特率不宜过高（115200 稳妥，过高可能失败）
- P3.0/RXD 接 USB-TTL 的 TXD
- P3.1/TXD 接 USB-TTL 的 RXD
- 共地！共地！共地！

## 🧠 对 sora 的 AI 辅助开发建议

1. **Keil C51 是标准答案** — SDCC 虽然开源，但与 Keil 的编译结果有差异
2. **用 AI 生成初始化代码骨架** → 人工校验寄存器配置 → 硬件实测
3. **仿真先行**: Proteus 或 Keil 自带仿真器可以零成本验证逻辑
4. **核心知识链**: C 语言基础 → 8051 寄存器 → 中断系统 → 外设时序
5. **常见坑**: 
   - 忘记 `EA=1` 导致中断不触发
   - P0 口未加上拉电阻
   - 晶振选错导致波特率不准（用 11.0592MHz！）
   - STC 烧录忘记冷启动
