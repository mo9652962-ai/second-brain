# 去 AI 味 2026 强化：39 类检测 + 注入肉身法（千轮研究 2026-08-21）

> 来源：avoid-ai-writing-zh（39 类中文检测）+ 36氪去AI味手册 + 王若风 10 工具横评 + ai-to-human-zh（老编辑实战）

## 核心认知

1. **AI 检测器不可靠**——OpenAI 自家工具真阳率仅 26%（下架）；被标记 ≠ 用了 AI，没标记 ≠ 没用
2. **去 AI 味 ≠ 规避检测**——是改品质（注入判断/声音/细节），不是随机替换词骗检测器
3. **真正的 AI 味** = 「说了等于没说」的空洞感：没具体数字、没真实场景、没你不查就说不出的细节

## 39 类中文 AI 痕迹（检测模式速查）

**句式结构（17）**：「不是X而是Y」/ 虚假让步三拍 ★最隐蔽 / 排比填充 / 报幕过渡 / 抒情过渡 / 对称收束 / 反问开场 / 「首先其次最后」/ 过度中性 / 「由此可见」/ 缺跳跃感 / 伪个人视角 / 成语堆砌 / 「我们」式共鸣 / 重复「我」/ 旧❌新✅结构

**用词短语（8）**：Tier1 高频词（赋能/底层逻辑/颗粒度）见即标 / Tier2（本质上/至关重要）聚集标 / 过渡短语 / 虚假归因 / 动词戏剧化 / 缓冲词（其实/本质上）堆砌 / 同义重复 / 生硬搭配 ★

**格式（4）**：加粗过度 / 列表过多 / 子标题对称 / 破折号过度

**节奏（4）**：句长均匀 / 段落均匀 / 同义词轮换 / 假口语混搭

**内容（6）**：意义膨胀 / 新颖性膨胀 / 虚假全面性 / 模板开头 / 模板结尾 / 比喻密度过高

## 注入肉身法（最强去味——让 AI 学你的风格）

```
① 收集 3-5 篇你的原创（>1500 字，覆盖说明/议论/口语/修辞）
② 【】标注风格锚点：高频过渡词 / 标志性句式 / 惯用比喻
③ 列出 3 个绝对避免项（禁用被动语态 / 不用「不是而是」/ 不超两个顿号）
④ 分阶段提示词训练（不一次性输入，防特征稀释）
⑤ 三版 A/B/C 对比反馈：绿=一致 / 黄=偏离 / 红=冲突 → 对红句发修正指令
```

## 老编辑铁律（ai-to-human-zh）

```
先出审查报告 → 问用户要不要改 → 确认才改（不直接动手）
版本迭代不覆盖原文（_V2/_V3）
「不是A而是B」保留 1 处开篇反转，其余删「不是」直接说
「所以/因此」推导 → 换语调信号（你看/说白了/你再想想）
结尾刺穿：描述行为 → 刺穿心理
```
