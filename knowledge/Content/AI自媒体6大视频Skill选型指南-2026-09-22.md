# AI 做自媒体，6 个视频 Skill 选型指南：剪辑、包装与补镜头全解

> 来源：抖音 @浩辰 Alex(AI 版) 短视频（93s）深度研读与技术溯源
> 整理：k · 2026-09-22 · 6 大开源 Agent Skill 逆向工程 + 技术底座拆解 +「sora做实事」落地管线

---

## 结论置顶

**很多自媒体创作者用 AI 还停留在「让 AI 写文案脚本」，但真正消耗 80% 精力的剪辑、动效包装和补镜头，最后依然全靠人工熬夜肝。**
博主的核心观点非常精辟：**“不要一次把 6 个 Skill 全装上，先看你最想把哪部分脏活累活甩给 AI。”**

视频创作管线天然可以解构成三大核心瓶颈，对应的 6 个开源 Agent Skill 构成了一套清晰的**三阶段选型决策树**：

| 创作瓶颈 | 推荐 Skill | 运作机制 | 核心优势 | 最佳适用场景 |
|:---|:---|:---|:---|:---|
| **❶ 素材拍好了，只差剪辑**<br>(粗剪、去废话、上字幕) | **1️⃣ `video-use`** | 基于词级时间戳（Whisper/ElevenLabs），LLM「只读文本不看画面」，算法精准识别气口、结巴、重复片段并自动切割 | 全自动、零人工干预、一键粗剪压字幕 | 口播、采访、会议实录等大段长素材快速瘦身 |
| | **2️⃣ `ChatCut`** | MCP 驱动的 Web 可视化多轨编辑器（`ChatCut-Inc/agent-plugin`），AI 对话裁切 + 人工时间轴微调 | AI 智能初筛 + 人工终审把控节奏 | 对成片节奏、停顿气口要求严苛的精品短视频 |
| **❷ 主视频有了，画面太干**<br>(加数据图表、MG动画、视觉包装) | **3️⃣ `HyperFrames`** | HeyGen 开源（49.3k★），HTML/CSS + GSAP $\to$ Headless Chrome 逐帧渲染确定性 MP4 视频 | 零生成式抽卡、高精度代码级数据可视化、零成本 | 单次临时插入动态图表、关键词高亮、产品功能演示 |

| **❸ 讲到概念，手里缺镜头**<br>(抽象概念视觉化、B-roll、空镜) | **5️⃣ `gbro-collage-broll`** | 将 5 秒口播或抽象概念自动转化为半调纸拼贴风（Editorial Halftone Collage）B-roll 动态短片 | 极具先锋科技感、打破大头娃娃枯燥感、极高完播率 | 科技拆解、硬核科普、算法讲解、商业逻辑复盘 |
| | **6️⃣ `seedance2-skill`** | 针对字节即梦（Seedance 2.0 / Kling / Sora）的多模态分镜提示词专家，拆解人物、运镜、动作与逐秒分镜 | 100+ 专业运镜词库、四关创意审核、直接输出生产级 Prompt | 剧情短剧、概念先导片、宏大自然/科幻场景补充 |

## 一、第一组：素材拍好了，只差剪辑（粗剪降噪）

口播博主最繁琐的工作是：一句话说了 3 遍挑选最好的一遍、中间的长停顿/深呼吸气口、语气词“呃、那个”。

### 1. `video-use`：全自动文字级精准盲剪
- **开源溯源**：`browser-use/video-use`（以及集成了它的 `ArtCog/chatcut` 自动化流）
- **底层架构**：
  - **Layer 1（音频转录）**：调用 ASR 模型（如本地 `faster-whisper` 或 ElevenLabs Scribe）提取包含每个单词精确起止毫秒的时间戳，并识别音频事件（如 `laughter`、`sigh`、`applause`）。将整段素材打包为极轻量的结构化文档 `takes_packed.md`；
  - **Layer 2（大模型语义裁切）**：**LLM 根本不需要“看”视频画面**，直接阅读纯文本时间轴。大模型能够一眼看出哪些句子是重复结巴（Retake）、哪些是无意义停顿，输出带有精确到词级边界（Word-boundary）的剪切指令列表（EDL / Cut-plan）；
  - **Layer 3（无损流合并）**：FFmpeg 根据指令无缝抽取保留片段拼接，自动对齐字幕并导出。
- **选型结论**：**追求极致吞吐量、极简自动化的懒人首选**。

### 2. `ChatCut`：AI 辅助的可视化微调工作台
- **开源溯源**：`ChatCut-Inc/agent-plugin`（支持 Claude Code / Codex / MCP 协议接入）
- **底层架构**：
  - 它不仅是一个脚本，而是一个完整的浏览器端多轨非线性编辑器（NLE）；
  - Agent 通过 MCP 协议操控工程：创建项目、导入音视频素材、执行 AI 粗剪；
  - 同时向创作者交付一个实时同步的可视化编辑链接。创作者可以在网页时间轴上亲手拖拽音视频轨道、微调转场切点、调节音量包络线。
- **选型结论**：**适合对表达语气、转场卡点有强迫症的细节控创作者**。

## 二、第二组：主视频有了，画面还差点意思（动态包装）

长达 1 分钟的纯人头口播极易导致用户滑走，必须在关键论点、数字爆发、核心概念出现时插入动态视觉刺激。

### 3. `HyperFrames`：HTML 确定性代码动画生成器
- **开源溯源**：`heygen-com/hyperframes`（49.3k★，详见 `knowledge/Content/hyperframes-html-to-video-2026-09-13.md`）
- **底层架构**：
  - 用人类与 AI 最熟悉的语言（HTML + CSS + GSAP）编写动效；
  - 核心引擎利用 Chrome DevTools Protocol 的 `BeginFrame` 机制逐帧离屏捕获，FFmpeg 压制输出；
  - **确定性优势**：绝对不会出现生成式 AI 的文字扭曲、肢体变形、前后不一致问题。同一份 HTML 代码在任何机器上渲染出的 MP4 分秒不差。
- **选型结论**：**临时单次需要插入科技感折线图、产品 3D 悬浮卡片、代码高亮弹窗的利器**。

### 4. `Remotion Skills`：React 组件化视频工程母版
- **开源溯源**：`remotion-dev/remotion` + Agent Skill 扩展包
- **底层架构**：
  - 把视频完全当成前端 React 项目开发：`<Composition />`、`<Sequence />`、CSS-in-JS 动画；
  - 能够把博主专属的“片头片尾”、“下三分之一姓名条（Lower Thirds）”、“关注引导悬浮窗”、“章节标题转场”抽象为强类型组件库；
  - 每次做新视频只需传入一段 JSON 数据（如 `{ title: "PCB 走线技巧", chapter: "03" }`），CLI 秒级批量合成带透明通道的 ProRes / WebM 动效素材。
- **选型结论**：**打造个人 IP 专属视觉识别系统（VI）与长期流水线日更的基石**。

## 三、第三组：讲到抽象概念，手里缺画面（补镜头与 B-roll）

当你在视频里讲到“去中心化通信”、“Transformer 自注意力机制”、“Linux 内核调度”这类抽象概念时，实拍根本拍不出来，纯文字又极其枯燥。

### 5. `gbro-collage-broll`：复古半调纸拼贴风（科技高级感）
- **开源溯源**：`pyang5166/gbro-collage-broll`
- **底层架构**：
  - **三阶段审核门（Gate 1~3）**：
    1. **视觉隐喻提取**：输入一段 5 秒的抽象口播，AI 首先提炼出贴切的视觉隐喻（如：将“并发死锁”隐喻为“四个机械齿轮同时咬死”）；
    2. **半调拼贴静帧生成**：结合复古报纸、撕纸边缘、几何图形、高对比度荧光色，生成 Editorial Halftone Paper-Collage 静帧；
    3. **动画微动合成**：调用轻量视频模型（如 Gemini Omni Flash）注入折叠、穿梭、弹跳微动效，生成 3~5 秒的无缝 B-roll 插入主视频中。
- **选型结论**：**硬核科技、商业财经、知识科普博主拉高视觉信息密度的必备神器**（何同学、影视飓风同款视觉风格）。

### 6. `seedance2-skill`：电影级多模态分镜导演专家
- **开源溯源**：`dexhunter/seedance2-skill` / `zhanghaonan777/Seedance2-skill`
- **底层架构**：
  - 专门针对字节跳动即梦 **Seedance 2.0**（`doubao-seedance-2-0`）等多模态视频大模型深度优化的 Prompt 工程技能；
  - 内置 12 类 100+ 电影运镜词库（推拉摇移、升降跟拍、移轴微距、希区柯克变焦）与导演风格库；
  - 实施四关创意门禁：**记忆点（Hook） $\to$ 意外感（Twist） $\to$ 情绪弧线（Emotion） $\to$ 叙事变化（Narrative）**；
  - 自动将一段故事大纲转化为标准的分镜头脚本表，包含首帧图描述、尾帧约束、相机轨迹编码（`[Zoom In 1.2x, Pan Left 15deg]`）。
- **选型结论**：**需要生成写实人物、科幻场景、影视级空镜时的专业导演助理**。

## 四、对「sora做实事」抖音账号的实战落地建议

结合 sora 的定位（**实战派 AI 自动化 + 蓝海工程：CAD / PCB / 单片机 / 自动化**），6 个 Skill 的落地组合拳：

```
[sora 录制原始口播 / 桌面实操]
           │
           ▼
   【阶段 1 · 粗剪】
   使用 video-use 理念：利用本地已部署的 SenseVoice (funasr) + ffmpeg
   全自动切除空白气口与结巴，生成精确时间轴字幕
           │
           ▼
   【阶段 2 · 视觉包装】
   遇到电路参数、代码对比、测试数据时：
   使用 HyperFrames（HTML/Canvas）生成高精度交互式图表与波形对比
           │
           ▼
   【阶段 3 · 概念补镜头】
   遇到“总线仲裁”、“时钟漂移”、“内存泄漏”、“Agent 反思回路”等硬核概念：
   调用 gbro-collage-broll 生成电路板切片 + 终端代码卡片折叠动效的 B-roll
           │
           ▼
[生成高清无水印、节奏紧凑、信息密度极高的 1080P 成片]
```

### 本地工程资产对齐：
1. **ASR 与粗剪**：本机已具备 `faster-whisper` + `funasr`，无需付费 ElevenLabs，本地即可跑通 `takes_packed.md` 提取机制；
2. **HTML 视频渲染**：工作区已有成熟的前端 3D / Canvas 代码体系，完全可无缝接入 `HyperFrames` 本地流水线；
3. **即梦 Seedance 2.0 词库**：已沉淀 `knowledge/Content/即梦Seedance-相机四维编码速查-2026.md`，可与 `seedance2-skill` 深度互锁。
