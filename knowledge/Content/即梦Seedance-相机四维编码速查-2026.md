# 即梦 Seedance 2.0 视频提示词：相机四维编码速查手册

> 核心法则：**拒绝模糊的“电影感/高级运镜”**，用 **[Z景别 + Y高度 + X偏角 + F运镜动词]** 的标准化公式下达指令。
> 适用模型：即梦 Seedance 2.0 / 阿里 Wan / 可灵 Kling / Runway Gen-3

---

## 一、相机四维坐标系统 (Z / Y / X / F)

| 维度 | 编码 | 中文标准词 | 画面特征与情绪传达 |
|:---|:---|:---|:---|
| **Z 景别** | **ECU** | 大特写 / 极致微距 | 聚焦眼眸、指尖、机械零件，强烈压迫感与细节张力 |
| | **CU** | 特写镜头 | 颈部以上头部，清晰捕捉微妙眼神与微表情 |
| | **MS** | 中景镜头 (腰部以上) | 黄金叙事景别，兼顾人物动作与上半身肢体语言 |
| | **FS** | 全景镜头 (全身入画) | 完整展示人物体态与所在地面交互 |
| | **WS** | 大远景 / 鸟瞰远景 | 环境交代、宏大世界观、孤独感或史诗氛围 |
| **Y 机位高度**| **Low** | 低机位仰拍 | 强化威严感、崇高感、压迫感或速度冲击 |
| | **Eye** | 视平线平拍 | 客观视角、纪实感、沉浸式对话平视 |
| | **High**| 高机位俯拍 | 俯瞰全局、人物渺小感、棋盘式空间布局 |
| | **Bird**| 垂直顶视 (90°鸟瞰) | 极简几何构图、战术布局、抽象美感 |
| **X 水平偏角**| **Front**| 正面机位 | 对峙感、直面观众、心理坦白 |
| | **3/4** | 三分之四侧面 (前侧45°)| 人物立体感最强、最自然的主流机位 |
| | **Profile**| 正侧面 (90°) | 剪影感、旅途行进、冷静对视 |
| | **Behind** | 背后跟拍 (背身视角) | 探索未知、悬念感、第一人称代入 |
| **F 运镜运动**| **Push In**| 慢速推镜头 | 悬念揭晓、焦点锁定、情绪升温 |
| | **Pull Out**| 慢速拉镜头 | 离别孤寂、从个体揭示宏大背景 |
| | **Pan** | 水平摇镜 (左右旋转) | 视线转移、场景横向扫描扫描 |
| | **Truck** | 横移跟随 (机位横移) | 伴随主体同步奔跑/行进 |
| | **Orbit** | 环绕运镜 (围绕旋转) | 英雄时刻、360°全方位展示、时间凝滞感 |
| | **Crane** | 升降镜头 (垂直升起) | 破土而出、纵览全局、高潮收尾 |

## 二、标准提示词组合公式

```
【景别与角度】+【主体特征与动作】+【机位运动方式】+【光影色彩氛围】+【负向质量约束】
```

### 示例 1：工程师桌面硬核实操
> `[中景平拍，微距特写切换] @image1 青年工程师正在用电烙铁焊接电路板，芯片表面浮现微弱呼吸光，[慢速平稳推进镜头]，暗调赛博朋克深蓝与金色微光，胶片颗粒感，电影级景深虚化，避免画面变形，避免手指错位，避免画质模糊。`

### 示例 2：科技产品悬浮 3D 环绕展示
> `[低机位特写镜头] 墨题刷题机硬件终端悬浮在半空中，屏幕亮起水墨金光界面，[平滑 360 度顺时针环绕运镜]，极简纯黑背景，边缘带锐利反光轮廓光，4K 商业广告质感，避免背景杂质，避免模型晃动，首尾帧自然过渡。`
