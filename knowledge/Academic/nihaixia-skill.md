# 倪海厦 Skill · 中医经方 AI 技能包

来源：小黑盒 "软件格律诗"
链接：https://jangviktor-web.github.io/nihaixia/
仓库：https://github.com/jangviktor-web

## 简介
完整蒸馏倪海厦毕生中医体系，做成 AI Agent 技能包。
输入"倪海厦""倪师"切换经方思考模式，症状输入直接给出六经分型、方剂、剂量与禁忌。

## 知识库规模
- **原始讲义**：2452 页，350 万字
- **伤寒论**：129 条原文
- **金匮要略**：23 篇
- **黄帝内经**：71 篇
- **神农本草**：345 种药材
- **临床医案**：849 份，癌症 147 例专项

## 核心能力

| 能力 | 说明 |
|:-----|:------|
| **六经诊断 v2.1.0** | 八大六经诊断公式 + 七步辨证思维（定表里→分阴阳→辨寒热→判传变→审体质→选方剂→精细加减） |
| **药材方剂** | 345 味药材（五味归经/炮制区别），271 首经方（剂量/煎煮/禁忌） |
| **医案库** | 癌症、心脑血管、自身免疫病分开归档 |
| **口语化** | 还原倪师讲课风格，通俗直白 |
