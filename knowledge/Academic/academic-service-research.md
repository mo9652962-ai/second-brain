## 二、能力强化

### 论文去AI化 — 新增技巧

基于知网5.0的检测逻辑，强化去AI味能力：

**技巧一: 打破"过于顺畅"的逻辑**
```
❌ "本研究采用问卷调查法，收集了500份有效问卷，然后进行了统计分析。"
   → 结构太完整，AI味重

✅ "在500份有效问卷的基础上，本研究尝试通过统计分析寻找答案。
   问卷调查法的选择，是基于..."
   → 语序调整，先摆结果再解释
```

**技巧二: 避免绝对判断句**
```
❌ "这直接导致了..." → 语气太肯定
✅ "数据似乎表明..." → 留有余地
✅ "这可能意味着..." → 条件性表达
✅ "在一定程度上..." → 修饰限定
```

**技巧三: 打断固定结构**
```
❌ "背景—分析—结论" 固定三段
✅ 结论先行 → 补充背景 → 解释分析
```

### PPT — 新增方法论

基于2026行业趋势，强化PPT制作：

**原则一: 数据叙事 (Data Storytelling)**
```
不只是一个图表，而是一个故事线：
问题 → 数据揭示 → 洞察 → 行动
```

**原则二: 手机优先**
```
2026年超60%的PPT首次在手机上打开
→ 字号 ≥ 18pt
→ 单列排版
→ 每页一个核心信息
```

**原则三: 暖色极简**
```
暖色调 + 柔和形状 + 充足的留白
避免冷白色背景、高对比色
```

## 五、新增/优化的服务流程

### 论文服务流程（强化版）

```
用户提交论文/需求
  ↓
① AI率检测（工具）
  ↓
② Grill 需求对齐（你问清楚：期刊要求？字数？风格？）
  ↓
③ 全文分析（paper-parse 深度研读）
  ↓
④ 去AI化润色（chinese-academic-writing + sci-paper-three-pass）
    ├── 打破固定逻辑结构
    ├── 委婉化绝对判断
    └── 优化句式多样性
  ↓
⑤ 格式排版（引用格式/图表/标题）
  ↓
⑥ 最终检测 → 交付
```

### PPT服务流程（强化版）

```
用户提供材料/需求
  ↓
① Grill 对齐（场景？受众？风格？数据？）
  ↓
② 内容策划（cn-ppt-outline-writer → 大纲）
  ↓
③ 设计生成（pptx-generator + academic-presentation）
    ├── 暖色极简风格
    ├── 手机优先排版
    └── 数据叙事线
  ↓
④ 配图方案（AI图片生成 or CC图源）
  ↓
⑤ 演讲备注（逐页演讲词）
  ↓
⑥ 优化审查（ppt-optimizer → 评分 > 60）
  ↓
⑦ 交付
```
