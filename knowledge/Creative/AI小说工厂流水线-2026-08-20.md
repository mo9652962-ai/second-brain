## 视频核心信息

一个**开源 AI 小说生产工作流**——把「写书那点事」拆成流水线，用户不用动技术，选一条线剩下全是 AI 的事。

### 流水线组成（SenseVoice 增强转写提取，错字已修正）

| 环节 | 说明 |
|:---|:---|
| 世界观构建 | 设定生成 |
| 角色创建 | 人物卡 |
| 章节生产 | **32 个节点全接好，单章全自动** |
| 大纲规划 | 全文大纲 |
| 章节润色 | 正文优化 |
| 章节后验 | 质量把关 |

- **36 个小说专家**（prompt/agent 角色：设定/角色/伏笔/人设专人负责）
- **34 维度设定**——写几十万字不崩（视频原话「四维度设定」口误可能）
- **开源不花一分钱**，开箱直接用

### 实测结构核验（2026-08-20 clone 4 个候选）

| 项目 | 语言/形态 | 大小 | 依赖 | 运行 |
|:---|:---|:---|:---|:---|
| sumeru | 纯 Skills 包（CLAUDE.md+skills/）| 323K | Python 3.11+ / Node 20（部分脚本）| Claude Code/OpenCode 加载；⚠️ 声明 macOS/Linux zsh |
| ainovel-cli | **Go**（修正：不是 Python！）| 15M | Go 构建 or 官方 release 二进制 | `ainovel-cli` 一键安装/Docker；Windows 有 release |
| ai-novelist | Claude Code 版 | 14M（含样例小说）| Node | Claude Code 加载，有 novels/ 样例 |
| LangGraph 版 | Python + langchain/gradio | 7M | langchain 全家桶（重）| `python app_gradio.py`，本地+API 双模式 |

**结论**：视频「7 条产线」= sumeru 7 模块（高度吻合）；ainovel-cli 最火最成熟（Go 全自动引擎）；LangGraph 版依赖重价值低。
