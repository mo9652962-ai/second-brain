# 接单工作流 SOP

## 一、接单前

### 1.1 咨询响应模板
```
您好，请问需要什么服务？
- 论文降重/降AI率
- PPT代做（学术/商务）
- 数学练习册定制
- PCB设计

请提供以下信息：
1. 字数/页数/具体要求
2. 截止时间
3. 预算范围
```

### 1.2 报价标准
| 服务 | 单价 | 备注 |
|------|------|------|
| 论文降AI率 | 30元/篇 | 笔灵3元/千字成本 |
| PPT代做 | 30-80元/份 | 按页数和复杂度 |
| 数学练习册 | 35元/份 | 40天定制版 |
| PCB设计 | 50-800元 | 按复杂度 |

### 1.3 需求确认清单
- [ ] 客户提供原始文件
- [ ] 确认目标平台（知网/维普/万方）
- [ ] 确认截止时间
- [ ] 确认交付格式
- [ ] 确认付款方式（先付50%定金）

## 二、执行中

### 2.1 论文降AI率
1. 客户提供原文 → 确认字数
2. 选择工具：**零感AI（主力，1元/千字）**，笔灵AI（备用，3元/千字）
3. 处理流程：
   - 先用零感AI初降（77.3%→3.6% 平均水平）
   - 人工复核语义
   - 目标平台复检确认
   - 如需补充，用笔灵AI精修
4. 交付前自检：AI率<10%，语义保留>90%

### 2.2 PPT代做
1. 确认主题和页数
2. 使用 python-pptx 生成 + 暖色极简风格
3. 交付 .pptx 文件

### 2.3 数学练习册
1. 确认年级/天数/题型
2. 运行 generate_math_workbook_standard.py
3. 交付 .docx 文件

### 2.4 PCB设计
1. 确认需求（层数/功能）
2. 使用 EasyEDA Pro + jlcmcp MCP
3. 交付 Gerber 文件

## 三、交付后

### 3.1 交付清单
- [ ] 发送最终文件
- [ ] 确认客户收到
- [ ] 收尾款
- [ ] 请求好评
- [ ] 记录到 Obsidian（接单记录模板）

### 3.2 好评话术
```
亲，如果满意的话麻烦给个好评哦~ 
有任何问题随时联系我修改，感谢支持！
```

## 四、工具速查

| 工具 | 用途 | 成本 |
|------|------|------|
| 笔灵AI | 降AI率 | 3元/千字 |
| 零感AI | 降AI率 | 1元/千字 |
| python-pptx | PPT生成 | 免费 |
| python-docx | Word生成 | 免费 |
| EasyEDA Pro | PCB设计 | 免费 |
| jlcmcp MCP | PCB自动化 | 免费 |

## 五、风险控制

- 论文类：交付前必须自检，不留AI痕迹
- PPT类：先发预览图，确认后发源文件
- PCB类：DRC检查必须通过
- 所有订单：先收定金再开工
