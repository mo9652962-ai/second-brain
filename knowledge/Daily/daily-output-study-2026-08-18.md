## 二、核心洞察（Research）

### 洞察 1：SRC 挖洞 = 信息收集的战争（80% 时间）
```
今天反复验证的结论: 挖洞的核心不是技术多强，是资产找得比别人全
  → 边缘资产/新业务/测试环境 = 别人漏掉你捡起来
  → 扫描前探针 10 秒省几小时无效扫描
  → 4 类通吃漏洞: 越权/敏感泄露/权限绕过/配置泄露
```

### 洞察 2：企业 SRC 的「规则差」= 赏金差
```
同类漏洞 A 厂中危 B 厂不算漏洞 → 摸清各家偏好是首要任务
  → 腾讯=逻辑漏洞 / 阿里=高危权重 / 字节=批量>单点
  → 降级自查清单（提交前过一遍能少踩 80% 的坑）
```

### 洞察 3：去 AI 味 = 「扮演」> 「拒绝」
```
小黑盒帖主核心观点: 拒绝低质量回答的 prompt 会变成新 AI 味
  → 最好办法是私人化角色塑造（nuwa-skill 蒸馏自己）
  → 5 技能工作流: 检测 → 去套话 → 改人话 → 提质感 → 统一文风
```

### 洞察 4：内容创作 = 可复制的系统
```
AI 漫剧: 3 小时出片流水线（豆包+即梦+剪映免费三件套）
  → 题材选「AI 悬疑反转」贴合 AI 博主定位（矩阵联动）
  → 60 秒 10 镜 = 新手可完成的最小闭环
```

### 洞察 5：工具选择 = 看场景不看名气
```
Lossless Scaling（29 元）: 适合骑砍2 老游戏/Sims4 CPU 瓶颈
  不适合 inZOI（显存 9GB > 4060 的 8GB + 自带 DLSS FG）
  → 结论: 先确认自己的使用场景再买
```
