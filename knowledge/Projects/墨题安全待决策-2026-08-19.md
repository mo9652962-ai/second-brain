## 待决策项

### ① 用户隔离 / 额度控制（BOLA/IDOR）
- **问题**: 墨题无 user 体系，所有接口全局共享数据（考试记录/词库/AI 对话/配置）
- **现状**: 本地/局域网单用户使用无影响；多人云端部署时隐私泄露 + 额度盗刷
- **方案**: 引入 user 表 + token 鉴权 + 所有业务表加 user_id + 管理接口 Admin Only
- **成本**: 大工程（涉及全库 schema + 所有路由 + 前端登录）
- **决策**: 等有真实多人部署需求再做

### ② DPAPI 跨平台（Windows 绑定）
- **问题**: security.py 用 ctypes.windll.crypt32（CryptProtectData）加密 API Key，Linux/Docker 部署直接崩
- **现状**: 墨题是 Windows 桌面应用，无影响
- **方案**: Linux 下用 cryptography.fernet + 环境变量主密钥降级
- **成本**: 中等（改 security.py 加平台分支）
- **决策**: 等有 Linux 云端部署计划再做
