- 本地处理（不上传）；版权：自有 PDF 转个人笔记合法
- **对 sora**：考研真题/英语教材/技术书 → 转技能 = 以后写代码/备课直接调用

### TencentDB-Agent-Memory（验证）
- 四类资产 = sora 现有体系的映射：
  - Chat Memory ↔ Hermes memory（MEMORY.md/USER.md）
  - Skill ↔ Hermes skills（技能库）
  - LLM-Wiki ↔ Obsidian 知识库（knowledge/）
  - Code-Graph ↔ Obsidian 图谱（graphify）
- 结论：方向正确，无需迁移；可借鉴"换 Agent 也能用"的可移植设计

### airllm（澄清误区）
- 刚删的本地生图模型（Krea2 12GB）是**生图**——airllm 是**文本推理**低显存（按层/专家流式）
- 若以后想本地跑 LLM（如 DeepSeek-V3 671B 在 12GB、Qwen3-235B 在 3GB）→ airllm 可用
- 与云端 API 互补：隐私/离线场景用 airllm，日常用云端
