# 英语刷题机 Android 版竞品研究（千轮研究）

> 参考项目：wssfk12138/android-english-multiple-choice-practice-machine（英语刷题机 Android——我们项目的独立发行版——为竖屏/大屏重新设计）

## 核心结论

**参考项目不是"桌面缩小"而是"移动端重新设计"**——窗口宽度驱动交互密度（平板横屏双栏/手机竖屏/分屏）。这是我们的 Capacitor 版最该借鉴的方向。

## 参考项目关键设计（可借鉴）

### 1. 响应式布局
- 平板大屏：横屏双栏（左文章/右题目）
- 手机/窄窗口：竖屏信息架构
- 支持平板分屏

### 2. 四项底部导航（功能重组）
- **首页 / 笔记 / AI / 设置**
- 错题本 + 单词本 → 笔记入口
- 导入、回收站、更新、帮助、模型配置 → 设置

### 3. 首页按题库动态显示
- 顶部切换题库
- 只显示当前题库**实际存在**的听力/完形/阅读/Part B 入口（无听力不显示听力）
- 试卷列表只显示名称；词汇回顾五秒一组上下翻页

### 4. 竖屏练习上下分区
- 上方文章/听力控制区 + 下方题目/选项区——**独立滚动**
- 中间**分隔条可拖动**（调整上下占比）

### 5. 紧凑工具栏
- 退出/计时/答题卡/更多 = 图标按钮
- 答题卡从顶部打开抽屉
- 底部集中：单篇提交 + 整卷提交（不挤压选项）

### 6. 笔记组织
- 错题本：题库配置 → 年份 → 篇目
- 单词本：跨题库共享

### 7. AI 对话（竖屏优化）
- 填充导航栏与状态栏之间区域
- 模型选择器靠近发送按钮
- 长消息不撑宽页面

### 8. 更新机制（完整）
- `android-update.json` 清单：schemaVersion/versionName/versionCode/apkUrl/apkSha256/releaseNotes
- GitHub Release 优先 + 2 个 HTTPS 镜像回退（ghproxy.net / gh-proxy.com）
- APK 下载后核对大小 + SHA-256 → 系统安装器确认
- 固定签名（signing.properties.example——私钥本机）

### 9. 题库导入
- ESQ 1.0/1.1 导入/预览/校验/冲突确认/导出
- DOC/DOCX/PDF + MP3/M4A/WAV/OGG 听力
- 模型辅助定位题目（只改草稿——用户批准才入库）
- 智能标注（按本次/年份/全部——听力不发送）
- 扫描版 PDF 明确提示人工 OCR（不伪装成功）

### 10. 练习判分
- 稳定选项键判分（不受显示顺序影响）
- 可选计时；暂停只停计时
- 未答完阻止提交并定位第一道未答
- 单篇提交即时得分；整卷提交整卷成绩
- 听力不显示原文/不做分析/整段提交

## 我们（墨题）的差距分析

| 维度 | 墨题（Windows+Capacitor） | 参考 Android 版 | 修正优先级 |
|:---|:---|:---|:---|
| 移动端布局 | 5 项导航（首页/题库/笔记/报告/设置）| 4 项（首页/笔记/AI/设置）| 中 |
| 首页 | 名言+推荐卡片+今日目标 | 按题库动态显示入口 | **高** |
| 练习竖屏 | 单栏滚动 | 上下分区+分隔条 | **高** |
| 工具栏 | 题号导航+按钮 | 紧凑图标+答题卡抽屉 | 中 |
| 更新 | GitHub tag 检查 | 清单+SHA-256+镜像回退 | **高** |
| AI 入口 | 设置内 | 独立导航+竖屏优化 | 中 |
| 主题 | 水墨（特色保留）| 米白宣纸/蓝紫星空 | 低 |

## 借鉴执行建议（2026-08-10）

3. **更新增强**（高）：GitHub 检查升级为清单+镜像+SHA-256
4. **AI 独立入口**（中）：移动端导航加 AI 入口
5. **工具栏紧凑化**（中）：答题卡抽屉
