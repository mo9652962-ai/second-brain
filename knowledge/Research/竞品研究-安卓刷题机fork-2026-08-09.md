# 竞品研究：安卓版刷题机（wssfk12138 fork）2026-08-09

> 来源：GitHub wssfk12138/android-english-multiple-choice-practice-machine（**我们的 fork**，2026-08-04 从 f76f113 独立）

## 定位确认

- 对方 = 我们项目的 **Android 衍生版**（Capacitor + 同一 ESQ 格式 + 独立 Git/版本/发布通道）
- 对方独立后专注：竖屏优化 + 导入增强 + 听力 + 错题迭代 + 安全存储
- 开发成本：20 亿 token ≈ 200 元，一周（Codex 驱动）

## 对方亮点 → 可回收清单（优先级排序）

| # | 对方功能 | 我们的现状 | 回收价值 |
|:--|:---|:---|:---|
| 1 | **听力音频支持**（MP3/M4A/WAV/OGG 导入+播放+计时禁拖进度条+听力不显示原文）| ❌ 无听力数据/音频 | 🔥 最高（用户刚要求听力）|
| 2 | **选项打乱**（判分用稳定键不受显示顺序影响）| 需查 | 高 |
| 3 | **错题迭代**（重做只显示这次错的，越做越少+高频/近期权重）| 部分 | 高 |
| 4 | **长按选词入单词本**（后台翻译+语境释义+高频🌟）| 部分 | 高 |
| 5 | **模型辅助导入**（模型定位题目/答案+用户逐字段校对+智能标注）| 手动 | 中 |
| 6 | **多 API 配置 + Keystore/AES-GCM 安全存储** | APK 明文 key | 中（安全）|
| 7 | **同义/反义/形近词辨析** | 字段有但前端未展示 | 中 |
| 8 | **更新 SHA-256 校验** | 仅大小 | 低 |
| 9 | **ESQ 1.1**（如有升级）| ESQ 1.0 | 需查 |

## 我方优势（对方没有）

- ✅ **标注笔记**（关键词高亮 + 笔记持久化 + 标签/导出/复习/统计）——差异化核心
- ✅ Gamification（学习报告/雷达/排行/专注/日历/目标）
- ✅ 水墨 UI 主题
- ✅ 桌面 + 网页 + 移动三端（对方仅安卓）

## 决策建议

1. **回收听力**（对方思路：导入时含音频附件 + 播放器 + 计时限制）——解决我们"听力无数据/无音频"的短板
2. **回收选项打乱**（简单高价值——防记答案）
3. **回收错题迭代**（成熟逻辑）
4. 标注笔记**保持我们的差异化**（对方无）
