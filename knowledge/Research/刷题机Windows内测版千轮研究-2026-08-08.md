## 二、技术方案（沿用现有，已验证）

```
Vue3 + Vite + sql.js (前端纯静态)
  ↓ electron-builder 打包
Electron main.js (spawn 后端 + autoUpdater)
  ↓ PyInstaller onedir
FastAPI backend_app.exe (EPM_DATA_DIR 隔离数据)
```

**选择理由**（研究验证）：
- Electron + electron-updater = 行业标准（差分更新 + GitHub Releases 集成）
- 前端 sql.js = 数据本地化（无服务器依赖，内测分发简单）
- 后端 PyInstaller = 免 Python 依赖（standalone_main.py v9.20.1 已验证）

## 四、Windows 安全协议（防杀软误报）⭐

### 4.1 核心原则（微软官方文档 + 2026 实践）
1. **数据放用户目录**（%APPDATA% 或 %LOCALAPPDATA%），不写 C:\Windows / Program Files
2. **不加开机自启**（无提示自启 = 高危信号）
3. **不收集隐私**（不读浏览器历史/通讯录）
4. **标准安装器**（NSIS——electron-builder 默认）
5. **代码签名**（最核心）：
   - 内测阶段：自签名证书 + 文档说明"首次运行 SmartScreen 提示属正常"
   - 正式发布：OV 证书（约 ¥2000/年）+ RFC3161 时间戳
   - **EV 证书不再绕过 SmartScreen**（微软 2026 确认）——不必多花钱
6. **SmartScreen 信誉**：签名 + 时间戳 → 提交微软 SmartScreen 门户积累信誉
7. **发布前自扫**：VirusTotal 多引擎扫描（确认无引擎误报）
