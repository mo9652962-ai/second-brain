# 双轨闭环路线图：SKiDL 原理图 → 网表 → EasyEDA 网络保留

> 2026-08-08 验证结论：KiCad PCB 直接导入 EasyEDA = **36 元件保留但网络丢失**（纯 PCB 无网表）。要保留网络必须走原理图 → 网表路径。
> **2026-08-08 第二阶段：SKiDL 符号库兼容性验证通过（13/13）**——KiCad 10 符号库经 KICAD10_SYMBOL_DIR 可用，footprint 经 KICAD10_FOOTPRINT_DIR 可用。

## 下次执行步骤（完整闭环）

```
① SKiDL 定义电路（aircon.sch.py）
   - 36 元件 + 真实网络（V12/V5/GND + 控制信号 + 继电器触点 AC 网络）
   - 注意：SKiDL 2.3.0 需 KiCad 符号库（.kicad_sym / legacy .lib）

② SKiDL 生成网表 + PCB
   - generate_netlist() → .net 网表文件
   - generate_pcb() 或 KiCad 导入网表 → PCB 带网络

③ 自动布线（KiCadRoutingTools）— 网络已真实存在，布线即连接
   - 需要先分配 pad 网络（替代手写 add_nets.py——SKiDL 网表自动带）

④ 导出 KiCad 工程 zip（含网表/原理图）
   - KiCad File → Archive 打包（含符号/封装库）

⑤ EasyEDA Pro 导入 zip → 网络应保留
   - 验证：pcb_get_state 应显示 nets: V5/GND/V12/...
```

## 关键坑（已踩）

1. **纯 PCB 导入丢网络**——必须带网表（原理图）导入
2. ~~SKiDL 符号库兼容性~~ ✅ **已验证通过（2026-08-08）**：设 KICAD10_SYMBOL_DIR + KICAD10_FOOTPRINT_DIR 后 13/13 符号可加载（R/C/D/Q_NPN/AMS1117/74HC595/Relay_SPDT/SW_Push/CA56-12SRWA/Conn_01x04/Buzzer/Fuse/L）；**MCU STC8H 无标准库**（8051 内核，用 MCU_AnalogDevices 的 ADuC8xx 替代或自定义符号）；保险丝在 Device:Fuse
3. 继电器触点 AC 网络（220V L/N）在 KiCad 里需要独立网络（强电网络与弱电分开）——网表设计时注意
