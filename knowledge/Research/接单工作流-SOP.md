# 接单工作流 SOP

## 一、接单前

### 1.1 咨询响应模板
```
您好，请问需要什么服务？
- 论文降重/降AI率
- PPT代做（学术/商务）
- 数学练习册定制
- PCB设计

请提供以下信息：
1. 字数/页数/具体要求
2. 截止时间
3. 预算范围
```

### 1.2 报价标准
| 服务 | 单价 | 备注 |
|------|------|------|
| 论文降AI率 | 30元/篇 | 笔灵3元/千字成本 |
| PPT代做 | 30-80元/份 | 按页数和复杂度 |
| 数学练习册 | 35元/份 | 40天定制版 |
| PCB设计 | 50-800元 | 按复杂度 |

### 1.3 需求确认清单
- [ ] 客户提供原始文件
- [ ] 确认目标平台（知网/维普/万方）
- [ ] 确认截止时间
- [ ] 确认交付格式
- [ ] 确认付款方式（先付50%定金）
- [ ] 确认客户是否面向 EU 市场（涉及则先做 EU AI Act 风险分级）

### 1.4 方案论证（CoPlan 可争辩论证）⭐ 2026-08-08 新增
**原则**：先给方案草案 → 明确请客户反驳 → 迭代收敛（比单向确认高效）

```markdown
交付前发：
## 方案草案
- 我计划这样做：<方案>
- 关键假设：<假设1、假设2>
## 请您反驳
- 哪里不符合预期？哪个假设不成立？
- 有更好的方向请直接说
```

**触发**：报价确认后、动工前，复杂度中高（PPT 架构/PCB 方案/论文结构）必须走此流程；简单单（30 元降重）可跳过。

### 1.5 客户隔离（Hermes profile）⭐ 2026-08-02 新增
**原则**：每个客户一个独立 profile，上下文永不串单。

```bash
# 接新单时（一次性）
hermes profile create client-XX --description "客户XX：<服务类型>，<主题>，<截止>"

# 该客户工作期间
hermes -p client-XX        # 用客户专属会话处理
```

**验证过的隔离机制**（2026-08-02 P2 实测）：
- 每个 profile 有独立 memories/sessions/cron/skills/workspace
- client-1 写入客户数据 → default 全局记忆 0 匹配 ✅
- 跨 profile 写记忆需显式确认（cross_profile guard 软保护）

**何时用**：
- ✅ 论文降重（客户原文 + 关键词敏感）
- ✅ 定制练习册（学校/年级信息）
- ⚠️ 简单 PPT/PCB 可不用（无敏感上下文）
- 交付后：客户资料留在 profile 内，不清理（可复用老客户关系）

## 二、执行中

### 2.1 论文降AI率
1. 客户提供原文 → 确认字数
2. 选择工具：**零感AI（主力，1元/千字）**，笔灵AI（备用，3元/千字）
3. 处理流程：
   - 先用零感AI初降（77.3%→3.6% 平均水平）
   - 人工复核语义
   - 目标平台复检确认
   - 如需补充，用笔灵AI精修
4. 交付前自检：AI率<10%，语义保留>90%

### 2.2 PPT代做
1. 确认主题和页数
2. 使用 python-pptx 生成 + 暖色极简风格
3. 交付 .pptx 文件

### 2.3 数学练习册
1. 确认年级/天数/题型
2. 运行 generate_math_workbook_standard.py
3. 交付 .docx 文件

### 2.4 PCB设计
1. 确认需求（层数/功能）
2. 使用 EasyEDA Pro + jlcmcp MCP
3. 交付 Gerber 文件

## 三、交付后

### 3.1 交付清单
- [ ] 发送最终文件
- [ ] 确认客户收到
- [ ] 收尾款
- [ ] 请求好评
- [ ] 记录到 Obsidian（接单记录模板）
- [ ] （如用了 profile）在 client-XX 记忆里更新交付状态，便于老客户复购时快速调出上下文

### 3.2 好评话术
```
亲，如果满意的话麻烦给个好评哦~ 
有任何问题随时联系我修改，感谢支持！
```

## 四、工具速查

| 工具 | 用途 | 成本 |
|------|------|------|
| 笔灵AI | 降AI率 | 3元/千字 |
| 零感AI | 降AI率 | 1元/千字 |
| python-pptx | PPT生成 | 免费 |
| python-docx | Word生成 | 免费 |
| EasyEDA Pro | PCB设计 | 免费 |
| jlcmcp MCP | PCB自动化 | 免费 |
| qwen-image-3.0-pro（百炼） | PPT/素材配图 | 0.25元/张（中文文字渲染强，可商用） |

## 五、风险控制

- 论文类：交付前必须自检，不留AI痕迹
- PPT类：先发预览图，确认后发源文件
- PCB类：DRC检查必须通过
- 所有订单：先收定金再开工
