## 🥇 Top 发现

### 1. ChainDrop npm 供应链攻击（已应用到本地安全检查）

**事实**（Chainguard/Snyk/Socket 三源验证）：
- 8/4 攻击者攻陷 keyv 维护者 GitHub 账号 → 发布恶意版本：`keyv@6.0.0`、`cacheable-request@13.0.20`、`cache-manager@7.2.10`、`@cacheable/utils@2.5.1`、`flat-cache@6.1.24`（9 包家族）
- 恶意特征：包内加 `setup.mjs` + `Math_Symbol.js` + `"preinstall": "node setup.mjs"` → npm install 时自动执行
- 行为：Bun 混淆载荷 → 窃取 npm/GitHub/AWS/K8s/Vault 凭据 → 用窃取 token 自动重打包发布（蠕虫式传播 400-2200 包）
- C2 域名：`npm-cache[.]com` / `pypi-get[.]com` / `js-mirror[.]com`；回退通道：GitHub 仓库 `Shai-Hulud: Here We Go Again`

**本地 apply（已执行）**：
- 扫描刷题机 frontend + Hermes ui-tui + apps 的 node_modules → **无 setup.mjs 恶意特征，干净** ✅
- 刷题机 package-lock 无 keyv/flat-cache/cache-manager 依赖 ✅
- 唯一 Math_Symbol.js 是 regenerate-unicode-properties（babel Unicode 数据）正常文件，非恶意

**教训入库**：npm 依赖有 lock 还不够——preinstall 钩子在 install 时执行，特征文件扫描（setup.mjs/Math_Symbol.js）+ 锁定已知恶意版本号是有效检测手段。

### 2. Cloudflare OS — 企业 AI 工作平台设计原则（可迁移）

**事实**（Cloudflare 官方博客）：
- 用 Workers + Access 自建内部 AI 平台，数千员工使用
- 五原则：① AI 服务客户优先（先定义 jobs-to-be-done）② 人人有超能力 ③ **人负责输出**（AI 是工具不是团队成员）④ **组织上下文比模型重要** ⑤ **AI 权限不扩大**（用 AI 时权限 ≤ 本人权限）
- 魔法邮件别名 → 收集用户不想做的工作 → 沉淀 skills → 平台化（与 Hermes 的 skill 模式同构！）
