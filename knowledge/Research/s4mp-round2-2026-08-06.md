# S4MP 第二轮深研 - 消息路由 + 连接生命周期

> 2026-08-06 反解 message_handler, timed_task, client_overrides, distributor_overrides

## 核心发现：S4MP 不是定时轮询，是拦截引擎消息流

### 架构对比

```
SimSync (当前):
  游戏 → 定时轮询(500ms alarm) → collect_* → pickle 广播 → 客机 receive

S4MP:
  游戏 → 引擎 Client.send_message → Override 拦截 → 过滤 LOCAL_ONLY → 
  GameNetworkMessageManager.send_message_over_network → 客机 engine.send_message
```

S4MP 直接 Hook EA 引擎的 `Client.send_message`，**零延迟、不丢帧**。我们的轮询有 500ms 延迟 + 可能丢帧。

## 5 个可借鉴模块

### 1. MessageHandler - 消息路由
```python
class MessageHandler:
    def __init__(self, message_class, override_type):
        # 根据 protobuf 类名自动生成消息类型名
        self._target_message_type = camel_to_snake(message_class.__name__)
        # ⚠️ 关键：注册到连接生命周期事件！
        NetworkClient.on_connect_finished += self._start_override
        NetworkClient.on_close += self._stop_override
```
**借鉴**：连接建立时动态注册消息处理器，断开时自动取消。

### 2. TimedTask - tick 驱动（🔥 解决 alarm error 的答案！）
```python
class TimedTask:
    def __init__(self, tick_seconds, override_type):
        # 注册到 CoreServicesHooks.on_tick（游戏主循环 tick）
        CoreServicesHooks.on_tick += self._wrapped
```
**借鉴**：用 `on_tick` 替代 `add_alarm_real_time`。**on_tick 不依赖 TimeService**，主菜单阶段也能正常工作！这就是我们 alarm error 的正确解法。

### 3. ClientOverrides - 引擎消息拦截（🔥 架构革命）
```
Override(Client.send_message, Override.Type.SERVER)
→ 拦截主机发给引擎的消息
→ 过滤 LOCAL_ONLY_OPS
→ 其余通过 GameNetworkMessageManager 发给客机
→ 客机收到后直接用引擎 omega.send 注入

Override(Client.send_message, Override.Type.CLIENT)  
→ 拦截客机发给引擎的消息
→ 过滤 SERVER_ONLY_OPS（Buy 模式）
→ 只通过 BUY_ALLOWED_CLIENT_OPS
```
**这是根本性的架构差异**——S4MP 不"同步数据"，而是**劫持引擎的消息管线**。

### 4. Distributor Overrides - 批量操作
白名单模式累积 ViewUpdate → 合并在一个 protobuf 帧发送

### 5. NetworkClient 事件生命周期
```
on_connect_finished → on_message(循环) → on_close → schedule_reconnect → on_connect_finished
```
每个连接生命周期事件触发注册/取消回调——零状态残留。

## 对 SimSync 的增强方案

| 优先级 | S4MP 模式 | SimSync 实施 | 收益 |
|:------:|:----------|:------------|:-----|
| 🥇 | on_tick 替代 alarm | 用 CoreServicesHooks.on_tick 替代 add_alarm_real_time | **解决 alarm error + 10054 断开** |
| 🥈 | 连接生命周期事件 | on_connect_finished/on_close 回调注册 | 解决状态残留 + 重连 bug |
| 🥉 | MessageHandler 动态路由 | _process_incoming 注册/取消回调 | 代码解耦 |
| 4 | 引擎消息拦截 | Override Client.send_message | 零延迟同步（长期） |
| 5 | 批量消息累积 | Distributor ViewUpdate 合并 | 带宽优化 |
