## 洞察① KiCad SWIG 绑定将废弃，PCB 自动化要迁 IPC API

### 原始表述 ✅ 准确但有更新

| 我的原文 | 官方实锤 |
|:---|:---|
| 9 deprecated / 11 移除 | 官方文档「SWIG binding deprecated in KiCad 9.0，**removed in KiCad 11.0**」 |
| 迁 kicad-python IPC API | 官方 GitLab 已发布 **kicad-python 9.0.0-rc1** 正式版，PyPI 可安装 |

### 关键新发现

**KiCad 11.0 nightlies（2026-03-22 起）已正式移除 SWIG Python 绑定！** devlist 公告确认「不再内置 Python」「Windows 安装器新增可选下载上游 Python 的页面」。这意味着：

- **KiCad 10.0.5（你当前版本）是 SWIG 的最后安全期**——11.0 已出 nightly，正式版发布后 SWIG 脚本全废
- IPC API 的**关键新增能力**：`kicad-cli api-server` 提供 headless 模式（无需 GUI 实例），`KiCad` Python 类可自动启动 CLI 服务器
- 当前功能对等：KiCad 9.0 IPC API 覆盖范围 ≈ SWIG Action Plugins 系统（KiCad 5 以来的能力），但**正在积极扩展中**，Plotting（输出 Gerber）已近期加入

### 对你当前体系的影响

```
pip install kicad-python  # 正式可用，PyPI
from kicad import KiCad
kicad = KiCad()  # 自动启动 kicad-cli api-server 或连接运行中实例
```

你的 PCB 自动化脚本（pcb_pipeline.py）用的是 SWIG 的 `pcbnew` 模块——**11.0 正式版发布前必须迁移**，否则脚本全废。IPC API 的 `kicad-python` 替代方案已就绪。

## 洞察② AI Skill 供应链：ClawHavoc 1184 恶意技能

### 原始表述 ✅ 数据准确，但攻击面比知道的更广

| 信源 | 关键证据 |
|:---|:---|
| **Unit 42 Palo Alto**（2026-02→05 持续追踪）| 确认 5 种未拦截恶意技能：infostealer×2、文件大小膨胀绕过扫描、**运行时 affiliate 注入**、agentic front-running（pump-and-dump）|
| **Antiy Labs** | ClawHavoc 定性为「大规模供应链投毒攻击」——攻击者注册 ClawHub 开发者、批量上传伪装合法插件的恶意 Skill |
| **arXiv 2605.11418**（SCH 攻击系统研究）| SKILL.md 是**语义控制面**：embedding 发现操控（86% 胜率）、选择操控（77.6% 倾向恶意变体）、**治理逃逸（36.5%-100% 因策略不同）**——上下文窗口溢出使 87.1% 恶意变体被标为「干净」|
| **CSA 云安全联盟** | 同期 Shai-Hulud 供应链攻击 170 包（含 23 个 MCP 定向包，**每个都有 SLSA Build Level 3 证明**——当前最高级别供应链验证签名）|

### 关键修正与补充

**SCH 攻击（Semantic Compliance Hijacking）** 是比 ClawHavoc 更深层的威胁——**不是恶意代码，而是语义操控**。攻击者只需在 SKILL.md 的描述字段里改几个词，就能让模型在 77.6% 的案例中倾向于选择恶意变体，而 **SAST/SCA/SBOM 全部通过**，因为「恶意」在自然语言语义里，不在代码里。

**对你的意义**：skill-vetter 技能的价值实证更硬了——**我们不是只防 ClawHavoc 式的明恶意，还要防 SCH 式的语义操控**。装外部技能前的审查清单不仅要看代码，还要看 SKILL.md 描述。

## 洞察③ B站算法：完播率权重最高、投币>点赞、搜索长尾资产

### 原始表述 ✅ 成立，且 2026 年有更新

| 维度 | 2026 经验权重 | 你的打法 |
|:---|:---|:---|
| **完播率** | 权重最高（> 30% 合格，> 45% 优秀短视频） | 前 30 秒钩子 + 每 3-5 分钟信息增量 |
| 三连率 | 投币 > 收藏 > 点赞 > 评论 > 分享 | 自然引导「值得投币」而非「一键三连」 |
| 标题 | 核心词提前 + 价值明确 + 少夸张 | 标题前半放搜索词 |
| 封面 | 高质量拍摄 + 主体清晰 + 3 元素以内 | 设计过的封面，非截图 |
| 冷启动 | 新号不再仅推粉丝，分配「潜在兴趣用户」 | 即使粉丝少也能破圈 |

### 2026 年算法特殊变化（从创作者运营经验总结中提取）

- **「不感兴趣」点击率成为重要负向指标**——开篇 3 秒内流失且标记不感兴趣会直接掐断推流
- **信息茧房破除机制**：20% 探索性内容插入，推给「关联兴趣」而非纯标签用户
- **长尾 7-60 天**：15% 优质内容会在发布后 7-60 天因搜索被重新捞起——**B站视频生命周期远长于抖音**
- **搜索流量占比：20-30%**——被忽视的真正长尾资产线
- **算法验证期安全线**（2026 经验值）：3 分钟以上视频完播率 > 35%，点赞率 > 5%

### 对你的直接应用

你做《Agent 操作系统之争》B站视频：
- 标题：**核心词「Agent 操作系统」在前半，钩子在后半**（如「Agent 操作系统之争：Codex 平台化 vs dsh 95K 星，谁定义了 2026？」）
- 前 30 秒：直接抛出冲突——不铺垫，第一句就是「AI 竞争已经从模型层上移到 Harness 层了」
- 投币引导：自然植入「这期值得投币记下来，因为过两个月揭晓答案时还能回来对照」
