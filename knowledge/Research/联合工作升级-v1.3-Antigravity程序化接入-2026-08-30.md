实测成功调用 Antigravity 创建对话（此前只能人工 IDE 操作）：

```bash
export ANTIGRAVITY_LS_ADDRESS=http://127.0.0.1:63224   # gRPC 端口（非 63223 HTTP）
export ANTIGRAVITY_CSRF_TOKEN=<main.log 的 --csrf_token= 值>  # 动态生成
export ANTIGRAVITY_PROJECT_ID=<~/.gemini/config/projects/*.json 的 id>
```

## 典型工作流（"错题收藏功能"为例）

```
sora → k（接收目标）
  ├─ GPT：需求分析/接口设计/验收标准（人工）
  ├─ Codex：后端 API/数据结构/测试（CLI）
  ├─ Antigravity：页面/交互/浏览器验证（agentapi 或人工）
  └─ 共享记忆：开工查记忆池、干完写回
k → 汇总核验（接口字段不一致→派修复）→ 沉淀技能 → sora 决策
```

## 边界

- Hermes 不能凭空控制 Antigravity IDE 内部——需要 agentapi/MCP/浏览器接口（agentapi 已通，技能加载缺口待后续研究）
- GPT/Gemini 是人工中转——设计流程时把"sora 贴网页"当已知延迟
- 所有外部产出过 k 手才进沉淀
