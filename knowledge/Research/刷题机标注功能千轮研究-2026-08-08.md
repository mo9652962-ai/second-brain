# 做题标注功能 · 千轮研究（关键词 + 笔记持久化）

> 3 轮 × 9 路搜索：竞品标注拆解 + 文本锚定技术 + 存储方案。**结论：文本偏移锚定 + SQLite 持久化 + 气泡交互。**

## 竞品借鉴（标注/笔记功能）

| 竞品 | 标注能力 | 我们借鉴 |
|:---|:---|:---|
| 薄荷阅读 | 双击查词不打断 + 讲义精读 | 双击查词交互 |
| 墨墨 | 我的例句 + 我的助记 | 用户自定义记忆注记 |
| 豆瓣阅读 | PC 划线 + 独立笔记页 | 笔记集中管理 |
| Reeden | 划线扩展 + 荧光样式 + 生词本 + 笔记全文搜索 | 荧光半高样式；笔记可编辑 |
| web-notes | 4 色高亮 + Markdown 笔记 + 三级锚定恢复 | **三级锚定策略（核心参考）** |
| epub.js | EpubCFI 锚定 + highlight/underline/mark | cfiRange 锚定思想 |

## 技术选型（落地）

1. **锚定**：`getSelection()` + Range → 存 `{start_offset, end_offset, text, prefix, suffix}`（纯文本偏移 + 上下文）——文章是固定文本渲染，偏移量足够，比 XPath 简单可靠
2. **存储**：后端 SQLite 表 `annotations`（unit_id 关联，本地持久化，跨端同步未来可扩展）
3. **渲染**：加载时按 offset 切段 → `<mark class="annotation">` 高亮
4. **交互**：选中文字 → 标注气泡（高亮 / 高亮+笔记）；点击已标注 → 查看/编辑/删除；移动端长按

## 数据模型

```sql
CREATE TABLE annotations (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  unit_id INTEGER NOT NULL,
  start_offset INTEGER NOT NULL,
  end_offset INTEGER NOT NULL,
  text TEXT NOT NULL,
  note TEXT DEFAULT '',
  color TEXT DEFAULT 'amber',
  created_at TEXT DEFAULT (datetime('now','localtime')),
  updated_at TEXT
);
CREATE INDEX idx_annotations_unit ON annotations(unit_id);
```
