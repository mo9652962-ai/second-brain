# AI 科研协作：110 亿 Token 的经验

来源：小黑盒 "吃太饱骑士"
更新：2026-07-25

## 核心问题
当前 AI 工具（Web/本地）都不是为科研设计的：
- **Web 端**：数据松散，对话间缺乏逻辑关系，靠人工复制粘贴维护上下文
- **本地软件**：主要是 Vibe Coding 工具，面向开发/办公，不对科研做特殊优化

## 科研项目的 5 个组件

作者从 AI 协作视角将科研项目解耦为：

| 组件 | 作用 |
|:-----|:------|
| **对话** | AI 协作的入口 |
| **文件** | 承载数据等信息 |
| **文献** | 统筹管理参考文献 |
| **实验资源** | 记录实验室仪器和条件，让 AI 给贴合实际的方案 |
| **记忆** | 跨对话可复用的核心知识，随项目推进更新迭代 |

## 实用技巧

### Skill 构建方法
1. 选项目方向 5-10 篇权威文献 → AI 锚定术语和含义
2. 选目标期刊 5-6 篇高引文献 → AI 归纳写作风格，沉淀为 Skill
3. 效果：八九不离十

### 索引文件的局限
- 项目变大后，索引文件本身需要架构 → 套娃
- AI 无法同时完成研究任务和更新索引（缺乏"旁观者"视角）

## 工具推荐
- 作者自研：**Jadense**（jadense.com），科研原生设计
- Codex Desktop（GUI 友好，非编程人士适用）
- ❌ 不推荐 Claude Code TUI（对话切换和消息浏览不方便）
