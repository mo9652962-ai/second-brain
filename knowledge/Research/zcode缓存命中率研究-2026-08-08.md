# zcode 中转站 + 缓存命中率研究 · 2026-08-08

> 来源：小黑盒帖子（codexplus→zcode，3亿token 2元，99%缓存命中）+ 多源验证。learn→research→apply。

## 核心结论

**缓存命中率是 Coding Agent 成本的命脉（50 倍价差）——帖子"3 亿 token 2 元"完全可能（官方直连验证过同等量级）；zcode 本身无公开评测需小额实测；"luna"不是中转站而是 GPT-5.6 Luna（OpenAI 新模型，视觉能力强）。**

## 事实（多源验证）

### 缓存命中率 = 成本命脉（硬数据）
- DeepSeek v4-flash 定价：未命中 $0.14/M vs **命中 $0.0028/M = 50 倍差**
- 官方直连案例：2.5 小时 8000 万 token，99.41% 缓存率 → **仅 4 元**；单日 278 亿 token → 160 美元（同量级 Claude 约 11076 美元）
- DeepSeek-Reasonix（开源）：围绕缓存稳定性重设计 Agent 循环 → 99.82% 命中，单日 4.35 亿 token 花 $1.38（无缓存 $61）
- **DeepSeek 官方 8/2 硬盘缓存公告**：命中 0.1 元/M，比 flash 的 cache_read 更低；API 返回 `prompt_cache_hit_tokens` / `prompt_cache_miss_tokens` 可实时监测

### "luna"真身
- **GPT-5.6 Luna**（OpenAI）：降价 80%、比 DeepSeek 便宜一半、**支持视觉理解 + 工具调用**、能力边界更宽——帖子作者说"luna 可以辅助下"= 用 Luna 补视觉
- 评论区"转 luna 了，中转站太便宜"= 中转站卖 Luna 便宜

### zcode（帖子主角）
- 声称：3 亿 token 2 元、缓存命中率 99%、干了很多活（codexplus 100+ 元/月 → 2 元）
- **无公开评测**（搜索无结果）——小众站，需实测验证真实性

### 中转站避坑（relayAPI 评测共识）
- **跑路风险**：用多少充多少，不存大额
- 缓存价格：正常 10%，黑心站收 15-30%（隐形收费点）
- 警惕异常低价模型（拿 GLM 等冒充国外高价模型）
- 优先公司运营、有群、账单清晰
