# 笔记功能增强 · 千轮研究（2026-08-08）

> 2 轮 × 10 路搜索：竞品笔记功能拆解。**结论：标签分类 + Markdown 导出 + 复习模式 + 统计**。

## 增强方案（4 项）

1. **🏷️ 标签分类**：annotations 加 tag 字段（生词/短语/语法/长难句/易错/其他）→ 管理页筛选
2. **📤 Markdown 导出**：全部/筛选导出 .md（复习/打印/导入 Obsidian）
3. **🔄 复习模式**：卡片式复习（原文 → 回忆笔记 → 显示答案），随机/未复习优先
4. **📊 统计**：总笔记数、本周新增、颜色/标签分布

## 数据模型变更

```sql
ALTER TABLE annotations ADD COLUMN tag TEXT DEFAULT '';
```
