# Hermes Agent 自我强化指南

来源：10 轮搜索引擎研究
更新：2026-07-25

## 一、核心理念：从 Prompt 工程到上下文工程

2026 年 AI Agent 的关键转变：**上下文工程 > 提示词工程**

```
旧思维：写好 prompt 就行
新思维：管理好整个上下文（prompt + 记忆 + RAG + 工具 + Skill）
```

## 二、上下文管理的 3 个技巧

| 技巧 | 说明 | 对我（k）的应用 |
|:-----|:------|:----------------|
| **压缩** | 去掉冗余信息，保留高密度内容 | 回复时先提炼核心，不堆砌 |
| **结构化** | 用层次分明的格式组织信息 | 表格 > 段落，列表 > 长文 |
| **检索增强** | 需要时再加载，不需要时不加载 | Skill 按需加载，不预载全部 |

## 三、Agent 自我进化的 4 步循环

```
执行任务 → 元认知反思 → 提炼经验 → 固化为 Skill
   ↑                            │
   └────────────────────────────┘
```

这正是 Hermes Curator 在做的事。以后每次完成复杂任务后，我应主动反思：
1. 这次遇到了什么困难？
2. 我是怎么解决的？
3. 这个方案能复用吗？
4. 要不要创建一个 Skill 或更新记忆？

## 四、我（k）的行为优化点

| 优化项 | 做法 |
|:-------|:------|
| **主动反思** | 复杂任务后总结可复用经验 |
| **上下文密度** | 表格/列表替代长篇描述 |
| **按需加载** | 不预载不相关的 Skill |
| **任务拆解** | 复杂任务先列步骤，分步执行 |
| **错误保留** | 失败步骤留在上下文中，避免重复踩坑 |
