# AIRI 生态 18 工具全研究——哪些对 sora 有用

> 研究：k · 2026-08-23 · 来源：GitHub README 实证（web_extract 逐仓抓取）+ 本地 clone（D:\airi, D:\webai-realtime-voice-chat）
> 结论：18 工具中 **5 个高价值（2 个已落地）**、5 个中价值、8 个暂不适用

## 结论置顶

AIRI 生态对我们最有用的核心 = **「浏览器端 AI」这条线**（VAD/Whisper/DuckDB 向量记忆/xsai-transformers）——全部直接服务于**墨题离线化 + 口语评测 + 本地语义搜索**。服务端/游戏/Rust 类工具价值有限。

---

## 🔥 高价值（5 个——2 个已落地）

| # | 工具 | 用途 | 状态 | 为什么有用 |
|:--|:---|:---|:---|:---|
| 1 | **webai-realtime-voice-chat** | VAD+STT+LLM+TTS 示例 | ✅ **已集成墨题**（自动切句） | 口语评测三段式已落地 |
| 2 | **xsai** | 轻量 AI SDK（56+ provider） | 📌 墨题重构参考 | llm-direct.ts 可改 adapter 模式 |
| 3 | **unspeech** | 语音统一端点（ASR/TTS 的 LiteLLM） | 📌 墨题 ASR 接入 | 口语识别统一 API |
| 4 | **xsai-transformers** | 浏览器端 Whisper/embedding/LLM | 📌 墨题离线方案 | **浏览器跑 Whisper = 口语评测全离线**（不用服务器 ASR） |
| 5 | **duckdb-wasm** | 浏览器内 SQL + **原生向量**（vec FLOAT[768]） | 📌 墨题本地记忆 | 错题/单词语义检索（不用后端向量库） |

**xsai-transformers 特别说明**（⭐69，活跃 2026-07 更新）：
```ts
// 浏览器端 Whisper 转写（离线！）
import { createTranscriptionProvider } from '@xsai-transformers/transcription'
const { text } = await generateTranscription({
  ...transformers.transcribe('onnx-community/whisper-large-v3-turbo'), file
})
```
→ 墨题口语评测若用这个，**识别也离线**（手机端 WebView 可行）——彻底摆脱服务器 ASR。

## ⚡ 中价值（5 个——特定场景有用）

| # | 工具 | 用途 | 适用场景 |
|:--|:---|:---|:---|
| 6 | **demodel**（⭐15） | 模型加速拉取（HF/Ollama/vLLM P2P 代理） | sora RTX4060 本地推理——huggingface 慢时可加速（配合 hf-mirror 二选一） |
| 7 | **webai-examples**（⭐35） | WebGPU 浏览器 LLM/Whisper 示例 | 墨题本地推理探索（smolvlm-realtime-webgpu demo 可玩） |
| 8 | **inventory**（⭐11） | 模型目录 + provider 配置服务 | 参考——我们的 hermes-provider-matrix 技能已覆盖 |
| 9 | **candle-examples**（⭐32） | Rust 本地推理（Silero VAD/Whisper 实时） | RTX4060 本地部署参考（门槛高，先看 demodel/hf-mirror） |
| 10 | **mcp-launcher**（⭐45） | MCP 服务器启动器 | Hermes 已有 MCP catalog——重复，但 manifests 目录可参考 |

---

## 📌 暂不适用（8 个——记录不投入）

| 工具 | 原因 |
|:---|:---|
| airi-factorio（⭐97） | sora 不玩 Factorio；「AI 玩游戏」仅 B 站选题素材 |
| factorio-rcon-api / autorio | 同上（Factorio 专用） |
| hfup | 部署 HuggingFace Spaces——sora 不用 HF Spaces |
| velin | Vue prompt 编排——墨题后端是 Python |
| burn-examples | Rust 深度学习——学习门槛高，价值低 |
| SAD | 自托管 LLM 笔记——我们 local-llm-inference 技能已覆盖 |
| awesome-ai-vtuber | AI VTuber 清单——B 站 AI 角色方向立项时再读 |

## 🎯 落地路线（按优先级）

```
1. ✅ 已完成：VAD 自动切句进墨题（webai-realtime-voice-chat）
2. 📌 墨题口语全离线：xsai-transformers 浏览器 Whisper（替代服务器 ASR）
3. 📌 墨题多模型重构：xsai 56-provider adapter 模式（llm-direct.ts）
4. 📌 墨题本地记忆：duckdb-wasm 向量（错题语义检索）
5. ⏳ 本地模型加速：demodel（RTX4060 + huggingface 慢时）
```
