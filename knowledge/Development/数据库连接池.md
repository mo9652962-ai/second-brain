# 数据库连接池（程序员Orion · 抖音 2026-08-21）

> 来源：抖音 @程序员Orion（创业中）《学校不教的商业级数据库天条：为什么大厂严禁使用 createConnection？》（1:19，页面章节要点）

## 坑

每个请求都新建数据库连接（createConnection）→ 高并发下连接数耗尽 → 数据库拒绝连接 → 系统崩溃。

## 保命打法

```
① 用连接池: 提前开辟固定连接池, 复用连接
② 限制连接数（池大小 = 合理上限, 排队等待而非新建）
③ 配置: 最大连接数/最小空闲/超时回收
```

## 落地检查

```
□ 不用每请求 createConnection（Python: 连接池/长连接; Java: HikariCP; Node: mysql2 pool）
□ 池大小按并发评估（不是越大越好, 数据库有上限）
□ 连接超时/泄漏检测
```
