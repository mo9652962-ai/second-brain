# 操作审计：别写盲盒系统（程序员Orion · 抖音 2026-08-21）

> 来源：抖音 @程序员Orion（创业中）《后台改错数据找不到内鬼？》（1:14，页面章节要点）

## 坑

新手写后台忽略操作审计 → 线上数据异常（改错价格/删错订单）→ 无法追溯是谁/何时/改了什么 → 盲盒系统。

## 保命打法

```
① 拦截器/切面统一记录核心操作（AOP 思想）
② 审计字段: 操作人 / 时间 / IP / 操作类型 / 变更前值 / 变更后值
③ 敏感操作（改价/删除/权限变更）必记录
```

## 落地检查

```
□ 核心写操作有审计日志（谁/何时/改了什么/前后值）
□ 审计表独立存储（防业务数据被误删连带）
□ 后台管理端可查审计记录
```
