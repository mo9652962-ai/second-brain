# 状态枚举替代 Boolean（程序员Orion · 抖音 2026-08-21）

> 来源：抖音 @程序员Orion（创业中）《谁教你无脑用 Boolean 设计表的？》（1:XX）
> 转写 394 字（SenseVoice）

## 坑

支付状态用布尔（is_paid: 0/1）→ 业务升级要加「支付中/支付失败/部分退款/已关闭」→ 疯狂加字段 → 表结构变垃圾场 → 架构报废。

## 保命打法

```
凡是未来可能超过两种状态的业务 → 用 status 枚举, 不用布尔
status: 0未支付 1支付中 2已支付 3失败 4已退款
```

> 现在只有两种状态 ≠ 以后永远只有两种。给业务留活路，才叫商业级全栈。

## 落地检查

```
□ 状态字段用枚举/int 常量表, 不用布尔
□ 已有布尔字段 → 评估迁移到 status
□ 枚举值留位: 值用 0/10/20 间隔, 方便插值
```
