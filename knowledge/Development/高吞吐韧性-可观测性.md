# 高吞吐后端韧性 + 可观测性（千轮研究 2026-08-21）

> 来源：张显达韧性设计 / eBPF+OTel 2026 实战 / 字节链路追踪 / 黑豹科技大促实战

## 韧性四支柱

```
限流(保生存) → 熔断(防扩散) → 背压(防OOM) → 隔离(防牵连)
```

| 支柱 | 要点 | 对应扫坑项 |
|:---|:---|:---|
| 限流 | 令牌桶+突发上限，按租户/用户/接口/热点参数维度；Gateway 截 30% 无效流量比扩容便宜一个数量级 | #5 验证码限流 |
| 熔断 | Resilience4j：滑动窗口 100 / 失败率 50% / 半开 10 次；核心链路禁止静默失败 | #10 微服务超时 |
| 背压 | 有界队列 LinkedBlockingQueue(cap=10000) 满则拒绝；Consumer Lag >10 万暂停非核心 Producer；DLQ 补偿 | #34 新增 |
| 隔离 | 依赖分线程池+超时；读写分离（Slave 延迟 >1s 自动路由 Master）；CQRS 读模型 | #33 新增 |

## 缓存三连（大促实战验证）

```
缓存击穿 → 互斥锁 + 逻辑过期
缓存雪崩 → TTL 随机偏移 ±10%
热点 Key → Local Cache(Caffeine) + Redis 双层
```

## 2026 可观测性标配（eBPF + OTel）

- **eBPF**：内核级零侵入观测（网络流量/系统调用/资源消耗，开销 <1% vs SDK 5-15%）
- **OpenTelemetry**：日志/指标/追踪统一标准（CNCF 活跃度第二）
- **AI 工作负载观测**（新标配）：Token 追踪 / 模型质量评估 / 提示词上下文 / 幻觉率告警
- **智能采样 + 存算分离**：存储成本降 90%（tail_sampling 保留错误/慢请求/LLM 请求）
- 推荐栈：Cilium + Grafana Beyla + OTel Collector + VictoriaMetrics + Loki + Grafana 11

## 落地清单（接客户大系统/平台时）

```
□ 限流/熔断/背压/舱壁配置落地且可观测（看板: QPS/P99/队列深度/熔断次数）

□ 核心链路禁止静默失败（快速失败+降级提示）
□ 调用 LLM 的服务有 Token/质量监控
□ 压测验证：限流触发率/熔断次数/Lag/P99；Chaos Mesh 故障注入
```
