# 小程序虚拟支付 400 排查（程序员Orion · 抖音 2026-08-21）

> 来源：抖音 @程序员Orion（创业中）《小程序虚拟支付明明开通了，为什么点击支付还是报400？》（1:25，页面章节要点）

## 症状 / 根因 / 解决

| 项 | 内容 |
|:---|:---|
| 症状 | 虚拟支付开通了，点击支付报 400——网络请求失败，创建订单接口被拦截 |
| 根因 | 微信后台虚拟道具**未同步到本地数据库** → 下单时 product ID 为空值 |
| 解决 | ① 本地服务规格表新增 `wechat_virtual_product_id` 字段<br>② 绑定微信后台生成的 product ID<br>③ 下单时字段有值 → 400 消失 |

## 两个铁律

1. **金额转换由后端严格计算**——前端浮点误差（0.1+0.2≠0.3）；金额前端算也是改价漏洞温床
2. **排查顺序：先查业务接口，再查微信支付接口**——不要一上来怀疑外部服务

## 通用排障顺序（可复用）

```
① 查自己业务接口: 参数/字段/数据库值 (先排除 90% 可能)
② 查外部接口: 微信/支付宝/短信等
③ 查权限/配置: 支付开通状态/回调域名/appid 绑定
```
