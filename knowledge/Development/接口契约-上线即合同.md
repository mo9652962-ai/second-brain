# 接口契约：上线即合同（程序员Orion · 抖音 2026-08-21）

> 来源：抖音 @程序员Orion（创业中）《后端随手改了个字段，前端当场全站白屏！》（1:14）
> 转写 442 字（SenseVoice）

## 事故

后端把返回字段 name → username / 列表外套对象（自认「小优化」）→ 前端/小程序拿不到老数据 → **全站白屏瘫痪**。

## 铁律

> **接口一旦上线，它就不是代码了，是合同。** 你随手一改，别人可能通宵返工。

```
❌ 上线接口: 不删字段 / 不改返回结构
✅ 必须动结构 → API 版本控制:
   - 路径加版本号 (/api/v1 /api/v2)
   - 新业务走 V2, 老 V1 保留
   - 给其他团队迁移时间
```

## 落地清单（墨题/客户项目对照）

```
□ 线上接口有文档/契约（Swagger/OpenAPI）
□ 改字段走版本控制, 不原地改
□ 前端引用字段名集中定义（常量/类型），不散落硬编码
□ 联调环境与生产环境契约一致
```
