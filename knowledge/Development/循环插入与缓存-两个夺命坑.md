# 循环插入 + 本地缓存：两个夺命坑（程序员Orion · 抖音 2026-08-21）

> 来源：抖音 @程序员Orion（创业中）《在学校写 for 循环插入数据？接单这么写直接把数...》（1:42）
> 转写 567 字（SenseVoice）
> 与 `循环调外部API-批量与队列.md` 成对：一个打数据库、一个打外部 API

## 坑 1：一级/二级缓存（多节点脏数据）

```
学校: 开启二级缓存减轻数据库压力
商业: 后端多节点集群 → A 改价 100→10, B 本地缓存不知道 → 展示老价格
= 脏数据 → 商城价格全乱 → 索赔
```

**保命**：果断关闭自带缓存 → 用 Redis 做**全局分布式缓存**

## 坑 2：循环单条插入（N+1 网络通讯）

```
for 循环 1 万次插入 = 与 MySQL 建立 1 万次网络通讯
→ 几分钟耗时 → 批量导入卡白屏 → 后台 502
```

**保命**：
```xml
<!-- MyBatis: <foreach> 拼一条超长 SQL -->
<insert id="batchInsert">
  INSERT INTO t (a,b) VALUES
  <foreach collection="list" item="x" separator=",">
    (#{x.a}, #{x.b})
  </foreach>
</insert>
```
```java
// 连接串加开关（MySQL 批量优化）
jdbc:mysql://host/db?rewriteBatchedStatements=true
```
→ 1 万条一次网络交互，几百毫秒落库

## 铁律

> 能批量的绝对不要循环；跨节点的绝对不要用本地缓存。
