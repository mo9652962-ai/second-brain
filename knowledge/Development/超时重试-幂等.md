# 超时盲目重试 = 重复扣款（程序员Orion · 抖音 2026-08-21）

> 来源：抖音 @程序员Orion（创业中）《接口一超时你就盲目重试？同一个订单直接扣了三次库存...》（页面服务器问题未转写，基于标题+幂等知识拆解）

## 坑

接口超时 → 客户端/服务端盲目重试 → 同一订单被扣 3 次库存/扣 3 次款 → 业务事故。

## 保命打法（幂等三件套）

```
① 幂等键: 请求带唯一 idempotency_key（订单号+操作）
② 服务端查重: 先查订单状态, 已处理直接返回结果（不重复执行）
③ 重试策略: 指数退避 + 上限; 重试前校验业务状态
```

```
❌ 超时 → 立刻重试 → 又超时 → 再重试 (3 次扣款)
✅ 超时 → 查订单状态 → 已扣? 返回结果 / 未扣? 重试(带幂等键)
```
