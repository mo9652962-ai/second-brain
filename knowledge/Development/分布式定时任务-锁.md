## 保命打法

```
多台机器只准跑一个任务: 执行前 Redis 抢分布式锁
SET NX EX → 谁抢到锁谁执行, 抢不到的瞬间退出
```

```python
# Redis 分布式锁
import redis, uuid
r = redis.Redis(...)
lock_key = "cron:settle_commission"
token = str(uuid.uuid4())
if r.set(lock_key, token, nx=True, ex=300):  # 抢到锁
    try:
        do_settle()   # 执行业务
    finally:
        if r.get(lock_key) == token:  # 确认是自己的锁
            r.delete(lock_key)
else:
    return  # 抢不到, 退出
```
