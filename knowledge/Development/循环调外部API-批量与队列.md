# 循环调外部 API = 自我 DDoS（程序员Orion · 抖音 2026-08-21）

> 来源：抖音 @程序员Orion（创业中）《循环里调外部 API？你这不是在写代码，是在对大厂...》（1:46）
> 转写 607 字（SenseVoice）

## 事故模型

```
学校: 30 人群发循环调短信 API → 完美（规模小）
商业: 几万会员循环调微信推送 → 1 秒成千上万并发
→ 大厂防火墙判定恶意攻击 → 服务器 IP 秒封
→ 客户商城支付/登录/短信全瘫 → 惨痛商业损失
```

## 保命打法（二选一）

```
方案1 批量接口: 翻大厂开发文档, 单条接口改批量 API 一次打包
方案2 队列限频: 没批量接口 → MQ / Redis 延迟队列, 限每秒频率, 细水长流(慢但安全)
```

**客户催快发 → 原话**：「这批数据单条循环调接口，IP 绝对会被封禁，我必须用批量接口或加队列限制频率，保证安全」

> 金句：对外部接口保持敬畏，就是对客户的钱包负责。

## 已验证实践（sora 词库补音标）

`vocabulary-data-pipeline`（有道 API）已用：限速 + 并发控制 + WAL 写锁 + 3 库同步——就是方案 2 的本地版 ✅
