# Windows 桌面美化方案

## 推荐工具组合

| 工具 | 用途 | 获取方式 |
|:-----|:------|:---------|
| **TranslucentTB** | 任务栏透明 | Microsoft Store |
| **Rainmeter** | 桌面小组件（时钟/天气/系统监控） | rainmeter.net |
| **Fences** | 桌面图标分区整理 | Steam（付费） |
| **RocketDock** | Mac风格 Dock 栏 | 免费 |
| **Wallpaper Engine** | 动态壁纸（已有） | Steam |

## 快速部署

1. Microsoft Store 搜索 TranslucentTB → 安装
2. 下载 Rainmeter → 装皮肤包
3. Wallpaper Engine 已有
