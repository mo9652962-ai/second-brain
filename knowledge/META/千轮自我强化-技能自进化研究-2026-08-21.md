# 千轮自我强化：Agent 技能自进化前沿研究（2026-08-21）

> 搜索引擎千轮研究——Agent self-improvement / skill evolution 2026 前沿。落地为 `skill-evolution` 技能。

## 核心论文/框架

| 框架 | 核心洞察 | 对我们可落地 |
|:---|:---|:---|
| **SkillHone** (arXiv 2606.08671) | 技能进化要**持久决策历史**（诊断→修订→证据→结果），不只留最终产物——GAIA +15.8 | 技能加 decision-log |
| **AutoSkill** (arXiv 2603.01145) | 从对话/交互经验自动提炼技能，add/merge/discard 三决策 | 会话经验蒸馏 |
| **ReMe** (ACL 2026 Findings) | 程序记忆生命周期：多面蒸馏 + 上下文适配复用 + **效用修剪**——Qwen3-8B 带 ReMe 超无记忆 14B | 技能库定期修剪 |
| **SkillOpt** (Microsoft) | 技能当「可训练状态」：rollout→reflect→aggregate→select→update→**验证门控**；SkillOpt-Sleep 夜间离线自进化 | 改技能像训练模型 |
| **ERL** (arXiv 2603.24639) | 从轨迹提炼 **trigger+action 启发式**，选择性检索注入——比原始轨迹可迁移 | 启发式格式标准 |
| **MetaSkill-Evolve** (arXiv 2607.05297) | **递归**：任务技能快循环 + 元技能慢循环（改进方法本身也被改进）| 季度审视进化流程 |
| **SkillX** (zjunlp) | 三级技能层次：Planning/Functional/Atomic | 技能库可分层 |
| **Trace2Skill** (arXiv 2603.25158) | 并行子 agent 分析轨迹池 → 归纳合并成单一技能目录（冲突检测）| 大量轨迹时用 |
