# 技能生产链全景图（407 技能 → 9 流派 × 6 段生产链）

> 千轮研究来源（2026-08-21 三轮）：
> ① Agent 架构四层（Skills/Subagents/Multi-Agent/Dynamic Workflows）— Yue Shui
> ② ADPS Agent 设计模式白皮书 v0.3（28 模式/6 执行拓扑/7 认知功能）
> ③ 生产级 Agent 8 层架构（Tool/Skill/Pipeline/Agent 四定位）— 虎嗅
> ④ AI 内容生产流水线（AutoCrew/aistacknav/51CTO：选题池→骨架→初稿→质检→多平台→复盘）
> ⑤ 知识蒸馏流水线（second-brain/llm-wiki/knowledge-iteration-system：Capture→Triage→Distill→Forge→Index）

## 设计原则（从研究中提取的 6 条铁律）

1. **Tool 解决「能做什么动作」，Skill 解决「某类任务怎么做」，Pipeline 解决「谁在什么阶段用什么能力」**——流派 = Pipeline 层
2. **执行拓扑选择**：步骤稳定用 Chain（链式）/ 分类用 Route（路由）/ 可并行用 Parallel / 中心调度用 Orchestrate / 迭代收敛用 Loop / 分权用 Hierarchy
3. **质量门前置**：每个流派必须有「输出前质检」阶段（不是写完就算完）
4. **半自动 > 全自动**：AI 生成 80%，人工做最后 20% 判断（事实核查/语气/决策）——草稿箱策略
5. **闭环反馈**：发布后复盘 → 回流到方法论/技能（AutoCrew 学习循环、knowledge-iteration feedback_loop）
6. **先跑通再自动化**：流程没定型前，自动化只会放大混乱

## 通用生产链模板（六段式，所有流派共用）

```
① 输入捕获 → ② 加工处理 → ③ 质量门(质检) → ④ 输出交付 → ⑤ 数据复盘 → ⑥ 迭代沉淀
   Capture     Process       Quality        Deliver       Review        Iterate
```

每段可映射 ADPS 执行拓扑：
- ① 输入：Route（分类分流）
- ② 加工：Chain（链式步骤）/ Parallel（并行拆解）
- ③ 质检：Loop（迭代收敛直到达标）
- ④ 输出：Orchestrate（多端编排）
- ⑤ 复盘：Loop（数据回流）
- ⑥ 沉淀：Skill Package（技能包固化）
