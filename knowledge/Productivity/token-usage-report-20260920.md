## 🔑 三~四要点

1. **真实成本环比暴涨 ~10 倍（¥6.51 → ¥73.5）**：主因不是用量增加（调用仅 +3.7%），而是**流量从方舟订阅跑偏到按量 relay**——本周 deepseek-v4-flash 113 会话走裸 `custom`（疑似 tokenrhythm/按量），而方舟订阅（custom:fangzhou-2）只剩 13 会话。上周主力 86 会话走方舟 ≈¥0，本周仅 13 会话走订阅。
2. **周日（09-20）用量为周内峰值**：878 calls / 12.4M 输入（周报日 5 个周度 cron 集中执行），占本周调用 36%、输入 38%。
3. **缓存命中率 85.2%，踩线健康但持续下滑**（94.1%→89.6%→85.2%）：本周大量新会话/并行集群带来冷缓存，缓存读取量 191M 仍占输入 token 的 5.8 倍（有效节省按量成本）。
4. **provider 层多故障日**：09-19~09-20 workbuddy-ai 反代大量 HTTP 400/429/500（34 次），方舟 429（28 次），cpa-gui Connection error（27 次）；DeepSeek 直连余额 **-¥0.10 欠费** ⚠️。
