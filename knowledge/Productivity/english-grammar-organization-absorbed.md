# 英语语法笔记 · 组织方法论吸收

> 68 个独立文件 × 7 大模块 × 4 要素/文件

---

## 最值得借鉴的：知识颗粒度设计

### 1. 单一知识点 = 一个文件
- 不是一个大 PDF 包罗万象
- 每个语法点独立成文件（68 个）
- 想学哪个点哪个，不用翻找

**→ 应用到 vault**：
- 一个大知识域（如 "PCB 设计"）拆成多个聚焦笔记
- 每个笔记只讲一件事

### 2. 每个文件的四要素结构
```
① 定义说明 → 本质是什么
② 用法规则 → 规律 + 例外
③ 典型例句 → 语境理解
④ 高频考点 → 考试怎么考
```

**→ 应用到 vault**：
- 我们的 knowledge notes 可以统一采用类似模板

### 3. 渐进式难度
从句子成分 → 词法 → 时态 → 非谓语 → 从句 → 特殊句式 → 高级语法
零基础能看懂，高手能拔高。

**→ 应用到 vault**：
- 配置知识从 "基础" 到 "高级" 分层
- 新手看基础篇，老手直接跳高级

### 4. 跨考试通用
同一套笔记覆盖高考/专升本/四六级/考研
不是为某个考试定制，是通用的知识体系

**→ 应用到 vault**：
- 闲鱼服务（论文/PPT/PCB）的通用方法论 skill
- 不绑定具体工具/模型，而是底层原理+可迁移能力
