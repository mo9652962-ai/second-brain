# Translumo · 实时屏幕翻译工具

来源：GitHub ramjke/Translumo (5.5k⭐)
安装：`C:\Users\31954\Downloads\Translumo\Translumo.exe`

## 快捷键

| 按键 | 功能 |
|:-----|:------|
| `Alt+Q` | 框选翻译区域 |
| `~` | 开始/停止实时翻译 |
| `Alt+G` | 打开设置 |

## 使用流程

1. 双击 Translumo.exe 启动
2. `Alt+Q` 框选要翻译的屏幕区域
3. `~` 键开始实时翻译
4. 翻译引擎：Google / DeepL（免费，无需 Key）
