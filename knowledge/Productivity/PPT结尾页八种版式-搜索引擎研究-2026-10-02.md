## 结论置顶

**「谢谢观看」不是错，错的是把它当成唯一手段。**

| 判据 | 说明 |
|:---|:---|
| 认知依据 | **近因效应（Serial Position Effect）**：人对序列开头和结尾的记忆最强。结尾页是整场演讲里记忆价值最高的一页 |
| 时间价值 | 答辩/评审场景下，致谢页在评委提问期间要**在屏幕上停留 5~15 分钟**，是实际曝光时间最长的一页 |
| 浪费程度 | 99% 的人把这一页留白给「谢谢聆听」四个字 —— 等于把最贵的广告位贴了张白纸 |
| 唯一标准 | 做完这一页，问自己：**我希望观众离开之后看到什么、记住什么、做什么？** 答案放上去，不放「谢谢」 |

### 「感谢聆听」为什么不建议用
「聆听」是谦辞。演讲者说「谢谢聆听」＝ 感谢您屈尊听我讲。改用「批评指正 / 指导 / 垂听」更稳。
（学术场合可直接用「恳请各位专家评委批评指正」）

## 8 种版式（按场景选型）

| # | 版式 | 适用场景 | 核心机制 | 关键参数 |
|:--|:---|:---|:---|:---|
| 0 | ~~谢谢观看~~（反例） | 任何场合都不推荐 | 对比基准 | — |
| 1 | **核心信息回旋镖** | 年会 / 年度汇报 / 复盘 | 开场金句在结尾原样弹回，首因+近因叠加 | 文案必须与开场**一字不差** |
| 2 | **行动号召 CTA** | 销售 / 招商 / 招募 | 一个动作 + 二维码 + 截止时间 | **只给一个动作**，给两个等于没给 |
| 3 | **联系方式卡片** | 求职 / 合作 / 讲师 | 左情绪右信息的分栏结构 | 联系方式放结尾页，别单开一页 |
| 4 | **金句升华** | 发布会 / 竞聘 / 演讲 | 一句能被复述的话撑满整页 | 字号 ≥44pt，越简单越高级 |
| 5 | **核心要点总结** | 培训 / 分析 / 复盘 / 异步交付 | 3 张卡，截屏即摘要 | **三张上限**，超三张一张都记不住 |
| 6 | **全屏影像 + 单字** | 演讲 / 品牌 / 致谢 | 图替你说最后一句 | 放完停 3~5 秒不说话 |
| 7 | **负空间镂空（红金）** | 学位答辩 / 国奖评奖 | 文字布尔运算镂空透出底层流光 | 先选底板再选文字，见下文铁律 |
| 8 | **负空间镂空（科技）** | 商务 / 路演 / 客户交付 | 同结构换冷色，学术秒变商务 | 面板放右侧，左侧留白 |

### 选型决策树

```
观众需要采取行动？ ──是──> #2 行动号召
        │否
        ├─ 是答辩/评审，要被记住？ ──是──> #7 镂空红金（+ Q&A 角标）
        ├─ 是内部汇报，要留联系方式？ ──是──> #3 联系方式卡片
        ├─ 是培训/复盘，要带走结论？ ──是──> #5 核心要点总结
        ├─ 是演讲/竞聘，要一句话定调？ ──是──> #1 回旋镖 或 #4 金句
        └─ 以上都不是 ──> #6 全屏影像（最少信息量，最高情绪量）
```

## 工程实现（本次交付的技术要点）

生成器脚本 `scripts/generate_ending_slide_library.py`，五层架构：

| 层 | 职责 | 函数 |
|:---|:---|:---|
| 1 配置层 | 尺寸/配色/文案/字体集中可改 | `CONFIG` / `META` / `PAGES` |
| 2 工具层 | 渐变背景、光晕、暗角、颗粒、二维码、镂空面板、动效注入 | `make_bg` `make_qr` `make_hollow_panel` `add_motion` |
| 3 生成层 | 每种版式一个纯函数（SRP） | `page_00_bad` … `page_08_hollow_tech` |
| 4 渲染层 | LibreOffice 渲染 → PNG，供视觉验收 | `render_ending_preview.py` |
| 5 流程层 | 编排 + 落盘 + 自检报告 + 版式对照表 | `main()` |

### 踩坑记录（真实踩过的，不是抄的）

| 坑 | 现象 | 解法 |
|:---|:---|:---|
| **python-pptx 不在 Hermes 自带 venv** | `ModuleNotFoundError: No module named 'pptx'` | 用系统 Python 3.12：`%LOCALAPPDATA%\Programs\Python\Python312\python.exe`（已装 pptx 1.0.2 / numpy / PIL / pymupdf；`qrcode` 需 `pip install qrcode`） |
| **图片对象没有 `nvSpPr`** | `AttributeError: 'CT_Picture' object has no attribute 'nvSpPr'` | 图片 shape id 用 **`shape.shape_id`**（文字/形状也通用），不要走 `_element.nvSpPr.cNvPr` |
| **动画挂错对象** | 背景图动效静默丢失（XML 里 timing 存在但 spid 指向别的元素） | 注入前先用 `unzip` 展开 pptx 校验 `p:spTgt spid` 对应 `p:cNvPr name` —— **一页一页对名字**，别信「代码跑通了」 |
| **空心文字压边** | 镂空大字底部被画布裁掉 | 镂空字画在上方安全区（y ≤ 0.60×H），底部文字用一块半透明底卡保证对比度 |
| **空心字与实字重复** | 面板镂空「THANK」+ 右侧又写「THANK YOU」 | 同一页只保留一处该词，另一处换别的语义（如 `CLOSING`） |

### 校验命令（可复用）

```bash
# 1) 渲染成图 + 白屏检测
python scripts/render_ending_preview.py          # 输出 preview_ending/page_XX.png + ink 占比

# 2) 拼 3×3 联系表，一次性视觉验收
python scripts/make_contact_sheet.py

# 3) 动效对象绑定自检（关键！）
unzip -o -q 输出.pptx -d /tmp/px
python - <<'PY'
import re,glob
for f in sorted(glob.glob('/tmp/px/ppt/slides/slide*.xml')):
    x=open(f,encoding='utf-8').read()
    ids=dict(re.findall(r'<p:cNvPr id="(\d+)" name="([^"]*)"',x))
    print(f, x.count('p:timing'), [ids.get(i,'?') for i in re.findall(r'p:spTgt spid="(\d+)"',x)])
PY
```

## 商业化应用（闲鱼 PPT 接单）

| 客户类型 | 用哪几页 | 客单提升逻辑 |
|:---|:---|:---|
| 学生答辩（30~80 元） | #7 红金镂空 + #4 金句 | 交付时附「结尾页 8 版可选」，把 30 元的单做成 80 元 |
| 企业汇报（100~300 元） | #8 科技镂空 + #5 总结 + #2 CTA | 客户要的是「看起来贵」，镂空页是性价比最高的「贵」 |
| 求职/个人品牌 | #3 联系方式 + #4 金句 | 加一页联系方式卡片，客户觉得「用心」 |
| 批量交付 | 改 `META` 字典 + 跑脚本 | 换文案换配色 30 秒出一套，边际成本≈0 |
