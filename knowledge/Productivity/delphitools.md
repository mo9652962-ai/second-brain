# delphitools · 在线小工具站

来源：小黑盒 "软件格律诗"
链接：https://tools.rmv.fyi/

## 简介
58 个小工具的集合站，浏览器本地运行，无需注册，不收集数据。
覆盖图片、颜色、文字、开发、文件转换等场景。

## 实用工具

| 工具 | 功能 |
|:-----|:------|
| **Background Remover** | 去除图片背景 |
| **Image Converter** | 图片格式转换（PNG/JPEG/WebP） |
| **Palette Generator** | 从图片生成配色方案 |
| **QR Generator** | 生成自定义二维码 |
| **Text Diff** | 对比两段文字差异 |
| **Document Converter** | Markdown/HTML/Word/LaTeX 转换 |

## 优势
- 本地处理，不上传服务器，隐私安全
- 不用注册登录
- 轻量快捷，适合内容创作者/设计师/开发者
