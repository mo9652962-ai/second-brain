# 攻玉 · 科研 AI 应用 · 吸收与评估

> "开发者也是使用者" — 一边写论文一边改工具

---

## 🎯 攻玉的核心设计

| 功能 | 说明 |
|:-----|:------|
| **自动化模板** | 预置模板一键启用，周报/文献速递/项目进度 |
| **技能系统** | 独家"文献速递"技能，多数据库检索 |
| **项目记忆** | 自动保存研究进展和产物作为上下文 |
| **免费模型** | 长期维持免费模型（5.5、Grok等） |
| **团队报销** | 支持导师报销 |

## 🔄 我们已经有的

| 攻玉的功能 | 我们的等效方案 |
|:-----------|:--------------|
| 自动化模板 | 22 个 cron 任务 |
| 文献速递 | light-literature-search + arxiv cron |
| 项目记忆 | Obsidian vault + knowledge/ |
| 技能系统 | Hermes Skills + Light Skills |
| 团队报销 | 闲鱼服务定价策略 |

## 💡 可借鉴的

1. **模板化 cron 任务** — 把常用的 cron 组合做成模板（比如"组会报告模板"= 文献速递 + 项目进展 + 本周总结）
2. **自动化关联项目** — cron 任务自动绑定到特定 Obsidian 项目
3. **"打开对话"模式** — cron 执行完结果后可以继续追问 → 我们已有（每条 cron 都可以回复）

## ❌ 不安装攻玉

结论：**不装。** 攻玉是面向个人的 SaaS 工具，我们有 Hermes + Obsidian + cron 已经全覆盖了。方法论值得吸收，但不需要再装一个平台。
