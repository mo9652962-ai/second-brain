# Show Me The Story · AI 长篇小说创作工具

来源：小黑盒 "软件格律诗"
更新：2026-07-25

## 简介
单文件运行的 AI 长篇小说创作工具，开源本地运行。
兼容所有 OpenAI 格式 API（DeepSeek/GPT/Ollama 等）。

## 核心功能

| 功能 | 说明 |
|:-----|:------|
| **两阶段创作** | 先生成大纲 → 审核确认 → 逐章写作 |
| **结构化设定** | 角色/世界观/组织/关系独立管理，写作时自动注入上下文 |
| **关系图谱** | 可视化角色/组织/世界观关系网络 |
| **伏笔系统** | AI 规划→埋设→追踪→回收，超期未回收自动告警 |
| **事实核查** | 每章自动一致性检查，人设/时间线冲突自动重写 |
| **去AI味** | 内置 23 条 AI 句式禁令 + 套话替换，一键润色 |
| **全书优化** | 完稿后诊断→一致性核查→生成优化工单→逐章修订 |
| **续写已有作品** | 粘贴已有文本，AI 分析提取设定后接着写 |
| **AI 助理** | 对话式查询/修改设定、大纲、章节 |
| **断点续作** | 随时保存，重启自动恢复 |
| **多语言** | 中英文项目可切换 |

## 部署
- 单个二进制文件，无需数据库/依赖
- 浏览器访问操作
- 支持 Ollama / DeepSeek / GPT 等

## 场景
长篇网文 / 原创小说 / 短篇合集
