# SRC 新手从 0 到第一个洞

> 作者: 网络安全黑卡 | 主题: SRC 平台分类 + 新手选平台 + 6 步挖洞全流程
> 定位: **新手入门补充节点**——体系已有，这里补「2026 新手平台清单 + 可照搬流程」

## 一、SRC 平台是什么

```
SRC (Security Response Center) = 企业官方漏洞接收/审核/奖励平台
核心: 「合法授权」是底线，区别于野站渗透
双向共赢: 企业修漏洞 / 白帽攒实战+赏金+简历
```

## 二、平台分类（2026 版）

| 类型 | 代表 | 特点 | 适合 |
|:---|:---|:---|:---|
| 企业 SRC | 字节/腾讯/阿里/美团 | 奖励高、含金量足 | 有基础后进阶 |
| 第三方众测 | 补天/漏洞盒子 | 规则统一、门槛低、漏洞类型丰富 | 纯小白入门 |
| 公益类 | EduSRC | 积累经验+荣誉证书，赏金少 | 新手补充实战 |

**2026 新手友好平台速查（审核快/易出洞）:**
```
vivoSRC / 荣耀SRC —— 审核快、高危立结
CTFshow SRC / 360SRC 新手专区 —— 难度低、易建立信心
EduSRC —— 教育资产，审核宽松
```

## 三、新手 6 步全流程（可照搬）

```
① 平台注册: 1-2 个新手友好平台 + 实名认证 + 精读《漏洞收录规则》《禁止测试行为》
② 环境搭建: 3 个核心免费工具（Burp 社区版 + Nmap + OneForAll）+ Wappalyzer 插件
③ 信息收集（地基，新手最易跳过）:
   子域名（OneForAll）→ 技术栈（Wappalyzer）→ 端口（nmap -T4 -F）
   → 后台路径（Dirsearch）→ 资产归属（爱企查/天眼查/爱站，避免测错资产）
④ 漏洞探测: 优先 4 类新手友好漏洞
   信息泄露（/backup.sql、/.git、/config.php）→ 未授权访问（后台/接口）
   → 反射型 XSS（搜索框/参数）→ SQL 注入（报错注入，只证明存在不深入利用）
⑤ 漏洞验证: 复现 2-3 次（不同浏览器/网络）+ 明确危害 + 全程截图
⑥ 报告提交: URL + 复现步骤 + 危害证明 + 修复建议；附截图/视频更易过审
```

## 四、避坑要点

```
❌ 不依赖自动化工具（逻辑漏洞必须手动，工具仅辅助）
❌ 不眼高手低（低危漏洞也能积累信誉，逐步冲中高危）
❌ 不越权操作（只证明漏洞存在，不脱库/不深入利用）
✅ 遵守红线: 只在平台授权范围测试
```

## 五、对 sora 的定位（已过新手阶段）

```
✅ 平台已选: T3SRC（首单已提交，审核中）
✅ 信息收集/工具链: OneForAll + Fofa + Burp + unveilr 已配齐
✅ 漏洞验证: DVWA 7 类 + 小程序审计实弹
⬜ 唯一待办: T3 首单审核结果（= 第一个洞闭环）
🟡 可选: 多注册 1-2 个新手友好平台分散风险（vivoSRC/荣耀SRC/CTFshow）
```
