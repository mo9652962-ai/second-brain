## 一、SRC 是什么

SRC（Security Response Center）= 企业官方漏洞接收平台。白帽子在授权范围内测试，提交漏洞拿赏金。合法、免费、贴近真实业务——新手最安全的实战起点。

平台分级：企业SRC（字节/腾讯/阿里，赏金高难度大）→ 第三方众测（漏洞盒子/补天，门槛低）→ 公益类（CNNVD/EduSRC，证书为主）。

## 二、新手平台选型（2026 实测）

| 平台 | 门槛 | 特点 |
|:---|:---:|:---|
| 漏洞盒子 | 无 | 新手首选，低危多 |
| 补天 | 低 | 厂商多，模板详细 |
| 字节SRC | 低 | 反馈快，新人奖励 |
| CNNVD/EduSRC | 高 | 证书背书 |

原则：选 2-3 个平台深耕 > 满大街扫。

## 三、新手 5 类漏洞（按易上手排序）

1. **业务逻辑漏洞**（70% 新手首笔赏金来源）——水平越权/验证码逻辑/金额篡改/密码重置/权益滥用；五步法：梳理流程→找信任点→跳过步骤→篡改参数→重复操作
2. **信息泄露**（最容易）——/.git、/.env、swagger、backup.sql、JS 搜密钥
3. **弱口令**——针对性字典（公司缩写+年份）
4. **XSS**——评论区/搜索框，存储型>反射型
5. **SQL 注入**——优先 POST，' or 1=1--

## 四、六步流程

平台注册（实名）→ 环境搭建（Kali+Burp+Wappalyzer）→ 信息收集（OneForAll/Nmap/Dirsearch/爱企查）→ 漏洞探测 → 漏洞验证（复现2-3次+截图）→ 报告提交。

## 五、报告模板

【标题】【类型】【等级】【描述】【复现步骤】【Payload】【危害证明】【修复建议】

## 六、避坑（法律红线）

- 不看 Scope = 白干
- SQL 注入点到为止（user()/database() 证明即可，拖库=违法）
- XSS 只获取自己 cookie
- 敏感文件确认后立即删除
- 不未授权测试

## 七、2026 趋势

逻辑漏洞主流（WAF 强）；云原生/AI安全/API 新兴高赏金；车企 SRC 蓝海；AI 辅助挖洞。

## 八、新手时间线

- 0-1 月：靶场练手 + 提交低危（反射XSS/弱口令）建立信心
- 1-3 月：逻辑漏洞 + 中危 Web 漏洞，掌握工具联动
- 3 月+：云原生/AI 安全，冲击高危，拿内推
