## 一、收益五层结构

```
单洞收益 = 漏洞等级基础奖励 × 业务系数 × 活动翻倍
```

| 层 | 机制 | 参考 |
|:---|:---|:---|
| ① 漏洞奖金 | 等级 × 业务系数 | 低危 5-300 / 中危 100-600 / 高危 200-2500 / 严重 800-3000+ |
| ② 积分兑换 | 安全币/积分换现金 | 360：1 安全币=5 元；京东：1 积分=5 元 |
| ③ 众测活动 | 翻倍/奖池 | 微信百万奖池、高危 2 倍 |
| ④ 排行榜 | TOP 额外奖金 | 银联年 TOP1 10000 兑换币；腾讯核心严重 1-6 万/月 |
| ⑤ 新人/报告奖 | 首洞礼物/优质报告 | 新人京东卡；优质报告最高 5000 |

## 二、安全边界（保命必读）

### 法律框架
- 刑法 285② 非法获取数据罪：侵入+获取+情节严重 → 3 年以下/特别严重 3-7 年
- 刑法 285③ 提供侵入工具罪 → 3 年以下
- 刑法 286 破坏系统罪 → 5 年以下
- 刑法 253 侵犯公民个人信息罪 → 3 年以下/特别严重 3-7 年
- 网安法 27 条：未经授权扫描即违法

### 入罪数字
- 285 条：金融认证 ≥10 组 / 其他认证 ≥500 组 / 违法所得 ≥5000 元或损失 ≥1 万
- 253 条：行踪/征信/财产 ≥50 条 / 住宿/健康/交易 ≥500 条 / 其他 ≥5000 条

### 判例教训
- 袁炜案：>500 组认证信息 → 批捕（白帽圈最著名）
- 银川白帽：未授权+恶意代码 → 被抓
- 00后张某：不提交反而卖兑换码获利 6 万 → 判 3 年缓 3 年
- 上海 Y 公司：超授权爬 1800 万条 → 判 3 年缓 3 年（合法授权≠无限授权）
- 新加坡酒店：未授权测 WiFi 口令公开 → 罚 $5000

### 字节 SRC 测试规范（行业标杆）
✅ 手工测试 / 越权 ≤5 组 / 自备测试账号
❌ 自动化扫描器 / 注入读表内数据 / 内网渗透 / webshell / 下载传播敏感数据 / 影响线上业务

### 实战红线
✅ 只测授权 scope / 注入只证明 / 越权 ≤5 条 / 敏感数据即删 / 命令注入只 whoami
❌ 未授权目标 / 拖库 / 破解真实密码 / 社工 / 内网横向 / 私下卖漏洞

## 三、新手收益路径
1. 低垂果实：信息泄露/未授权（低危 5-300）→ 门槛低通过率高
2. 盯众测活动翻倍期
3. 新人首洞奖 + 排行榜
4. 提报告质量（优质报告额外奖最高 5000）

现实锚点：全国月入超 1 万白帽仅 24 人——稳定副业（3000-5000/月）而非暴富。
