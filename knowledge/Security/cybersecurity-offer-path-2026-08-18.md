```
  第 3 月(重中之重): 产出完整渗透测试报告
          选靶场或 SRC 实际挖 2-3 个漏洞

          「学到这，你才具备拿下一个网安 offer 的能力」

结尾: 「90% 的人都只停留在现成的 POC 脚本，
       宁愿相信一个注入工具打，也不愿意去抠底层原理」
```
