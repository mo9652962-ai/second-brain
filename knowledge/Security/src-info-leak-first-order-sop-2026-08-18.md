# SRC 信息泄露首单实战 SOP（2026-08-18 双视频学习沉淀）

> 来源：成哥《5分钟挖SRC信息泄露漏洞》(7.56万赞) + 网安小宇《放假挖洞2k+》
> 定位：新手首单最优路径 = 信息泄露漏洞

## 一、成哥完整 SOP（base 模型转写还原）

```
① 选目标网站（必须在 SRC 平台授权范围）
② 找至少 2 个高风险页面（用户中心/订单/搜索/个人资料）
③ 按 F12 打开开发者工具 → 刷新页面 → 看到数据包
④ 🔥 核心技巧: 用 Network 面板搜索框过滤「User」
   → 快速过滤出用户信息相关数据包（省 90% 时间）
⑤ 逐个点击过滤后的数据包 → 看响应内容
   → 如果包含手机号/邮箱/地址等敏感信息
   → 而且不需要登录就能访问 = 真实信息泄露漏洞 ✅
⑥ 保存发现过程的所有截图（后面提交报告要用）
⑦ 回到 SRC 平台 → 提交漏洞 → 按 4 部分模板写报告:
   1. 漏洞标题 = 厂商名称 + 漏洞类型
   2. 复现步骤 = 每一步写清楚（审核照着能复现）
   3. 漏洞危害
   4. 修复建议
⑧ 等审核（1-3 工作日）→ 赏金 7 工作日内到账
```

### 报告打码规范（关键红线）
```
敏感信息只留前后两位，中间用星号代替
例: 手机号 138****8000 / 身份证 110***********1234
证明漏洞存在即可，不要泄露完整信息
不要夸大危害: 是什么等级就写什么等级
```

### 审核时间线
```
审核: 1-3 个工作日（漏洞盒子/补天）
赏金: 审核通过后 7 个工作日内到绑定账户
状态: 个人空间 → 漏洞列表 → 查看审核状态
```
