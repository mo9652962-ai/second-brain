# OSS 公共读 = 隐私泄露现场（程序员Orion · 抖音 2026-08-21）

> 来源：抖音 @程序员Orion（创业中）《把身份证和合同设成公共读？你的 OSS 文件桶正在...》（1:XX）
> 转写 467 字（SenseVoice）

## 事故

```
头像/合同/身份证/营业执照全传同一个桶 → 图省事设公共读
→ 别人拿到一个外链地址/脚本扫路径规则 → 全站用户隐私批量下载
→ 系统变公共展览馆
```

> 文件能打开 ≠ 应该公开。对象存储不是网盘，权限开错就是隐私泄露现场。

## 保命打法（公私分桶 + 签名 URL）

```
① 公开资源(头像/封面) 和 私密资源(合同/证件/订单) 分桶存储
② 私密桶默认私有, 禁止公共访问
③ 前端看图/下载 → 先请求后端 → 后端验身份权限
   → 调云厂商 API 生成带签名的短时效 URL（如 5 分钟）
   → 过期作废
```

## 落地检查

```
□ 私密文件桶 ACL/权限 = 私有
□ 无公共读的敏感文件（合同/证件/订单附件）
□ 下载走后端签名 URL（时效 5-15 分钟）
□ 路径规则不可猜测（随机名/不可枚举）
```
