# 双非本科入局网络安全 · 视频学习笔记

> 作者: 白帽小七 | 抖音 4487573978505931
> 主题: 双非本科入局网络安全（攻防方向）需要的学历/技术/项目强度

## 核心观点（3 段式）

### ① 学历：攻防方向对学历要求相对不高
```
- 网络安全攻防方向 > 纯技术研发岗（研发要求学历）
- 更看重实战能力（学校教的都是理论/防火墙配置，真正对抗性技术靠自学）
- 计算机专业 or 非计算机专业入行都得自学 → 站在同一起跑线
- 双非不用一开始就觉得自己没机会
```

### ② 技术栈三层
| 层级 | 内容 | 说明 |
|:---|:---|:---|
| **第一层 基础** | 计算机网络（TCP/IP/HTTP 扎实）+ Linux（命令/权限管理）+ Web 安全原理（SQLi/XSS/CSRF/文件上传）+ 脚本语言（Python/Go）| 渗透测试/流量分析的根基 |
| **第二层 核心** | Web 渗透测试全链路（信息收集→漏洞发现→利用→提权→后渗透）+ Burp/CS/MSF 熟练 + 内网渗透/权限维持（域环境/PT攻击/绕过技巧）| 找工作最核心部分 |
| **第三层 工程** | 代码审计或日志分析（看懂 PHP/Java/Go 漏洞代码）+ 自动化脚本 + 应急响应 | 加分项，提升效率 |

```
公司真正关心的: 「你能不能发现系统的漏洞并给出解决方案」
不需要: 写编译器/造轮子/刷算法题
```

### ③ 项目：一个做透的真实项目 > 三个普通靶场
```
❌ 停留在 DVWA 基础靶场（一问原理说不出 = 露馅）
✅ 有价值项目特征: 明确的漏洞挖掘过程
   - 挖 SRC（真实系统）✅
   - 复现真实 CVE 漏洞
   - 针对一个 CMS/中间件完整做一次渗透测试
     （信息收集→漏洞利用→提权→写渗透报告，全环节跑一遍）
✅ 一个做透的漏洞复现或 SRC 挖掘记录 > 三个普通靶场练习
```
