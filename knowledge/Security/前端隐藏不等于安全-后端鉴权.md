# 前端隐藏 ≠ 安全：后端鉴权才是真（程序员Orion · 抖音 2026-08-21）

> 来源：抖音 @程序员Orion（创业中）《AI生成后台以后，把管理员按钮对普通用户隐藏，就代表安全？》（1:01）
> 转写 346 字（SenseVoice）

## 核心认知

> 权限不能靠前端不给你看，而应该靠**后端不允许你做**

- **坑**：AI 生成的后台只在前端判断管理员（不是管理员就隐藏按钮）
- **真相**：前端看不到按钮 ≠ 后端功能不存在——抓包/改请求直接调 API 照样执行管理员操作
- **正确**：每一次管理员操作到后端都要**重新判断权限**——普通用户后端直接拒绝(403)，管理员才放行
- 范围：商品管理/订单退款/用户管理/数据导出——全部这个逻辑
- AI 生成后台高频坑：按钮能点页面能跑 ≠ 权限设计完成

## 后端鉴权清单（接单交付对照）

```
① 所有管理接口（增删改/导出/退款）→ 后端中间件/装饰器鉴权
② 权限校验放后端，不信前端传的 role/user_type
③ 每个接口独立校验（防「只给列表接口加，详情接口漏」）
④ 默认拒绝：没显式放行的接口 = 403
```

## SRC 挖洞方法（攻防一体）

```
找「前端隐藏权限」接口:
① 登录普通用户 → F12/抓包看前端 JS → 找隐藏 API 路径
② 直接请求 admin 接口 (GET/POST /api/admin/xxx)
③ 返回 200 + 数据/操作成功 = 未授权访问漏洞
④ 对照 bizlogic_lab.py 靶场 /api/admin/delete/ 练习
```
