# 数据库公网裸奔 = 找死（程序员Orion · 抖音 2026-08-21）

> 来源：抖音 @程序员Orion（创业中）《你还在公网直连 3306？难怪你的数据库天天被黑客...》（1:17）
> 转写 455 字（SenseVoice）

## 事故

新手为了方便连改数据 → MySQL 绑公网 IP + 3306 全开 + 权限 0.0.0.0 → 公网扫描机器人一周内暴力破解 → **全盘脱库删光 + 勒索比特币**

## 保命打法（VPC 物理隔离）

```
✅ 核心 MySQL/缓存: 不分配公网 IP → 深藏私有子网（连不上外网）
✅ 只有后端应用服务器有资格通过内网通信
✅ 在家查线上数据 → 堡垒机 / SSH 隧道
```

> 金句：不给数据库穿防弹衣，别说自己是全栈。

## 落地检查（部署/接单交付对照）

```
□ 云服务器安全组: 3306/6379 不对公网开放（仅内网/白名单 IP）
□ DB/缓存无公网 IP
□ 弱口令检查: root 密码强度 / 禁止空密码
□ 远程访问走堡垒机/SSH 隧道
□ 公网暴露面扫描（SRC: 3306/6379/9200/5432 等高危端口）
```
