# 日志泄露：敏感字段脱敏（程序员Orion · 抖音 2026-08-21）

> 来源：抖音 @程序员Orion（创业中）《别再乱打日志了，小心用户信息全泄露》（1:27，页面章节要点）

## 坑

新手为调试方便，在后端接口打印完整请求包/用户对象 → 密码/token/手机号进日志 → 日志被查看/泄露 = 敏感信息全暴露。

## 保命打法

```
① 统一封装 Logger 中间件/拦截器（不散落打印）
② 敏感字段脱敏: password→*** / phone→138****1234 / token→截断
③ 日志不含: 密码/验证码/完整token/身份证/银行卡
```

## 落地检查

```
□ 全局搜 print/log 打印 request/user 对象
□ 统一日志切面 + 脱敏注解（@Sensitive / 自定义序列化）
□ 日志分级: DEBUG 可含脱敏详情, INFO 不含敏感
```
