# 银狐木马预防 · 千轮研究（2026-08-17）

> 来源：公安部网安局 5 起典型案例 + 北京大学通告 + 国家病毒应急中心预警 + 360 年度报告 + 安天追踪 + CN-SEC 分析
> 技能沉淀：`silver-fox-malware-defense`（Hermes）

## 一、银狐是什么

针对中国企事业人员的远程控制木马，重点攻击财务/税务/人事岗位。「银狐」已不再是特定家族，而是一类木马的通称——背后制作/免杀团伙 20+，2025 前 11 个月 967 个新变种、约 3 万免杀样本，攻击能力准 APT 级。

## 二、攻击规模（360 年度报告）

工作日日查杀 5 万+/天；传播高峰周 90 余万次；单日拦截峰值 20 万+/天；免杀更新分钟级（高峰日 200+ 新版本）。

## 三、技术演进（2025 内核级对抗）

- 白加黑（正常 exe 加载恶意 DLL+ShellCode）
- BYOVD（合法签名漏洞驱动，Ring 0 强杀 EDR）
- SigFlip（改驱动时间戳，签名仍有效）
- EDRSilencer（WFP 屏蔽 EDR 云端通信）
- WDAC 滥用、PowerChell（先干 AMSI/ETW）
- ChaCha20+硬件随机数（流量审计失效）
- AtlasCross 变种（Typosquatting + 偷 EV 证书 + 内存无文件执行 + 定向注入微信 DLL）

驻留 5 种：无文件/LOLBAS、合法软件「永久免杀」（IP-guard）、自启动项、ShellCode 注入、软件劫持。

## 四、获利三大分支

转账诈骗（冒充领导，大额）/ 扫码电诈（小额高频 2000-3000/笔）/ 数字货币窃取（最难追回）+ 勒索前置。

## 五、2025 趋势

从「精准大额」转向「广撒网小额」，受害人群扩散到普通用户+海外华人；假安全之名钓鱼（「防范银狐木马」文件名）；盗版 IP-guard 被利用。

## 六、真实案例

北京怀柔财务小王：收到「税务机关」邮件点 .exe → 木马监控微信 → 骗子克隆领导号 → 拉群指令转 40 万 → 想起反诈宣讲报警止付 → 40 万保住。

## 七、预防 + 应急

- 预防三层面：源头（官网下载/查签名）/ 过程（核实发送者/不信广告链接）/ 技术（杀软实时监控/复杂密码/双因子/HVCI）
- 应急 8 步：断网 → 下线聊天工具 → 通知亲友 → 全盘查杀 → 清微信缓存 → 改密码 → 重装系统 → 杀软异常关闭即断网停用
- 关键认知：银狐不盗微信密码，利用已登录账号传播 → 断网+下线聊天工具优先于查杀
- 可疑文件检测：virus.cverc.org.cn（国家计算机病毒协同分析平台）
