## 调研发现：万年历 AI 开发的关键资产

### ⭐ 1. lunar-calendar-service（MCP 服务，AI 直接可查）
- **仓库**：github.com/wouhao/lunar-calendar-service（MIT，1★，2026-03 活跃，52 commits）
- **价值**：给 AI Agent 用的中文万年历 MCP 服务——AI 开发万年历**不用写农历转换公式**，直接调用 API
- **9 个工具**：公农历互转 / 24 节气 / 法定节假日 / 黄历宜忌 / 八字五行 / 黄道吉日
- **技术栈**：Python 3.11 + uv + lunar-python（6tail 的历法库）+ FastMCP + Pydantic v2
- **接入**：本地 stdio 或云端 SSE（Railway 部署），Claude/Cursor 等 MCP 客户端直接配
- **本地跑**：`uv sync && uv run python server.py`；CLI：`uv run python cli.py today`

### ⭐ 2. lunar-python（核心历法库）
- github.com/6tail/lunar-python（成熟历法库，公农历/干支/节气/黄历全支持）
- 所有中文万年历项目的基石，MIT

## 对 sora 业务的落点

**闲鱼 PCB/单片机接单（万年历是常客）：**
1. **接单话术升级**：用 AI 开发 → 报价可以更高（「AI 辅助开发，工期短交付快」）
2. **技术路线**：ESP32-C3（成本低）或 ESP32-S3（带屏）+ LVGL + lunar-calendar-service 或 lunar-python
3. **AI 开发流程**：让 AI 直接生成 Arduino/PlatformIO 代码 → 本地编译烧录验证 → 交付
4. **差异化**：加天气显示（心知天气 API）→ 加价项；加墨水屏低功耗 → 电池供电卖点

**B站/AI博主内容方向：**
- 「AI 一小时做出 ESP32 万年历」是很好的实操选题（AI自动化+单片机蓝海）

## 注意事项

- lunar-calendar-service 只有 1★（小众但代码完整、有测试 26 个），适合作为参考/自部署
- 万年历农历数据年份范围：lunar-python 支持 1900-2100，查表法更稳
- ESP32 项目编译环境：PlatformIO（VSCode 插件）比 Arduino IDE 更适合 AI 生成的项目
