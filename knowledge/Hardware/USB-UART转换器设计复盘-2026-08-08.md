# USB-UART 转换器设计复盘（嘉立创示例项目学习）

> 来源：嘉立创 EDA 示例项目（CH340G + USB-C + 3.3V LDO + FTDI 风格）
> 日期：2026-08-08 · 学习要点 + 可复刻方案

## 一、架构拆解（6 个功能模块）

```
USB-C 接口 ──→ CH340G (USB转串口) ──→ FTDI 排针 (DTR/RTS/TXD/RXD/CTS)
   │                  │
   ├─ CC1/CC2 ← 5.1kΩ 下拉 (UFP 识别)   ├─ 3.3V LDO (LM1117) ← 5V 输入
   └─ VBUS 5V ────────────────┼─────────────┴── 电压选择开关 (3V3/5V 切换)
                              └── PWR_LED 电源指示 (R + LED)
```

## 二、设计要点（结合 CH340 官方手册）

### 1. CH340G 核心电路
| 元件 | 规格 | 要点 |
|:---|:---|:---|
| 晶振 | 12MHz 无源 | XI/XO 之间；负载电容 22-33pF（陶瓷晶振用 47pF）|
| V3 引脚 | 0.1μF | 内部 3.3V 节点退耦，**必须接** |
| 外部退耦 | 0.1μF | 靠近 VCC 引脚 |
| 5V 供电 | VCC=5V | V3 接 0.1μF 到地 |
| 3.3V 供电 | V3 连 VCC | 同时外部 3.3V 输入（周边电路电压 ≤3.3V）|
| UD+/UD- | 直连 USB | 内置上拉，无需外置 |

### 2. USB-C 接口
- **CC1/CC2 各接 5.1kΩ 下拉到 GND**（UFP 设备识别——本设计 R4/R5）
- VBUS 5V 直接供电（10W 内小功率无需 PD 协商）
- 数据 D+/D- 直连 CH340G

### 3. 电压选择开关（本设计亮点）
- SW 切换 VCC_3V3 / VCC_5V → 兼容 3.3V 和 5V 目标板
- 对应 FTDI 风格排针（VCC/GND/TXD/RXD/CTS/RTS/DTR/DSR 全信号引出）

### 4. PCB 布局布线（CH340 手册要求）
- 退耦电容**尽量靠近** CH340 对应引脚
- D+/D- 平行布线 + 两侧地线/覆铜（抗干扰）
- 晶振走线**短** + 周边覆铜环绕（高频）
- 电源轨（5V/3V3）加粗走线
- GND 均匀分布（多处过孔接地）

## 三、对工具链的启示（可复刻）

我们已有 KiCad + SKiDL 自动化流程，可以**用 SKiDL 复刻此设计**：

```python
# 核心 SKiDL 片段（示意）
from skidl import Net, Part

ch340 = Part('xess.lib', 'CH340G', footprint='SOIC-16')
usbc  = Part('conn', 'USB-C-16P', footprint='USB_C_Receptacle')
ldo   = Part('regul', 'LM1117-3.3', footprint='SOT-223')
xtal  = Part('device', 'Crystal', value='12MHz')
c_v3  = Part('device', 'C', value='0.1uF')  # V3 退耦
cc1   = Part('device', 'R', value='5.1k')   # USB-C CC 下拉
```

复刻流程：SKiDL 原理图 → KiCad PCB → .enet 网表 → 嘉立创真元件 → 打样

## 四、改进建议（对比本设计）

> ⏳ **状态（2026-08-14 建议落实扫描）**：以下 4 项为下一版复刻 backlog，当前版不动；若接单需出「升级版」时优先做 1+4（ESD + CH340N 更小封装）

1. **加 ESD 保护**：USB-C 口加 ESD 器件（如 USBLC6-2）——原设计 D1/D2 二极管可升级
2. **串口电平选择**：本设计用跳线/开关——可加 3.3V/5V 双供电 + TXD/RXD 电平自动适配
3. **板载 LED**：TX/RX 数据指示灯（TNOW 引脚可指示发送状态）
4. **更小封装**：CH340N（内置晶振）可省晶振与 2 电容——小板更小

## 五、用途

- 嵌入式调试必备工具板（ESP32/STM32 开发标配）
- 闲鱼接单热门品（CH340G 方案成本 5-8 元，售价 15-30 元）
- 教学演示（模块化设计最佳范例）
