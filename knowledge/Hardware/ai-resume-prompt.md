# AI 求职简历提示词 · 高级设计排版

来源：社区分享
更新：2026-07-25

## 提示词特点
超高密度视觉描述，适合 Midjourney / DALL-E / Grok Imagine 等 AI 生图工具。

## 核心设计要素

| 要素 | 描述 |
|:-----|:------|
| **版式** | 竖版 9:10，不对称双栏网格 |
| **主体** | 大尺度黑白抠像，上缘清晰，下缘乳白雾化融入纸面 |
| **符号** | 极细线描放大字母/主题符号，被主体遮挡，制造前后穿插 |
| **签名** | 雾化交界上横跨纤细连笔签名字样，唯一高纯度强调色 |
| **标题** | 粗重几何无衬线 + 轻斜体副标题 |
| **内容** | 左对齐固定栏宽，章节标题/正文/图标三级尺度跃迁 |
| **能力项** | 空心小圆点领行，圆点/缩写表达熟练度 |
| **联系方式** | 小型实心方块图标 |
| **定位框** | 对角位置的短虚线+小方点开口框 |
| **色彩** | 大面积明亮浅底 + 近黑至中灰单色阶 + 少量高纯度强调色 |
| **质感** | 哑光纤维基底，极细灰色颗粒+轻微云雾斑+扫描式不规则纹理 |
