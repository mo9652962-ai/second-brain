# 三角洲干员人物"明天过后"转场制作教程

## 视频核心流程（两个阶段）

### 阶段一：音乐播放器式视频制作（00:10-01:08）
1. **导入人物视频**（三角洲干员出场素材）
2. **调整背景颜色**（画布/背景色）
3. **蒙版 + 抠图**（人物抠出，去掉原背景）
4. **添加音乐元素**：
   - 音乐歌词（文本歌词对齐）
   - 碟片（圆形蒙版 + 旋转关键帧）
   - 人物照片
   - 视频进度条（贴纸）
5. **碟片转动效果**（关键帧旋转动画）
6. **音效贴纸 + 英文贴纸**（包装）
7. 导出备用

### 阶段二：云朵转场制作（01:08-01:25）
1. 导入两段视频
2. 点击**小白块**（转场按钮）→ 选择**云朵转场**

## 关键技术点（搜索补充）

### 神人转场核心逻辑（通用）
```
两段相似动作视频拼接：
1. 转场素材（人物翻滚/摔瓶子/射箭/举枪）→ 找到动作帧 → 按 W 裁剪删除后面
2. 出场素材（另一段相似动作）→ 找到相同动作帧 → 按 Q 裁剪删除前面
3. 对齐两段素材（动作衔接点）
4. 添加卡点 BGM（favorite pitch / weber patch 等）→ 找到高潮点按 M 打标记 → 对齐分割处
5. 转场处添加特效（推进/叠化/穿越/震动/湍流冲击）
6. 框选全部 → 右键新建复合片段 → 运动模糊（模糊30~50，融合10）
```

### 碟片效果制作（播放器风）
```
1. 素材改 1:1（编辑→调整大小）
2. 圆形蒙版（双指放大调位置）
3. 碟片贴纸 + 播放器贴纸（层级调整）
4. 关键帧旋转（开头0° → 结尾360°/720°）
5. 混合模式绿色（歌词/播放器叠底）
6. 特效：水中倒影（垂直位移20-25）+ 左右摇晃 + 频谱（音频来源选音乐）
7. 进度条贴纸（可取消等比缩放调宽高）
```

### 蒙版转场原理（通用方法论）
```
图层遮罩 + 关键帧动画：
1. 两片段叠轨（上方片段 = 即将显示的）
2. 蒙版形状（线性/圆形/矩形/自定义）
3. 关键帧动画蒙版属性（位置/大小/旋转）
4. 羽化柔化边缘（高级感关键）
5. 反转蒙版（隐藏区域转场）
6. 曲线缓动（三次方缓入/缓出——开始结束慢、中间快）
7. 叠加光效/粒子/音效增强冲击
```

## 可复用方法论（B站/接单适用）

1. **神人转场 = 相似动作拼接 + BGM 卡点 + 运动模糊**——任何两段动作相近的素材都能做（游戏开场/动画片/电影镜头）
2. **碟片播放器 = 圆形蒙版 + 旋转关键帧 + 贴纸包装**——通用"高级感"包装模板
3. **剪映免费资源就够**：官方素材库（黑底/雪花/白场）+ 贴纸（碟片/播放器/进度条/英文）+ 特效（水中倒影/左右摇晃/湍流冲击/震动）
4. **关键帧曲线**：三次方缓入/缓出是剪映动画自然感的核心
5. **复合片段 + 运动模糊**：批量素材包装 + 模糊30-50 让转场丝滑

## 落地建议
- 用户可制作：三角洲/骑砍/游戏剪辑视频（B站实战派定位契合）
- 素材需求：游戏内录制出场/操作视频 + 任意相似动作素材
- 工具：剪映（免费版够用）
