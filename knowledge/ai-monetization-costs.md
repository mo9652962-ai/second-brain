## 四、闲鱼运营技巧

### 标题公式
```
关键词 + 价格锚点 + 信任感
例：AI PPT代做 工作总结 答辩 9.9元起 快速出图
```

### 主图
- 放PPT样张截图（不要AI生成图，用实图）
- 标价格在图上

### 擦亮技巧
- 每天擦亮1次（早上8-9点最佳）
- 前期定价低冲销量，攒5-10条好评后提价

## 五、避坑指南

1. ❌ "躺赚""零投入高收益" → 被举报封号
2. ❌ 过时方法（2024年的玩法2026年已失效）
3. ❌ 拉人头分销 → 本质是割韭菜
4. ❌ 纯AI直出不加人工 → 客户差评，退款率高
5. ✅ 必须有人工精修 + 去AI味

## 六、变现工作流

### PPT代做流程
```
客户需求 → AI生成大纲 → 套模板 → 人工精修
→ Napkin AI做图表（免费）→ Ideogram做封面（免费额度）
→ 导出PPTX → 客户确认 → 收款
```

### 论文降重流程
```
客户发论文 → 查重（维普AIGC 20元/篇）
→ AI降重（零感AI 1元/千字）→ 人工精修去AI味
→ 再次查重验证 → 交付报告
```
