    本地环境¶

    • OS: Windows 11 (24H2)
    • Shell: PowerShell 5.1（不支持 && 和 ||）
    • Git: 已安装
    • Python: python-pptx, Pillow
    • Node: v24.18.0, npm registry → npmmirror

    常用工具¶

    • Visual C++ 运行库: AIO v0.105.0（全版本已安装）
    • Wallpaper Engine: Steam
    • Hermes Agent Desktop: Hermes Agent GUI 桌面应用（任务面板、终端、预览、TUI dock）
    • Obsidian: 知识中枢 / 库文件管理（.openclaw/workspace/knowledge/ 映射到 Obsidian vault）

    PowerShell 注意事项¶

    • 命令分隔用 ;（不能用 &&）
    • 条件用 if ($?) { ... }
    • 2>$null 代替 2>nul
    • 路径用 \\ 而非 /

    搜索工具（5-Way 多后端）¶

    后端 用途
    Tavily 主力 AI 搜索
    Exa 语义神经搜索
    Firecrawl JS 渲染 + 反爬
    DDGS DuckDuckGo 免费回退
    SearXNG 自托管元搜索引擎

    配置方式: hermes config set search.backends '["tavily","exa","firecrawl","ddgs","searxng"]'

    系统维护¶

    VC++ 运行库¶

    • 工具: VisualCppRedist_AIO v0.105.0 (30.7MB)
    • 全版本检查: 2005/2008/2010/2012/2013/2015-2022
    • 注意: 2005/2008 在 WinSxS 中，不显示为独立条目

    SFC / DISM 系统扫描¶

    • SFC: sfc /scannow — 需管理员权限
    • DISM: DISM /Online /Cleanup-Image /RestoreHealth — 先执行，再 sfc
    • 场景: 系统文件损坏、游戏报错、dll 缺失
