# DeepTutor 架构吸收笔记

来源：https://github.com/HKUDS/DeepTutor (28k⭐)
香港大学数据智能实验室

## 核心思路：自适应个性化教学

| 能力 | 说明 |
|:----|:------|
| 知识掌握感知 | 动态检测你的薄弱点 |
| 节奏调整 | 根据掌握程度自动加快/放慢 |
| 练习难度 | 从简单到困难渐进式提升 |

## 可借鉴到学习的点

1. **渐进式学习** — 不跳步，确认掌握了再进阶
2. **薄弱点优先** — 先补短板再练长处
3. **动态反馈** — 每学完一个知识点测一下理解程度
