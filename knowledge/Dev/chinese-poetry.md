# chinese-poetry · 最全古诗词数据库

来源：GitHub (52,359⭐，中文开源前排)
链接：https://github.com/chinese-poetry/chinese-poetry

## 数据量

| 类型 | 数量 |
|:-----|:------|
| 唐诗 | 5.5 万首 |
| 宋诗 | 26 万首 |
| 宋词 | 2.1 万首 |
| 诗人 | 1.4 万位（带生平简介） |
| 其他 | 诗经、楚辞、论语、纳兰词 |

## 优势

- **JSON 格式**：标题/作者/正文/平仄标注全部分好字段
- **MIT 协议**：商用/二改/打包 App 都不受限
- **本地运行**：下载到本机直接用，无 API Key、无调用限制、无账单

## 安装使用

```bash
# Node.js 一键装
npm install chinese-poetry

# 启动本地 API
npx chinese-poetry-server
```

或直接去 Releases 下载压缩包。
