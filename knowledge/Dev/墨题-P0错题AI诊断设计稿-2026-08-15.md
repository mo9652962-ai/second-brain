# P0 错题 AI 诊断功能设计稿

> 基于墨题现状（wrong_analysis.py 已实现单题归因 + ReportView.vue 已有统计报告）
> **核心结论：单题归因已有 80%，缺「归因聚合 → 学习诊断报告」这一层**

## 一、现状盘点（实证）

| 已有 | 位置 | 说明 |
|:---|:---|:---|
| ✅ 12 分类归因 | `wrong_analysis.py` | vocabulary/collocation/grammar/context/discourse/detail/inference/main_idea/attitude/trap/carelessness/uncertain |
| ✅ 归因 prompt | `diagnose_wrong_answers` | recency 加权、证据不足用 uncertain、防泄漏（不输出解析/选项文字）|
| ✅ 历史作答跟踪 | `_question_history` + practice_answer_events | 改答案事件、12 条最近记录 |
| ✅ 预标注 | `question_ai_labels` | primary_skill/secondary_skills/trap_types/vocabulary_demand |
| ✅ 统计报告 | `report.py` + ReportView.vue | 正确率趋势/题型雷达图/词汇进度/智能建议 |
| ✅ 前后对比雏形 | `previous_snapshot` 参数 | 已传但未形成「诊断变化」视图 |

## 二、缺口定义

**「单题归因」（已经有了）≠「学习诊断」（缺）**：
- ❌ 没有把 N 道错题的归因**聚合**成薄弱知识点排行
- ❌ 归因给了通用建议（CAUSE_GUIDANCE），但没有**推荐具体练习**的闭环
- ❌ 没有「水平评估」（当前水平 1-5 + 阶段目标）
- ❌ 没有「诊断变化」（上次 vs 本次：改善/恶化/新问题）
- ❌ ReportView 是统计型（正确率），不是学习型（怎么改）

## 五、AI 归因实现（现有 + 增强）

### 已有（不动，已验证）
- `diagnose_wrong_answers`：逐题 12 分类归因

### 新增：聚合层（`diagnostic_aggregate.py` 新服务）
```
输入: question_ids（本次错题） + 上期 snapshot
步骤:
1. 调 diagnose_wrong_answers 得逐题归因（复用现有）
2. 本地聚合（不调 AI）：Counter 统计 cause 分布 → 薄弱点排行
3. 水平评估（AI 轻调）：只给薄弱点 TOP3 + 推荐路径 → 模型判断 level 1-5
   - prompt 只输入：cause 分布 + 各维度正确率 + 上期 level（不含题目文字，防泄漏）
4. trend 对比：上期 cause 分布 vs 本期（improved/worsened/new 全本地算）
5. recommendations：按薄弱 cause → 题库筛选（question_type + question_ai_labels 匹配）+ 词库单元
```

### 关键设计决策
- **AI 只做两件事**：逐题归因（已有）+ 水平评估（轻量）——**聚合/对比/推荐全本地**（省 token、可离线、可解释）
- **防泄漏延续**：聚合 prompt 不给题目/选项/原文，只给 cause 统计
- **uncertain 处理**：低于 3 题样本的 cause 不展示（证据不足不误导）
- **action 闭环**：recommendations 直接带 question_ids / unit_id → 前端一键加入练习

## 六、实施清单

| 步骤 | 内容 | 工作量 |
|:---|:---|:---|
| 1 | 新建 `diagnostic_aggregate.py`（聚合+水平评估+推荐）| 1-2 天 |
| 2 | 新 router `diagnostic.py`（POST /api/diagnostic/report + GET 历史）| 0.5 天 |
| 3 | 新页面 DiagnosticView.vue + 错题页入口 | 1 天 |
| 4 | previous_snapshot 持久化（存上次报告 JSON）| 0.5 天 |
| 5 | 测试：归因聚合正确性 + 防泄漏回归 | 0.5 天 |

**总计 3.5-4.5 人天**（复用现有 80%，纯增量）

## 七、验收标准

- [ ] 42 题错题 → 诊断报告 < 10 秒生成（AI 只调 2 次：归因批 + 水平评估）
- [ ] 薄弱点排行与人工标注一致率 ≥ 70%（抽样 20 题）
- [ ] 推荐 action 的 question_ids 真实存在且类型匹配
- [ ] 诊断报告不包含任何题目原文/选项文字（防泄漏回归）
- [ ] 离线/API 失败时：显示本地统计降级版（无 AI 水平评估但有薄弱点排行）
