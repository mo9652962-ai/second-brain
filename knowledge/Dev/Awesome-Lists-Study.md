## 🏆 Awesome Python 精选项目

### 🔴 高优先级（立即能用）

#### 1. markitdown ⭐ 168,802
- **简介**: 微软出品的文件转 Markdown 工具
- **用途**: 批量导入 Word、PDF、PPT 等文件到 Obsidian
- **安装**: `pip install markitdown`
- **价值**: ⭐⭐⭐⭐⭐
- **笔记**: 知识库建设神器！

#### 2. uv ⭐ 87,849
- **简介**: Rust 写的极速 Python 包管理器，比 pip 快 10-100 倍
- **用途**: 替代 pip，加速所有 Python 环境操作
- **安装**: `pip install uv`
- **价值**: ⭐⭐⭐⭐⭐
- **笔记**: 性能提升立竿见影

---

### 🟡 中优先级（深入研究）

#### 3. browser-use ⭐ 106,621
- **简介**: AI Agent 浏览器自动化框架
- **用途**: 让 Hermes 能真正操作浏览器
- **价值**: ⭐⭐⭐⭐⭐
- **潜在应用**:
  - 自动搜索、整理信息
  - 自动填表、提交表单
  - 网页自动化测试
- **与 Hermes 集成**: 可以作为 MCP 工具

#### 4. Graphify ⭐ 95,265
- **简介**: 代码/文档/论文/图片转知识图谱
- **用途**: Obsidian 知识库的超级补充！
- **价值**: ⭐⭐⭐⭐⭐
- **潜在应用**:
  - 代码库分析
  - 论文关联发现
  - 跨文档知识连接

#### 5. vLLM ⭐ 87,088
- **简介**: 高吞吐量 LLM 推理引擎
- **用途**: 本地部署模型加速
- **价值**: ⭐⭐⭐⭐
- **场景**: 需要本地运行大模型时

#### 6. Agenta
- **简介**: LLMOps 平台
- **用途**: 统一管理所有 Prompt，版本控制，A/B 测试
- **价值**: ⭐⭐⭐⭐
- **好处**: Prompt 工程系统化

## 🏠 Awesome Self-hosted 精选项目

### 🔴 高价值个人工具

#### 1. AFFiNE ⭐ 70,799
- **简介**: Notion + Miro 开源替代
- **用途**: 知识库前端备选，白板协作
- **价值**: ⭐⭐⭐⭐⭐
- **部署**: Docker 一键部署

#### 2. Actual ⭐ 27,708
- **简介**: 本地优先个人财务管理
- **用途**: 第二大脑的财务模块
- **价值**: ⭐⭐⭐⭐⭐
- **特性**: 零基预算，多设备同步

#### 3. ActivityWatch ⭐ 18,367
- **简介**: 自动时间追踪
- **用途**: 量化自我，分析生产力模式
- **价值**: ⭐⭐⭐⭐⭐
- **部署**: Windows 客户端 + 服务器

#### 4. Activepieces ⭐ 23,426
- **简介**: Zapier 开源替代
- **用途**: 无代码自动化，连接各种服务
- **价值**: ⭐⭐⭐⭐⭐
- **集成**: 数百个现成连接器

#### 6. 2FAuth ⭐ 4,065
