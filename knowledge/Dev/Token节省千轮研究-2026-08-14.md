# Token 节省千轮研究 · 落地报告

## 核心结论

缓存命中率是最大省钱杠杆（**50-100 倍价差**），其次砍工具结果回灌、上下文修剪、模型路由。成本周报显示缓存在工作（cache 读 27.8M），最大浪费是 glm-5.2 高价兜底 + 长会话滚雪球。

## 四大省钱杠杆（研究实证）

| 杠杆 | 节省幅度 | 说明 |
|:---|:---|:---|
| 缓存命中 vs 未命中 | **50-100 倍** | DeepSeek 缓存读 ¥0.0028/M vs 全价 ¥0.14/M |
| 工具结果截断 | TRAE 案例 76% token | tool 结果占大头，需截断/摘要/引用句柄 |
| 上下文修剪/摘要 | 50 步任务省 62% | 历史封顶 + 定期摘要替换 |
| 模型路由 | 8:2 分工省 75% | 简单→便宜模型，关键→旗舰 |

## 缓存友好架构（核心）

```
✅ 稳定前缀在前（系统提示+工具+历史）→ 命中缓存
❌ 易变内容在前（时间戳/随机ID/RAG结果）→ 每轮失效

缓存杀手：
- system prompt 放时间戳/日期 → 每轮缓存失效
- 工具列表每次乱序（dict/set 序列化）→ 前缀对不上
- RAG 检索结果放指令前面 → 每次都变
- 会话中间改写历史 → 全断
- 注入 session ID/request ID 到前缀 → 挪到末尾
```

**实测**（Reasonix 框架）：前缀冻结 → 命中率 85-95%，省 94%；通用框架前缀漂移 → 命中 <20%。

## 其他关键认知

1. **DeepSeek 官方缓存读价全市场最低**（¥0.0028-0.03/M，比次优托管商便宜 6-28 倍）——缓存密集 agent 活走官方最划算
2. **思考模式烧钱**：推理 token 按输出价计费（贵 3-5 倍）——简单/格式固定任务关思考
3. **失败重试是乘法项**：503/504 重试风暴不仅失败还烧钱——护栏（最大步数/预算熔断/重复检测）是底线
4. **DeepSeek V4 Flash 缓存价差**：托管商缓存读价差 28 倍（$0.0028-$0.078），选托管商要看缓存读价
5. **盈亏平衡 ~77% 缓存命中率**：高于走官方，低于走便宜托管商
