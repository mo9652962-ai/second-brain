## 2. 字体规范统一

### 小学教材标准字体配置

| 内容类型 | 字体 | 字号 | 颜色 | 加粗 |
|---------|------|------|------|------|
| 主标题（第X天） | 黑体 | 二号/小二 | 黑色 | ✅ |
| 板块标题（一、口算） | 宋体 | 四号 | 黑色 | ✅ |
| 题目内容 | 宋体 | 小四/五号 | 黑色 | ❌ |
| 等号横线 | 宋体 | 小五 | 黑色 | ❌ |
| 姓名/用时/家长签字 | 宋体 | 五号 | 灰色 | ❌ |
| 答案部分标题 | 黑体 | 三号 | 黑色 | ✅ |

**WPS操作步骤：**
1. 选中要修改的文字
2. 在 [开始] 工具栏选择字体、字号
3. 使用格式刷统一应用到全部文档

    3. 段落格式优化¶

    3.1 行距设置¶

    内容类型 行距 段前 段后
    主标题 1.5倍 0.5行 0.3行
    板块标题 固定值20磅 0.3行 0.1行
    口算题目 固定值18磅 0 0
    竖式计算 固定值22磅 0 0
    分数口算分子/分母行 固定值16磅 0 0
    分数分数线行 固定值14磅 0 0

    WPS操作步骤： 1. 选中段落 → 右键 → [段落] 2. 选择 [行距] 选择对应类型，输入数值 3. 输入段前/段后间距

    ### 3.2 缩进设置

    首行缩进: 0字符（题目不缩进） 左缩进: 0.5字符（使题目整体右移一点）

## 4. 分数竖式格式精修

### 4.1 使用WPS公式编辑器（推荐）Alt+=）

**步骤：**
    1. 光标放在要插入分数的位置
    2. 按快捷键 Alt + = 调出公式编辑器
    3. 点击 [设计] 菜单
    4. 选择 [分数] → [竖式分数（上）
    5. 输入分子和分母
    6. 在分数后输入减号、等号
    7. 重复以上步骤
    **效果：

    8 7 ─── - ─── = 10 10

    ### 4.2 分数对齐技巧

    选中分数格式设置：

    1. 选中所有分数
2. 右键 → 字体 → 高级
3. 位置：标准
4. 间距：标准
5. 如果分数线不齐，可以使用公式编辑器重新编辑

## 5. 对齐方式统一

### 5.1 题目对齐规范

    ✅ 正确对齐方式 | 对齐方式

    | 内容类型 | 对齐方式 | 说明 |
|---------|---------|------|
| 主标题（第X天） | 居中对齐 | |
| 姓名/用时/家长签字 | 居中对齐 | |
| 板块标题 | 左对齐 | 缩进2字符 |
| 口算题目 | 左对齐 | 自动换行 |
| 竖式计算 | 左对齐 | 每题单独一行 |
| 分数口算 | 两列左对齐 | 列间距均匀 |
| 填空题目 | 左对齐 | |
| 应用题 | 左对齐 | 首行缩进2字符 |

### 5.2 两列分数对齐技巧

    如果使用分栏对齐： 1. 选中所有分数口算 2. [页面布局] → [分栏] → 两栏 3. 勾选分隔线：否 4. 栏间距：2字符 5. 调整每栏的题目数量5题/栏

## 6. 页眉页脚设置

### 6.1 页眉设置

    页眉内容：三年级数学每日一练40天 字体：宋体，小五号，居中对齐

    6.2 页脚设置¶

    页脚内容：第 X 页 共 页
字体：宋体，小五号，居中对齐

**WPS操作步骤：**
1. [插入] → [页眉和页脚]
2. 输入页眉内容，设置格式
3. 切换到页脚，插入页码
4. 勾选首页不同（第一天不显示页眉）

## 7. 题目编号规范

### 7.1 编号统一

    一、两位数乘法口算 （一、二、三、四、五） 1. 34 × 20 = 2. 18 × 50 = ...

    二、两位数乘两位数笔算 （1. 2. 3. ...） 1. 23 × 34 = 2. 45 × 12 = ...

    三、分数口算 （1. 2. 3. ... 每题占三行） 8 7 1. ── - ── = 10 10

## 8. 打印预览与输出

### 8.1 打印预览检查清单

- [ ] 所有页面边距是否正确
- [ ] 题目是否有跨页问题
- [ ] 分数是否对齐
- [ ] 编号是否连续

- [ ] 行距是否合适
- [ ] 答案部分是否清晰

### 8.2 输出为PDF（推荐）
    1. [文件] → [另存为]
    2. 选择文件类型：PDF (*.pdf)
    3. 点击 [选项]
    4. 勾选符合ISO 19005-1标准（PDF/A）
    5. 确定 → 保存

## ⚡ 快速优化技巧

### 技巧1：使用格式刷批量应用
    1. 选中已经设置好的段落
    2. 双击格式刷（双击是连续应用，单击是一次）
    3. 点击要应用的段落
    4. 全部应用完后再点击格式刷取消
    ### 技巧2：使用样式管理器
    1. [开始] → [样式]
    2. 新建样式：主标题、板块标题、题目内容等
    3. 以后直接点击样式即可一键应用
    ### 技巧3：批量替换格式
    1. [开始] → [替换]
    2. 点击 [更多] → [格式]
    3. 可以批量替换字体、字号等 ```
