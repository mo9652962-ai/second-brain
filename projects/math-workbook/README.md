# 📐 三年级数学每日一练 — 实战项目

> 从零构建的 40 天练习册生成系统，已投入实际使用

## 项目概述

生成 40 天 × 1240 题不重复的三年级数学每日一练 Word 文档。从单脚本迭代为函数化五层架构（配置→工具→生成→渲染→流程），实践了十轮研究落地。

## 技术栈

| 层 | 技术 |
|----|------|
| 语言 | Python 3.11 |
| 文档 | python-docx |
| 包管理 | uv |
| 排版 | 人教版教材标准（宋体/黑体，Tab制表位） |

## 核心功能

| 模块 | 说明 | 状态 |
|------|------|------|
| 口算 | 两位数乘法，5 类难度递进，10 题/天 | ✅ 400/400 不重复 |
| 笔算 | 两位数×两位数列竖式，2×2 表格布局，4 题/天 | ✅ 160/160 不重复 |
| 分数 | 同分母加减法，10 题/天（加/减各半） | ✅ 400/400 不重复 |
| 单位换算 | 时分秒+年月日 200+ 题库，5 题/天 | ✅ 200 题不重复 |
| 应用题 | 乘法+分数各 1 道/天，40+ 题库 | ✅ 80 题不重复 |
| 单页适配 | 行距压缩、答题区精简、一页容纳 | ✅ v3.1 已验证 |
