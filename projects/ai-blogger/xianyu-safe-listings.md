## 🛡 防举报通用策略

| 策略 | 具体做法 |
|-----|---------|
| 标题避雷 | 不说"代做/代写/AI生成"，说"设计/优化/美化/咨询" |
| 正文避雷 | 强调"仅提供建议/协助"，避嫌"代写/代考" |
| 价格避雷 | 不设异常低价（<10元），不低于市场均价30% |
| 聊天避雷 | 不在聊天中说"代写论文""用AI生成"，用"文档处理"替代 |
| 图片避雷 | 封面不用"代做""代写"文字，用作品展示 |
| 发货避雷 | 通过闲鱼内发文件，不引导到微信/QQ |
| 差评应对 | 先沟通解决，不退款差评（平台判定恶意差评可申诉） |
| 多号策略 | 不同服务用不同商品，不集中在一个链接 |
