---

## 📝 B 视频发布标准流程

### 视频结构模板

```
▸ 开头（0-30s）：钩子 + 预告
  例："花了 3 天测试 5 个 AI 降重工具，最后只推荐这 1 个，剩下的别碰
```
→ 结论前置，3 秒抓住注意力

▸ 正文（1-15min）：分点讲解 + 实操演示
  每个要点配演示 + 效果对比
  节奏：每 3 分钟一个小结论/转场，避免观众流失

▸ 结尾（30s）：总结 + 引导关注
  例："下期测 AI 写论文降 AI 率实战，关注不错过
```

### 视频封面公式

```
主标题（大字，粗体
+
副标题（小字
+
左侧配图（对比图/实测图
```

颜色：高对比度，避免复杂背景

### B 站视频标签（固定标签

```
AI, 人工智能, 效率工具, 办公技巧, 大学生, 研究生, 论文, PCB, 编程, 副业, AI工具, 自动化
```

每视频专属标签 + 领域标签

## ✅ 内容发布检查清单

### [ ] 发布前检查项
- [ ] 封面图高对比度，文字清晰可读
- [ ] 标题有关键词，有钩子
- [ ] 简介有关键词，有引导
- [ ] 标签已添加（10-15个，混合大小流量标签
- [ ] 视频/图片无版权问题
- [ ] 有错别字检查
- [ ] 音频清晰，无杂音

### [ ] 发布后动作
- [ ] 发布后 1 小时内回复首条评论
- [ ] 评论区互动
- [ ] 置顶评论引导
- [ ] 其他平台同步
- [ ] 记录发布数据（观看/点赞/收藏/评论）
