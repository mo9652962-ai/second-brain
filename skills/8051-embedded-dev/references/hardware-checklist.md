# 51 单片机开发硬件清单

## 必备
- [ ] STC89C52RC 开发板 (或最小系统板) ×1
- [ ] USB 转 TTL 模块 (CH340/CP2102) ×1
- [ ] 杜邦线 (公母/母母各 10 根)
- [ ] USB 数据线 (Mini/Micro/Type-C, 给板子供电)

## 显示
- [ ] LED ×8 (红绿黄各几个, 5mm)
- [ ] 220Ω 限流电阻 ×8
- [ ] 4 位共阴数码管 ×1
- [ ] LCD1602 字符液晶 ×1 (带 I2C 转接板更方便)

## 输入
- [ ] 轻触按键 ×4
- [ ] 10KΩ 电阻 ×4 (上拉)

## 传感
- [ ] DS18B20 温度传感器 ×1
- [ ] 4.7KΩ 上拉电阻 ×1 (DS18B20 必需)

## 其他
- [ ] 蜂鸣器 (有源) ×1
- [ ] 10KΩ 排阻 ×1 (P0 口上拉)
- [ ] 面包板 ×1
- [ ] 烙铁 + 焊锡 (如果自己焊最小系统)

## 总预算
约 ¥50~100 (淘宝"51单片机开发板套件"一站式搞定)
