    📋 使用说明¶

    本知识库以中文为主，目的是降低国内开发者的学习门槛。

    但在实际工作中，你会遇到： - 需要用英文关键词搜索更准确的资料 - 需要和海外团队、开源社区交流 - 需要看懂英文文档和论文

    这张表就是帮你快速建立中英文对应关系的桥梁。

    🔍 中英文搜索对照表¶

    很多技术问题用英文搜能找到更准确的答案，这张表帮你快速转换关键词：

    你想搜的中文 推荐的英文关键词
    「如何设计 API」 API design best practices
    「XX 最佳实践」 XX best practices 2026
    「怎么调试 XX」 how to debug XX
    「XX 性能优化」 XX performance optimization
    「XX 架构设计」 XX architecture patterns
    「XX 踩坑」 XX common pitfalls
    「XX 教程」 XX tutorial getting started
    「XX 面试题」 XX interview questions
    「XX vs YY 对比」 XX vs YY comparison
    「XX 入门指南」 XX beginner's guide

    搜索技巧： - 加年份（比如 "2026"）过滤过时的内容 - 加 "best practices" 找业界共识的方案 - 加 "common pitfalls" 找踩坑总结 - 加 "cheat sheet" 找速查表

    💡 双语使用建议¶

    日常工作¶

    ✅ 中文：和国内团队交流、写内部文档、做笔记
  → 效率最高，没有理解障碍

✅ 英文：搜技术问题、看官方文档、和海外社区交流
  → 信息更新、更全、更准确

    知识管理¶

    ✅ 中文写笔记（理解深、记忆牢）
✅ 关键词保留英文（方便搜索）
✅ 重要术语附英文对照

    示例：

    ✅ 好的写法：「用 DFM（可制造性设计） 理念优化 PCB 布局，减少打板返工」

    ❌ 不好的写法：「用可制造性设计理念优化 PCB 布局」（少了英文关键词，以后搜英文资料找不到对应）
