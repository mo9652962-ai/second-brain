    🚧 待建领域一：🐳 DevOps / SRE¶

    核心内容规划¶

    ├─ 🐳 Docker 容器化
│   ├─ Dockerfile 最佳实践
│   ├─ 多阶段构建
│   └─ 镜像优化技巧
├─ ☸️ Kubernetes 编排
│   ├─ Pod / Deployment / Service / Ingress
│   ├─ Helm 包管理
│   └─ K8s 排障指南
├─ 🔄 CI/CD 流水线
│   ├─ GitHub Actions
│   ├─ GitLab CI
│   └─ ArgoCD GitOps
├─ 📊 可观测性
│   ├─ Prometheus + Grafana
│   ├─ ELK / Loki 日志
│   └─ 链路追踪（OpenTelemetry）
└─ 🚨 SRE 方法论
    ├─ SLO / SLA / SLI
    ├─ 错误预算
    └─ 事故复盘流程

    3 个月入门学习路径¶

    第 1 个月：Docker + Linux 基础
  ✅ 把自己的常用服务都容器化
  ✅ 学会写 Dockerfile，理解层缓存
  ✅ docker-compose 编排多个服务
  🎯 里程碑：把这个知识库 MkDocs 容器化部署

第 2 个月：Kubernetes 基础
  ✅ 用 k3d 搭一个本地 K8s 集群
  ✅ 学会 Deployment / Service / Ingress
  ✅ 学会 kubectl 常用排障命令
  🎯 里程碑：把你的服务部署到 K8s 上

第 3 个月：CI/CD + 可观测性
  ✅ 写一个 GitHub Actions 自动部署流水线
  ✅ 搭一个 Prometheus + Grafana 监控面板
  ✅ 接入日志系统
  🎯 里程碑：完整的 Git → 构建 → 部署 → 监控闭环

    入门推荐资源¶

    • Docker 官方文档 - 最好的入门资料，没有之一
    • Kubernetes Up and Running - K8s 入门圣经
    • Kubernetes Handbook（中文）- 国内最好的 K8s 中文资料
    • Site Reliability Engineering（Google SRE 书）- SRE 理念源头

    🚧 待建领域二：📈 数据工程¶

    核心内容规划¶

    ├─ 🗄️ 数据库与数仓
│   ├─ PostgreSQL 高级
│   ├─ ClickHouse 列式存储
│   └─ Snowflake / BigQuery 云原生数仓
├─ 🔄 ETL / ELT 管道
│   ├─ Airflow 工作流调度
│   ├─ dbt 数据建模
│   └─ Fivetran / Airbyte 数据接入
├─ 🐘 大数据技术栈
│   ├─ Spark 分布式计算
│   ├─ Kafka 消息队列
│   └─ Flink 流处理
└─ 📊 数据质量与治理
    ├─ Great Expectations 数据期望
    ├─ 数据血缘追踪
    └─ 数据 Catalog

    3 个月入门学习路径¶

    第 1 个月：SQL + 数据库进阶
  ✅ 刷完 LeetCode SQL 全部题目
  ✅ 学会 PostgreSQL 的高级特性（窗口函数、CTE、索引优化）
  ✅ 自己设计一个星型模型的数仓
  🎯 里程碑：1 亿行数据查询优化到秒级返回

第 2 个月：ETL 工具链
  ✅ 用 Airflow 搭一个定时数据同步任务
  ✅ 学会 dbt，做一个完整的建模项目
  ✅ 接入 Kafka 处理实时数据流
  🎯 里程碑：T+1 离线数仓 + 分钟级实时数仓双链路

第 3 个月：大数据引擎
  ✅ 本地跑 Spark，处理 GB 级数据
  ✅ 理解分区、分桶、数据布局优化
  ✅ 理解列存 vs 行存的适用场景
  🎯 里程碑：100GB 数据处理任务，成本和性能优化到极致

    入门推荐资源¶

    • Designing Data-Intensive Applications（DDIA）- 数据工程圣经
    • The Data Warehouse Toolkit - 维度建模经典
    • Apache Spark 官方文档 - 体系完整，示例丰富

    3 个月入门学习路径¶

    第 1 个月：需求分析
  ✅ 给你自己常用的一个产品写个需求分析
  ✅ 用 RICE 模型给 10 个功能排优先级
  ✅ 写 5 个高质量的用户故事
  🎯 里程碑：一份完整的产品需求文档 PRD

第 2 个月：数据分析
  ✅ 给一个产品设计核心指标体系
  ✅ 设计一个 A/B 实验方案
  ✅ 学习漏斗分析和留存分析
  🎯 里程碑：一份完整的产品数据分析报告

第 3 个月：真实项目实践
  ✅ 参与一个开源项目，以产品经理的视角提建议
  ✅ 给一个小产品做增长方案
  ✅ 写一份产品路线图 Roadmap
  🎯 里程碑：从零规划一个小产品的 3 个月路线

    入门推荐资源¶

    • Inspired - 产品经理必读书，如何创造用户真正喜爱的产品
    • Cracking the PM Interview - 产品经理面试圣经，同时也是很好的方法论
    • The Lean Product Playbook - 精益产品开发实战指南
