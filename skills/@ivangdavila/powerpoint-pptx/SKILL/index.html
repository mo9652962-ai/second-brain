    When to Use¶

    Use when the main artifact is a Microsoft PowerPoint presentation or .pptx deck, especially when layouts, templates, placeholders, notes, comments, charts, extraction, editing, or final visual quality matter.

    🆕 2026 Industry Awareness¶

    AI Integration Landscape¶

    Platform Integration Use When
    Plus AI Native PowerPoint/Google Slides add-in Need AI generation inside existing PPTX workflow
    Microsoft Copilot Built into Microsoft 365 Already on M365, need document→deck conversion
    Gamma Web-first card-based export Rapid prototyping, then export to PPTX for polish
    Beautiful.ai Rule-based auto-layout Design consistency is top priority
    Canva Magic Design + PPTX export Need large asset library + AI generation

    Key insight: In 2026, the optimal workflow often = AI generation (Gamma/Copilot) → PPTX export → manual QA/polish in PowerPoint.

    🆕 Async-First Awareness¶

    Most decks are now shared asynchronously via email/Teams/WeChat without a presenter.

    QA checklist for async-ready decks: - [ ] Can every slide be understood independently without a speaker? - [ ] Are all slide titles complete conclusion sentences (not descriptive phrases)? - [ ] Do charts have self-explanatory annotations/labels? - [ ] Are Speaker Notes filled for every slide (they are the "hidden narration")? - [ ] Is body text ≥18pt for mobile readability? - [ ] Are multi-column layouts avoided on content-rich slides?

    🆕 Gamma Card-Based Thinking¶

    The "card" mental model (from Gamma's dominance): - Each slide = one independent card/module - Cards can be reordered, skipped, or expanded without breaking the narrative - Traditional linear slides → modular card decks for flexible presentations - When editing existing decks: consider if rigid linear order could benefit from modular restructuring

    🆕 Mobile + Export Awareness¶

    • PPTX shared via links → opened on phones increasingly common
    • Export to PDF → check mobile rendering
    • Complex animations/transitions → often lost in export/conversion
    • Font substitution across platforms → test on target devices

    🆕 2026 Common Traps (新增)¶

    • AI-generated decks from Gamma/Copilot often look polished but break on PPTX export — always verify layout after import
    • Async-shared decks with incomplete Speaker Notes lose 40%+ of intended information
    • Mobile viewers can't read body text below 16pt — 2026 standard is 18pt minimum
    • AI-generated images may have inconsistent styles across slides — establish image style guidelines before generation
    • Card-based layouts export poorly to traditional PPTX if not explicitly designed for both formats
    • Copilot-generated speaker notes can be verbose; trim to key points only
