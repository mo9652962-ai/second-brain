    1. 2026 硬件创业新格局¶

    范式转移：硬件正在变"软"¶

    2010 年代的硬件创业
    ├── NRE (一次性工程费用) 高昂
    ├── 最小起订量 (MOQ) 数千起
    ├── 供应链不透明
    └── 烧钱速度堪比 SaaS

2026 年的硬件创业
    ├── 24-48 小时 PCB 打样
    ├── PCBA 一站式服务
    ├── 无 MOQ 或 极低 MOQ
    ├── 在线 DFM 实时检查
    ├── 开源设计复用率 >50%
    └── AI 辅助设计工具普及

净效应：硬件创业门槛降低了 10-100 倍

    2026 硬件创业优势趋势¶

    趋势 影响
    AI 设计工具 原理图/PCB 布局效率提升 5 倍
    开源 IP 核 RISC-V 等免授权费内核普及
    模块化设计 子系统像乐高一样组合
    DFM Shift-Left 设计阶段即时检查可制造性
    分布式制造 靠近客户的区域性制造网络
    远程测试验证 不用飞深圳也能看产线测试

    🔥 硬件 + AI 交汇 = 最大机会¶

    边缘 AI 硬件 = 2020 年代最大的硬件机会
    ├── TinyML 模型直接在 MCU 运行
    ├── 数据本地化 = 隐私合规
    ├── 云端推理成本 = 硬件成本的 10 倍
    └── 专用 AI 加速器下放（从数据中心到边缘）

    2. 开源硬件运动全景¶

    什么是开源硬件 (OSHW)¶

    "任何人都可以基于开源硬件的设计文件进行学习、修改、分发、制造和销售，无论这些文件是硬拷贝还是数字形式。" — OSHWA 定义

    开源 vs 闭源：商业神话破解¶

    神话 事实
    ❌ "开源就是免费送" ✅ 90%+ 开源硬件公司都在盈利
    ❌ "抄袭者会毁了你" ✅ 社区维护的项目比闭源迭代更快
    ❌ "核心技术要保密" ✅ 真正的护城河是软件/生态/服务，不是原理图
    ❌ "开源没有商业模式" ✅ 至少 7 种可验证的盈利模式

    开源硬件四大许可主流¶

    许可 特性 知名项目
    CERN-OHL-W 弱 Copyleft，修改需开源但可以组合闭源 Arduino
    CERN-OHL-S 强 Copyleft，衍生作品必须同许可 大多数 KiCad 项目
    CERN-OHL-P 宽松，类似 MIT/Apache RISC-V 参考实现
    MIT / Apache 软件风格宽松许可 大量工具和库

    2026 最佳实践：优先使用 CERN-OHL v2 系列 专为硬件设计的许可，解决了软件许可不适用硬件的灰色地带

    OSHWA 认证¶

    认证价值
    ├── 法律合规性保证
    ├── 社区信任标志
    ├── 目录收录曝光
    └── 官方 UID 追溯

认证流程
    ├── 项目符合 OSHW 定义
    ├── 设计文件完整可获取
    ├── 文档规范
    └── $1-$20 认证费（按地区）

    3. RISC-V 革命与机遇¶

    为什么 RISC-V 是游戏规则改变者¶

    传统芯片 IP 模式
    ├── ARM 内核授权费 = $数百万
    ├── 每颗芯片版税抽成
    └── 不能自主修改架构

     vs

RISC-V 模式
    ├── ISA 规范完全开源免费
    ├── 零版税
    ├── 可自由扩展定制指令
    └── 全球社区协作演进

    RISC-V 生态成熟度 2026¶

    高端应用 (A 级)
    ├── Linux 能力级
    ├── 对标 ARM Cortex-A
    └── 平头哥玄铁 / SiFive U 系列

中端 MCU (M 级)
    ├── 对标 ARM Cortex-M
    ├── GD32 / CH32 / BL 系列
    └── ✅ 最成熟，创业首选

低端/极低功耗 (E 级)
    ├── 对标 Cortex-M0+
    ├── 替代 8051 的新选择
    └── 传感器 / 控制器场景

AI 加速扩展
    ├── RISC-V Vector Extension (RVV)
    ├── 各家自研 AI 指令
    └── 专用 NPU 集成

    RISC-V 创业机会地图¶

    层级 创业切入点 竞争烈度
    IP 核设计 垂直领域专用核 ⭐⭐⭐⭐⭐
    芯片设计 特定场景 SoC ⭐⭐⭐
    模组方案 无线 / AI / 感知 ⭐⭐
    开发板 教育 / 快速原型 ⭐
    垂直应用 行业专用终端设备 ⭐⭐

    4. 硬件制造可及性¶

    2026 PCB 制造格局¶

    中国大陆 (主流选择)
    ├── 嘉立创 (JLCPCB)：性价比之王，24 小时出货
    ├── 华秋 / 捷多邦：备选方案
    └── 一站式 SMT + 钢网 + 测试

全球化分布式制造
    ├── PCBWay / Seeed Fusion：全球分发
    ├── 欧洲 / 北美本地制造：快速响应 + 关税规避
    └── 制造网络 API：编程式下单

    一站式 PCBA 革命¶

    设计文件上传 → DFM 检查 → 采购物料 → SMT 贴片 → 功能测试 → 快递发货 整个流程 5-7 天，完全在线完成

    💰 成本基准（2026）¶

    项目 数量 5 数量 100 数量 1000
    PCB 2 层 10x10cm ~$2/片 ~$0.5/片 ~$0.2/片
    SMT 贴片费 ~$30 工程费 ~$1/片 ~$0.3/片
    钢网 ~$20 摊销 摊销
    总价 ~$75 ~$150 ~$500

    惊人的事实：100 片 PCBA 的总成本现在低于 1000 元人民币

    🚩 DFM Shift-Left 趋势¶

    2020 年：设计完成 → 发给工厂 → 收到 DFM 反馈邮件 → 修改 → 再发
2026 年：设计软件实时检查规则，不符合的地方即时标红提醒

关键变化
    ├── 设计软件内置 DRC 规则库
    ├── 制造商规则 API 化
    ├── 首轮良率从 60% → 95%+
    └── 设计到制造迭代周期从天 → 小时

    5. 硬件商业模式矩阵¶

    硬件创业 7 种可盈利模式¶

    模式 描述 案例 毛利率
    1. 销售硬件 直接卖产品赚钱 Raspberry Pi / Arduino 30-60%
    2. 硬件 + 订阅 硬件亏着卖，靠服务赚钱 安防摄像头 / IoT 设备 60-80% (软件)
    3. 开源核心 + 商业版 社区版免费，企业版收费 SiFive / Adafruit 70%+
    4. 定制服务 基于开源设计做客户定制 各类方案商 20-40%
    5. 开发者生态 开发板引流，SDK/工具收费 Espressif 综合
    6. 市场平台 连接供需双方抽佣 CrowdSupply / Tindie 10-15%
    7. 培训/认证 知识变现 + 人才输送 各类硬件认证课程 80%+

    🏆 推荐：开源硬件的"双重许可"模式¶

    社区版本
    ├── CERN-OHL 开源许可
    ├── 完整设计文件
    ├── 社区支持
    └── 不提供商业保证

商业版本
    ├── 商业许可协议
    ├── 官方技术支持
    ├── 定制修改服务
    ├── 长期供货保证
    └── 合规认证文件

双赢结果：社区获得免费可用的设计，公司从企业客户获得收入

    ⚠️ 硬件创业的隐形陷阱¶

    1. 低估 BOM 成本
   报价时看起来很美，量产时每个组件贵 $0.1 = 利润归零

2. 低估测试成本
   自动化测试夹具 = 额外的硬件开发工作

3. 库存风险
   卖不出去的板子 = 真金白银变成了电子垃圾
   SaaS 没有库存问题，硬件有！

4. 合规长尾
   FCC / CE / RoHS / 电池认证...
   每项都是时间和金钱

    ├── 招聘成本降低

    ├── 资金赞助开源项目

Level 5: 创立者
    ├── 发起新的开源标准

    └── 推动行业协作

    8. 合规与认证路径¶

    全球市场合规地图¶

    中国市场
    ├── CCC 强制认证 (特定品类)
    ├── SRRC 无线电型号核准
    └── RoHS 环保要求

美国市场
    ├── FCC Part 15 (无线电)
    ├── FCC Part 18 (工业)
    └── UL / ETL 安全认证 (自愿但强烈推荐)

欧盟市场
    ├── CE 标志 (自我声明)
    ├── RED 指令 (无线电)
    ├── RoHS / REACH
    └── WEEE 回收责任

全球互认
    └── CB 认证体系 = 一次测试多国接受

    认证成本与时间表 2026¶

    认证 预计费用 周期 备注
    CE (自我声明) $500-$2,000 1-2 周 实验室测试报告 + 技术文档
    FCC ID $2,000-$5,000 4-8 周 无线产品强制
    SRRC (中国) $3,000-$8,000 6-12 周 国内销售无线产品
    UL / ETL $5,000-$15,000 8-16 周 亚马逊等平台要求
    CCC $10,000+ 3-6 月 特定品类强制

    开源硬件的认证优势¶

    如果你的设计开源
    ├── 社区会帮你发现合规问题
    ├── 很多认证机构对开源项目有优惠
    ├── 设计文件公开 = 审查过程更快
    └── 其他公司可以复用你的认证基础

    9. 典型成功案例拆解¶

    案例 1: Espressif (乐鑫科技)¶

    商业模式：芯片 + 模组 + 开发者生态
开源策略：完整 SDK / 工具链开源，硬件参考设计开源
成功关键：
    1. ESP8266 把 WiFi 模组价格从 $10 打到 $2
    2. 极度重视开发者体验
    3. 构建了全球最大的嵌入式开发者社区
    4. 每个新项目都有社区贡献的支持

结果：市值数十亿美元，IoT WiFi 芯片全球市占率第一

    案例 2: Raspberry Pi¶

    商业模式：销售硬件 + 教育授权 + 品牌合作
开源策略：软件完全开源，硬件设计延迟开源（保护核心）
成功关键：
    1. 极致的性价比 ($35 电脑)
    2. 教育市场深耕
    3. 百万级的教程/项目生态
    4. 非营利定位赢得广泛支持

结果：售出 5000 万台+，定义了单板计算机品类

    案例 3: SiFive¶

    商业模式：RISC-V IP 核授权 + 定制芯片服务
开源策略：核心 IP 开源，高端版本商业许可
成功关键：
    1. RISC-V 先驱和主要推动者
    2. 开源吸引开发者，商业版服务企业
    3. 定义了 RISC-V 生态的标准

结果：独角兽估值，RISC-V 生态领导者

    10. 90 天硬件 MVP 路线图¶

    Day 1-30: 概念与验证¶

    第 1-2 周
    ├── 定义核心功能（不是功能列表，而是"做什么不做什么"）
    ├── 竞品拆解分析
    ├── 关键器件选型（BOM 成本估算）
    └── 风险评估（哪个部分最可能失败？）

第 3-4 周
    ├── 面包板原型验证
    ├── 关键信号测试
    ├── 最小系统验证
    └── 编写技术设计文档

    Day 31-60: 设计与打样¶

    第 5 周
    ├── 原理图设计
    ├── DRC 检查
    └── 生成 BOM 表

第 6 周
    ├── PCB Layout
    ├── 3D 模型检查（碰撞检测）
    ├── DFM 规则检查
    └── 生成 Gerber

第 7-8 周
    ├── 投板 + SMT
    ├── 同时准备测试夹具
    └── 准备测试程序

    Day 61-90: 迭代与优化¶

    第 9 周
    ├── 收到第一版 PCB
    ├── 硬件 bring-up
    ├── 功能测试
    └── Bug 记录

第 10-11 周

    🎯 行动建议：迈出第一步¶

    如果你是软件背景想做硬件

    ├── 不用一开始就做 PCB，先用开发板组装
    ├── 找一个硬件合伙人（或者雇佣自由职业）
    └── 第一个目标：做出能演示的东西

    ├── 不要闭门造车，先在社区分享想法
    ├── 尽早拿到真实的客户反馈
    ├── 考虑先做咨询服务验证需求
    └── 不要一开始就想着做芯片，从模组开始
