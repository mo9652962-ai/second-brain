## 🚀 AI PCB 工作流 2026 版

### 方案 A：全 AI 驱动（最快上市）

```
阶段 1：原理图捕捉
└── ProtoFlow AI → 生成原理图网表
    └── 导出到 KiCad/Altium

阶段 2：布局布线
└── Quilter AI → 全板自动布局 + 关键信号布线
    └── 5-6 倍速度提升（传统 27-32 小时 → 5 小时）
    └── 并行生成多方案候选，择优选择

阶段 3：人工精修 + 验证
└── 工程师审核关键路径、阻抗控制
    └── DFM/DRC/ERC 检查
```

### 方案 B：混合工作流（推荐）

```
原理图 → 嘉立创 EDA / KiCad 手动设计
    ↓
布局 → 关键器件手动放置 + AI 辅助优化
    ↓
布线 → 手动走关键信号 + AI 处理剩余布线
    ↓
验证 → AI 辅助 DFM 分析 + 人工审核
```

## ✅ DFM 可制造性设计最佳实践 2026

### 左移原则：DFM 越早介入越好

| 项目阶段 | 必须执行的 DFM 动作 |
|---------|-------------------|
| **原理图阶段** | 早期与制造商确认叠层方案 |
| **布局开始** | 应用更新的 DFM 规则集（IPC-2221 标准） |
| **布局中期** | 跨团队 DFM 检查点 |
| **发布前** | 联合设计装配审计 + DFM 全面检查 |
| **量产前** | 工厂 CAM 数据验证 |
| **首批次** | 反馈到 DFM 规则库持续改进 |

### 核心检查清单

```
必查项：
1. 线宽与间距优化 → 符合制造商最小工艺
2. 过孔 DFM 检查 → 孔径/焊盘比例，反焊盘尺寸
3. 参考平面完整性 → 高速信号下方无分割
4. 阻抗控制计算 → 50Ω/90Ω/100Ω 差分对
5. 热焊盘设计 → 防止"冷焊点"
6. 元件到板边安全距离
7. 高低元件合理布局（波峰焊方向）
```

### IPC 标准引用

| 标准 | 适用 |
|------|------|
| IPC-2221 | 通用刚性板 |
| IPC-2222 | 刚性板细节 |
| IPC-2223 | 刚挠结合 |
| IPC-2226 | HDI 高密度互连 |
| IPC-2228 | 高频/RF/微波 |

## 🚄 高速 PCB 设计原则

### 高速判断标准

> 不是看时钟频率，而是看**信号上升时间**！
>
> **上升时间 < 4× 传输延迟** → 需要高速设计方法

### 信号完整性核心规则

```
1. 【强制】控制阻抗走线
   └── 50Ω 单端，90/100Ω 差分对
   └── 用叠层 + 线宽计算确定

2. 【强制】完整参考平面
   └── 信号层必须紧邻 GND 或 POWER 平面
   └── 绝对避免跨分割（跨平面裂缝）

3. 【推荐】最小化层切换
   └── 每次过孔切换 = 阻抗不连续点

4. 【推荐】差分对内严格等长
   └── 长度不匹配 → 时序偏斜

5. 【推荐】3W 规则
   └── 线中心间距 ≥ 3× 线宽，减少串扰
```

### 叠层设计推荐（4 层板）

```
顶层：信号层（Top）
↓
第二层：完整 GND 平面（关键！）
↓
第三层：POWER 平面（可分割）
↓
底层：信号层（Bottom）
```

## 💡 设计到交付标准工作流

```
1. 原理图设计（嘉立创 EDA / KiCad）
    ↓ 执行 ERC 检查
2. 元器件选型 + BOM 准备（优先 LCSC 有库存型号）
    ↓ 确认价格与交期
3. PCB 布局 + 布线
    ↓ 在线 DRC 检查
4. DFM 预检查（对照制造商规则）
    ↓ 特别注意最小线宽/孔径
5. 导出 Gerber + NC Drill + BOM + 坐标文件
    ↓ 一键下单（嘉立创 EDA → JLCPCB）
6. 制造 + SMT 装配
    ↓ 7-10 天
7. 收到样板 → 焊接测试
```

## ⚠️ 常见陷阱

1. **忘记与制造商确认叠层**
   > 每家工厂的材料厚度不同，阻抗计算结果也不同
2. **布线后才发现元件封装错了**
   > 提前审核封装，特别是 QFN/BGA 的焊盘尺寸
3. **不做 3D 检查**
   > 器件高度冲突、外壳干涉问题，投产前才发现就晚了
4. **迷信全板自动布线**
   > 2026 年 AI 可以处理大部分，但关键路径仍需人工精修
