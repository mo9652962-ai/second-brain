    PPT 智能优化助手 v3.0（含 Gate 检查）¶

    帮助用户快速优化PPT演示文稿，v3.0新增：Async-First自检、移动端适配、3D一致性、卡片式布局评分、AI图像质量检测。

    2026优化标准（v3.0升级）¶

    标准0: 🆕 Async-First 独立阅读检查¶

    检查项 通过标准 典型违规
    标题独立性 每页标题=完整结论句 "数据分析"应该改成"Q3核心指标增长35%"
    图表自解释 所有图表有annotation标注 纯图表无任何标记文字
    Speaker Notes 100%页面有Notes 异步阅读者得不到任何补充信息
    "脱讲自测" 去掉所有Notes后仍可理解 提到"这里我们看..."等指代词

    Async-First评分： | 等级 | 描述 | |------|------| | A | 发送PPT链接给任何人→完全理解，无需讲解 | | B | 大体可理解，少数页面需上下文 | | C | 强烈依赖演讲者，不适合异步分享 |

    标准1: 15字标题法则（保持）¶

    标准2: One Idea Per Slide（保持）¶

    标准3: 对比度 ≥ 4.5:1（保持）¶

    🆕 标准6: 移动端适配诊断¶

    检查项 阈值 修正方法
    正文最小字号 ≥18pt 在手机上16pt以下无法阅读
    多列布局 手机端自动单列 建议≤2列
    图表系列数 ≤3系列 手机上多系列混杂
    触控目标 按钮≥44x44pt 链接/按钮需触控友好
    页边距 足够宽 防止手机浏览器裁切

    🆕 标准7: 3D元素一致性¶

    信号 阈值 修正
    3D/2D混用率 <30%混用 全部3D或全部平面
    3D图标风格 统一来源 不混用不同3D库
    3D复杂度 适中 低端设备渲染不卡顿

    🆕 标准8: 卡片式布局评分¶

    评分 描述
    A 模块清晰、可自由排序、每卡片独立完整
    B 有卡片意识但不够模块化
    C 传统线性布局, 不适合灵活分享

    标准5: AI痕迹检测（升级版，增加新检测项）¶

    新增检测信号： | 信号 | 阈值 | 修正 | |------|------|------| | 🆕 AI图片风格单一 | 同一prompt风格 | 混合2-3种视觉风格 | | 🆕 过度使用AI生成图 | >50%页用AI图 | 混入真实照片/截图 | | 🆕 完美数据可视化 | 无一异常值 | 加入1-2个"不完美"元素 |

    🚦 Gate 检查机制（v3.0新增）¶

    输入PPT → 八标准诊断 → 综合评分
  │                    │
  ├─ score >= 60 ───→ ✅ 通过 → 输出优化方案
  │
  └─ score < 60 ────→ ❌ 阻断 → 生成修订指令 → 退回重制

    评分细则（100分制）¶

    维度 权重 满分 检查内容
    Async-First 18% 18 标题结论性、图表自解释、Notes完整性
    15字标题 15% 15 每页标题≤15字
    One Idea 15% 15 每页单一论点
    对比度 12% 12 文字/背景对比度≥4.5:1
    叙事流 12% 12 页间逻辑连贯
    AI痕迹 10% 10 去AI化程度
    移动适配 10% 10 字号≥18pt、≤2列、触控目标
    3D一致 5% 5 3D/2D不混用
    卡片布局 3% 3 模块化程度

    Gate 阈值¶

    场景 阈值 行为
    默认 ≥60 通过，输出优化建议
    严格模式 ≥75 通过，任何单项<50%触发阻断
    紧急模式 ≥50 通过，仅阻断致命问题

    阻断回退指令¶

    当 score < 60 时，输出：

    {
  "gate_passed": false,
  "score": 52,
  "blocking_issues": [
    "Async-First: 8/15页标题非结论句 (权重18% → 扣9分)",
    "移动适配: 5页字号<18pt (权重10% → 扣7分)"
  ],
  "retry_instructions": "1. 将第2,3,5,7,9,11,13,14页标题改为结论句\n2. 将所有正文字号调整至≥18pt\n3. 重新运行 pptx-generator 生成"
}

    优化流程（v3.0升级）¶

    输入PPT → 八标准诊断 → 综合评分 → Gate检查
  │                               │
  │                        ├─>=60 → 优化方案
  │                        └─<60 → 阻断回退
  │
  └─ report.json（每次必输出）
