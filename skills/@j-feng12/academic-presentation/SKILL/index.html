    🆕 2026学术PPT前沿原则¶

    原则0: Async-First（独立可读性）⭐ 最重要¶

    在2026年，大多数学术PPT通过邮件/微信/Teams分享，审阅者在没有你的讲解下阅读。

    要求： - 每张slide即使脱离演讲者，也能独力传达该页的核心信息 - 标题必须是完整结论句，而非描述性短语 - 图表必须配自解释标注（annotation），不依赖口头说明 - Speaker Notes 强制填写（异步阅读者的"隐藏解说"）

    自检：把PPT发给导师，不加任何说明，ta能完全理解吗？

    原则1: 图表优先（Figure-First Design）¶

    • Methods 页用流程图替代纯文字
    • Results 页用图表+annotation替代表格罗列
    • 每张图表配1条「关键发现」标注文字（≤15字）

    原则2: 15字学术标题法则¶

    • 标题 = 该页的核心发现/结论
    • ❌ "实验结果分析" → ✅ "模型A在3个数据集上优于baseline"
    • ❌ "相关工作" → ✅ "现有方法均未解决跨域泛化问题"

    原则3: 证据等级标注¶

    • 在PPT的关键结论旁标注证据等级
    • [Established] / [Comparative] / [Computational] / [Speculative]

    原则4: 知识缺口诚实标记¶

    • 至少2页主动展示研究局限
    • 避免"完美研究"假象

    🆕 原则5: 移动端优先¶

    正文最小字号: 18pt (手机上可读)
图表标签最小: 14pt
避免密集多列布局: 手机屏宽≈375px
高对比度: 户外/通勤场景也能看清

    🆕 原则6: AI学术图像生成¶

    学术插图: Copilot/Gemini/DALL-E生成定制化概念图
化学结构/分子: AI生成3D分子模型
数据可视化升级: AI辅助选择最佳图表类型
提示词模板: "科学插图风格，展示[概念]，简洁线条，学术配色，白底，适合期刊发表"

    🆕 2026论文叙事框架（升级3→4种）¶

    框架D: 模块化卡片（Gamma风格）🆕¶

    适用于：在线预讲、异步分享、灵活组会

    核心卡片(1张) → 问题卡片(1-2张) → 方法卡片(2-3张)
→ 结果卡片(2-3张) → 局限卡片(1张) → 展望卡片(1张)
    • 每张卡片 = 1个独立论点
    • 可自由排序, 按听众兴趣跳过/深入
    • 适合网络分享和异步审阅

    工作流（6 + 1 阶段）¶

    🟢 Stage 4：PPT大纲设计（升级版）¶

    输出格式（v4.0升级）：

    ### Slide 1: 标题页（≤15字标题 + 作者信息 + 日期）
🎯 核心信息：一句话概括整个研究
📱 移动自检：标题在手机上清晰可读

### Slide 2: 问题背景
🎯 核心信息：[一个背景陈述]
📊 视觉：关键数据大字卡
💡 One Idea：为什么这个问题值得研究？
📝 Speaker Note：[异步阅读者需要的背景补充]

### Slide 3-5: 方法/发现（图表优先 + 自解释标注）
📊 每页1个核心图/表 + 1条Key Finding标注
📝 Speaker Note：[方法细节补充]

### Slide N-2: 知识缺口（诚实页）
🎯 核心信息：[具体局限1]
🎯 核心信息：[具体局限2]
💡 "这些局限意味着..."

### Slide N: 致谢/QA

    🆕 Async-First自检表： - [ ] 去掉Speaker Notes, 每页能否独立理解? - [ ] 图表标注是否自解释? - [ ] 手机上正文≥18pt是否可读? - [ ] 配色是否通过WCAG AA对比度?
