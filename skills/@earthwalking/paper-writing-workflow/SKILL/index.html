    Paper Writing Workflow v2.0¶

    Overview¶

    标准化论文写作工作流，整合多个论文写作技能，提供从选题到完稿的完整流程。v2.0新增「去AI味」独立阶段。

    7 Workflow Stages¶

    1. 选题与假设 (10-20 分钟)¶

    • 研究问题生成
    • 假设形成
    • 变量定义

    使用技能: hypothesis-generation, research-lookup

    2. 文献搜索与综述 (30-60 分钟)¶

    • 文献搜索（知网/PubMed/Scopus/Google Scholar）
    • 文献整理
    • 文献综述写作

    使用技能: cnki-scholar, paper-parse, paper-summarize-academic

    3. 论文大纲设计 (15-30 分钟)¶

    • IMRAD 结构设计
    • 每部分关键点
    • 图表计划

    使用技能: chinese-academic-writing, paper-writing-workflow

    4. 初稿写作 (60-120 分钟)¶

    • 摘要写作
    • 引言写作
    • 方法写作
    • 结果写作
    • 讨论写作

    使用技能: chinese-academic-writing, paper-writing-workflow

    2026写作原则（防止初稿过度AI化）： - ❌ 不使用"首先...其次...最后"结构 - ❌ 结论段不以"综上所述"开头 - ✅ 引言用"研究空白驱动"而非"重要性罗列" - ✅ 讨论用"对话式"而非"结论式"收束

    5. 🆕 去AI味处理 (20-40 分钟)¶

    触发条件：初稿完成后、润色前强制执行

    检测流程：

    1. AI痕迹快速扫描（使用sci-paper-three-pass检测清单）
    2. 句长标准差检测（std < 5 → 需修复）
    3. 模板句式检出率（>10% → 需改写）
    4. 段落开头词重复率（>30% → 需多样化）

    5. TTR均质化检测（跨段TTR差异 < 0.1 → 需扩充词汇）

    6. 句式多样性注入

    7. 每200词插入1个短句(≤8词)冲击
    8. 句长分布重塑：确保10%短句、60%中句、30%长句

    9. 相邻段落开头多样化

    10. 论证非线性重构

    11. 识别"首先→其次→最后"模式 → 替换为嵌套论证
    12. 添加1-2处让步/自我反驳

    13. 关键结论前插入1处"不完全确定性"表述

    14. 学科习语注入

    15. 中文论文：嵌入领域惯用表述（如"换句话说"替代"换言之"、"从某种意义上"替代"在某种程度上"）

    16. 英文论文：使用field-specific abbreviation和约定俗成的表达

    17. 知识缺口标记

    18. Introduction末尾：明确标记1-2个研究界未解决的问题
    19. Discussion中段：嵌入至少2处知识缺口信号
    20. 将"further studies are needed"具体化为可操作的研究建议

    使用技能: sci-paper-three-pass (四刀方法论)

    6. 图表生成 (30-60 分钟)¶

    • 图形摘要（必需）
    • 方法流程图
    • 结果图表
    • 理论框架图

    使用技能: openclaw-slides, pptx-generator

    7. 润色与格式检查 (30-60 分钟)¶

    • 语言润色
    • 格式检查（期刊/学校模板）
    • 引用检查
    • 2026新增：去AI味后复核（确认阶段5的修改未被润色覆盖）

    使用技能: chinese-academic-writing, journal-sci-ssci-checker, sci-journal-search

    2026版 AI痕迹检测清单（写作全流程）¶

    写作过程中逐项自查：

    🔴 高危信号（出现任1条 → 立即改写）¶

    • [ ] 句长标准差 < 5
    • [ ] plays a crucial/essential role 出现
    • [ ] 连续3句以 However/Furthermore/Moreover 开头
    • [ ] "综上所述"/"In conclusion" 开头结论段
    • [ ] ≥3处 "significantly/notably/remarkably"

    🟡 中危信号（≥3条 → 需处理）¶

    • [ ] "首先...其次...最后" 结构 ≥2处
    • [ ] 段落开头词重复率 > 30%
    • [ ] 跨段 TTR 差异 < 0.1
    • [ ] 被动语态比例 < 30% 或 > 55%
    • [ ] 全文零处自我修正/让步表述

    🟢 低危信号（注意即可）¶

    • [ ] "There be" 句型过于密集
    • [ ] 所有段落都是 topic→evidence→conclusion 结构
    • [ ] 缺少学科专属缩写/黑话

    IMRAD Structure¶

    Introduction (引言)¶

    • 研究背景（宽）→ 知识缺口（窄）→ 研究问题 → 研究假设 → 研究意义
    • 2026重点：背景段末尾必须嵌入知识缺口信号
    • 字数: 800-1200 字

    Methods (方法)¶

    • 研究设计 → 参与者 → 材料/工具 → 程序 → 数据分析
    • 字数: 1000-1500 字

    Results (结果)¶

    • 描述统计 → 推断统计 → 图表展示 → 效应量报告
    • 2026重点：数值精确到有效位数，不四舍五入过度
    • 字数: 1000-1500 字

    Discussion (讨论)¶

    • 主要发现 → 与现有研究对话 → 理论贡献 → 实践意义 → 局限性 → 未来方向
    • 2026重点：
    • 必须嵌入 ≥2 处知识缺口信号
    • 与至少2篇最新文献（近3年）对话
    • 局限性不得泛泛而谈
    • 字数: 1500-2000 字

    Quality Checks¶

    去AI味检查（🆕 2026）¶

    • [ ] Burstiness 评分 > 6（句长标准差 > 7）
    • [ ] TTR 跨段差异 > 0.1
    • [ ] 模板句式检出 < 5%
    • [ ] 每2000词 ≥1 处自我修正/让步
    • [ ] 知识缺口信号 ≥2 处
    • [ ] 学科习语 ≥3 处

    结构检查¶

    • [ ] IMRAD 结构完整
    • [ ] 各部分字数符合要求
    • [ ] 图表数量符合要求
    • [ ] 参考文献数量充足（30-50 篇）

    内容检查¶

    • [ ] 研究问题明确
    • [ ] 方法详细可重复
    • [ ] 结果客观准确
    • [ ] 讨论深入全面

    格式检查¶

    • [ ] 引用格式正确
    • [ ] 参考文献列表完整
    • [ ] 图表格式规范
