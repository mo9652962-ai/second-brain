## 1. GitHub SEO 排名因子（2026 最新）

### 权重排名

| 权重 | 因子 | 说明 |
|------|------|------|
| 30% | **仓库名称** | 关键词精确匹配 |
| 20% | **About 描述** | 关键词密度 + 清晰度 |
| 15% | **README 内容** | 标题层级、关键词分布 |
| 10% | **Topics 标签** | 精确匹配热门话题 |
| 10% | **Stars/Forks** | 社区活跃度 |
| 8% | **提交频率** | 最近更新时间 |
| 7% | **其他** | Issue 数量、贡献者数量 |

### 2.1 仓库描述优化公式

```
[一句话定位] + [3-5 个核心关键词] + [独特卖点]
```

**本仓库当前描述**：
```

```

**优化后建议**：
```

```

### 2.2 Topics 标签（10-15 个最佳）

**推荐标签组合**：

```
second-brain, obsidian-vault, knowledge-base, ai-agent,
hermes, self-improving-agent, pcb-design, hardware,
academic-writing, chinese-knowledge-base, llm-agent,
agent-memory, skill-library, open-source-hardware
```

**标签选择原则**：
- ✅ 混合「大词」（second-brain, ai-agent）和「精准词」（pcb-design, hermes）
- ✅ 每个标签都要和仓库内容真的相关
- ✅ 检查标签页面有多少仓库在用，优先选已有一定量的标签

## 5. 徽章系统最佳实践

### 5.1 徽章使用原则

| 原则 | 说明 |
|------|------|
| **数量控制** | 顶部只放 2-4 个核心徽章，不要搞徽章墙 |
| **统一来源** | 全部用 Shields.io，风格一致 |
| **信息密度** | 每个徽章传达一个明确的信息 |
| **颜色逻辑** | 用颜色表达状态（绿色=好，黄色=注意，红色=警告） |

### 5.2 推荐徽章组合

```markdown
<!-- 基础信息 -->
![GitHub License](https://img.shields.io/github/license/mo9652962-ai/second-brain)
![GitHub Repo Size](https://img.shields.io/github/repo-size/mo9652962-ai/second-brain)

<!-- 活跃度 -->
![GitHub Last Commit](https://img.shields.io/github/last-commit/mo9652962-ai/second-brain/dev)
![GitHub Commits](https://img.shields.io/github/commit-activity/m/mo9652962-ai/second-brain/dev)

<!-- 内容统计（自定义） -->
![Skills Count](https://img.shields.io/badge/Skills-13-blue)
![Knowledge Notes](https://img.shields.io/badge/Notes-84+-green)
![Maturity](https://img.shields.io/badge/Maturity-63%25-yellow)
```

### 5.3 自定义颜色规范

```
🔵 蓝色 = 信息类（数量、版本）
🟢 绿色 = 状态良好（健康、通过）
🟡 黄色 = 注意、进行中
🔴 红色 = 警告、需要修复
🟣 紫色 = 特色、亮点
```

## 6. GEO AI 搜索优化（2026 新趋势）

### 什么是 GEO？

> **Generative Engine Optimization** — 优化让 ChatGPT、Claude、Perplexity 等 AI 在回答时引用你的仓库。

### 优化要点

| 优化项 | 怎么做 |
|--------|-------|
| **清晰的类别定义** | 在 README 开头明确说「这是什么」，比如：「这是一个中文 AI Agent 第二大脑...」 |
| **结构化的能力列表** | 用列表/表格列出核心功能，AI 更容易提取 |
| **独特卖点明确** | 「国内唯一公开的 Agent 自举系统」这种明确的表述 |
| **关键词重复** | 主要关键词在不同地方自然出现：名称/描述/正文 |
| **允许 AI 爬取** | robots.txt 允许 GPTBot、ClaudeBot、Google-Extended |
