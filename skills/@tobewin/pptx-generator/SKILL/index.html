    PPT Generator v4.0¶

    专业 PPT 生成器。通过 JSON 描述生成标准、可编辑的 PowerPoint 演示文稿。 v4.0 新增：Async-First独立模式、卡片slide、AI图像prompt、暖色主题、移动端适配。

    2026设计原则（内建强制执行）¶

    原则0：Async-First独立可读 🆕¶

    • 每张slide即使脱离演讲者也能独立传达信息
    • 标题必须是完整结论句
    • 图表自动添加自解释标注
    • Speaker Notes 强制生成

    原则1-4（继承v3.0）：One Idea / 15字法则 / 视觉层次 / WCAG 2.2¶

    🆕 原则5：AI图像集成¶

    {
  "ai_image_prompt": "scientific illustration of neural network architecture, clean lines, academic color palette, white background, suitable for journal publication",
  "image_style": "scientific|3d_render|flat_illustration|photorealistic|warm_minimal"
}

    🆕 原则6：移动端适配¶

    • 正文字号自动≥18pt
    • 多列布局自动降级为单列（mobile-safe模式）
    • 触控友好间距

    配色方案（扩展至10套）¶

    风格 适用场景 模式 🆕
    business_blue 商业汇报 light -
    academic_white 学术论文 light -
    creative_purple 创意展示 light -
    tech_dark 技术分享 dark -
    glass_morphism 产品发布 glass -
    warm_minimal 温和专业 🆕 light ✅
    bold_contrast 融资路演 dark -
    nature_green ESG/可持续 light -
    card_deck 模块化展示 🆕 light/dark ✅
    async_canvas 独立阅读 🆕 light/dark ✅

    JSON 结构（v4.0扩展）¶

    {
  "style": "warm_minimal",
  "theme_mode": "light|dark|glass",
  "async_first": true,
  "mobile_safe": true,
  "ai_images": [
    {"slide_index": 3, "prompt": "...", "style": "scientific"}
  ],
  "footer": "机密",
  "page_numbers": true,
  "accessibility_check": true,
  "output": "report.pptx",
  "slides": [
    {"type": "cover", ...},
    {"type": "card_deck", "title": "核心发现", "cards": [
      {"icon": "🔬", "heading": "发现1", "body": "≤30字", "figure": "85%"},
      {"icon": "📊", "heading": "发现2", "body": "≤30字", "figure": "62%"}
    ]},
    {"type": "async_content", "title": "完整结论句≤15字", 
     "visual": "chart/table/image", 
     "annotation": "自解释标注≤20字",
     "speaker_note": "异步阅读者需要的补充信息"}
  ]
}
