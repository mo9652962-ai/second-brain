# 🧠 Memory 索引

> 依据【资产三级隔离原则】，所有个人日常复盘、任务日记、运行日志与离线反思已物理隔离至本地私有保险箱（`private_knowledge/memory/`），不对外公开同步。
> 本文件仅作为文档站结构导航与本地索引锚点保留。

## 🔒 物理隔离说明

* **公开开源层（Public）**：不包含任何私有日常日记、财务或心路历程；
* **本地隔离层（Air-Gapped）**：包含 `memory/2026/`、`memory/dreaming/` 与归档记录，已全部归档至本地环境。
