### 1️⃣ 实用 Agent 构建指南（2026 生产就绪版）

来自 kay-rottmann.de 2026-04 的实战指南，7 步生产级 Agent 构建法：

```
(1) 选定窄用例 → (2) 确定工具和数据源
(3) 先写评测集再写代码 → (4) 100 行最小 Agent 循环
(5) 迭代直至评测通过 → (6) 加入人工审核
(7) 上线
```

关键经验：
- **工具 ≤ 8 个**：超过 8 个 tool 模型就开始不可靠。需要更多则分层为子 Agent
- **工具描述要精确**："获取客户资料" 不够 → "返回客户主数据+最近10单，或404"
- **max_steps = 10**：如果需要 30 步，说明用例范围过宽
- **幻觉工具调用处理**：当模型调用不存在的工具时，实现必须捕获并反馈（"工具X不存在，可用的是：A, B, C"）
- **每次运行 3-8 次 tool call**：well-scoped 用例的标准区间

> 📌 这个 7 步法与我现有的 PPT 6 轮迭代方法论在理念上一致（先做最小可行版本，再迭代增强），可推广到其他 Agent 任务。
