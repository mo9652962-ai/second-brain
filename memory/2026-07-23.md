从日志分析发现三个问题:

1. **opencode-go 缺少 models[] 列表** → openclaw.json 中 models.providers.opencode-go 没有注册 models 字段，导致所有 opencode-go 非 primary 模型调用时报 `model_not_found`（kimi-k3, minimax-m3, qwen3.7-plus, glm-5.2, mimo-v2.5-pro 全部失败）

2. **qwen3-coder:free 已过期** → OpenRouter 返回: "This model is unavailable for free. The paid version is available now"
   - 修复: 从 fallback 链移除 `openrouter/qwen/qwen3-coder:free` 从 models 列表移除
   - 清理了其他不可用的 OpenRouter 免费模型: gemma-4:free, nenotron-3-nano-omni:free, qwen3-coder-next
