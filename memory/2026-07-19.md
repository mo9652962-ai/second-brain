# 2026-07-19

## OpenClaw HTTP 500 诊断与修复

### 问题
13:47-13:48 期间，webchat 连续两次报错 `Agent failed before reply: HTTP 500: Internal server error`。sora 当时在问 Steam 下载地址。

### 根因分析
查看日志 `C:\Users\31954\AppData\Local\Temp\openclaw\openclaw-2026-07-19.log`，确认：

**不是 OpenClaw Gateway 自身的 bug，而是上游模型供应商 opencode.ai 故障。**

证据链：
1. 所有请求 `POST https://opencode.ai/zen/go/v1/chat/completions` → `status=500` × 9+ 次
2. OpenClaw 内建重试（两轮 run，每轮多次重试）全部失败
3. `fallbackConfigured: false` — 没有配置跨供应商 fallback，重试链路耗尽
4. `chain_exhausted` / `surface_error` — OpenClaw 把错误正确抛给了用户

### 当前配置
- Provider: `opencode-go`（仅此一个供应商）
- 所有模型 (`deepseek-v4-pro`, `kimi-k2.6`, `kimi-k2.7-code`, `kimi-k2.5`, `glm-5.2`, `qwen3.7-plus`, `mimo-v2.5`, `mimo-v2.5-pro`, `hy3-preview`) 都走同一个 API endpoint
- 没有配置跨供应商 fallback，所以供应商一挂全挂

### 修复
- ✅ 配置模型级 fallback：deepseek-v4-pro → kimi-k2.6 → qwen3.7-plus → glm-5.2
- ⚠️ 局限：同供应商，供应商级故障时仍无效。未来可考虑添加跨供应商 fallback
